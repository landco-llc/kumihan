How to use KUMIHAN｜글짜임 with Gemini.

01 / Choose the Korean package

The bundle contains all four skills. Choose a standalone ZIP for one skill. Every file below belongs to the Korean product. A download does not establish a marketplace listing or successful native installation.

  • Gemini CLI extension bundle — v0.1.0
  • Standalone Skill — kumihan-geuljjaim
  • Standalone Skill — kumihan-geuljjaim-web
  • Standalone Skill — kumihan-geuljjaim-documents
  • Standalone Skill — kumihan-geuljjaim-review

SHA256SUMS.txt · MANIFEST.json

After downloading, compare the file SHA-256 with SHA256SUMS.txt, then extract it. Each Skill folder contains SKILL.md and local references. Attaching a file to an ordinary chat does not install a skill.

02 / Install and reload

Extract the Gemini CLI extension bundle and install the local folder with the commands below. Review the host trust/consent prompt. For a standalone Skill, copy its complete folder to the project .gemini/skills/, then restart or use /skills reload. Uploading these ZIPs to the Gemini consumer app is not claimed. Authenticated model invocation requires a separate check.

gemini extensions install ./kumihan-geuljjaim
gemini extensions list
gemini skills list --all
  1. Back up existing configuration and any Skill folder with the same name. Replace only the Korean product, leaving other language products intact.
  2. Copy the complete selected Skill folder. Copying SKILL.md alone omits local dependencies. The package version is 0.1.0.
  3. Reopen the host or refresh its Skill list. Check the name appears, then run the example below.

03 / First review

Check that the example targets Korean, preserves the source and numbers, and returns read-only findings. It must not edit files or report unperformed checks as passed.

ko-KR의 상품 소개 페이지를 검토해 주세요. 상품명, 가격, 원산지와 숫자는 바꾸지 말고 줄바꿈과 정보 구조만 확인해 주세요.

04 / Updates and limitations

For updates, verify the Korean release and checksums, back up the old folder, replace it, reload the host and repeat the smoke review. Automatic correction, native Korean editing, Office/PDF and native host behavior are not guaranteed. No public marketplace listing.
