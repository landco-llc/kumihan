01 / 한국어 배포물 선택

번들은 네 가지 Skill을 포함합니다. 하나만 필요하면 단독 ZIP을 선택하세요. 아래 파일은 모두 동일한 한국어판입니다. 공개 마켓플레이스 등록이나 네이티브 호스트 설치 성공을 뜻하지 않습니다.

  • Gemini CLI 확장 번들 — v0.1.0
  • 단독 Skill — kumihan-geuljjaim
  • 단독 Skill — kumihan-geuljjaim-web
  • 단독 Skill — kumihan-geuljjaim-documents
  • 단독 Skill — kumihan-geuljjaim-review

SHA256SUMS.txt · MANIFEST.json

다운로드 후 SHA256SUMS.txt와 파일의 SHA-256을 비교하고 압축을 풉니다. ZIP의 Skill 폴더에는 SKILL.md와 로컬 참조가 들어 있습니다. 일반 채팅에 파일을 첨부하는 것만으로 설치되지 않습니다.

02 / 설치와 다시 읽기

Gemini CLI 확장 번들을 압축 해제하고 아래 명령으로 로컬 폴더를 설치합니다. 호스트의 신뢰·동의 내용을 확인하세요. 단독 Skill은 전체 폴더를 프로젝트의 .gemini/skills/에 두고 재시작하거나 /skills reload로 다시 읽습니다. Gemini 소비자 앱의 ZIP 업로드는 지원한다고 주장하지 않습니다. 인증된 모델 호출은 별도 확인이 필요합니다.

gemini extensions install ./kumihan-geuljjaim
gemini extensions list
gemini skills list --all
  1. 기존 설정과 같은 이름의 Skill 폴더를 백업합니다. 한국어판만 교체하고 다른 언어판은 변경하지 않습니다.
  2. 선택한 Skill 폴더 전체를 옮깁니다. SKILL.md만 복사하면 로컬 참조가 빠집니다. 버전은 0.1.0입니다.
  3. 호스트를 다시 열거나 Skill 목록을 새로고침합니다. 목록에 이름이 보이는지 확인하고 아래 예시로 동작을 확인하세요.

03 / 첫 검토

예시를 실행한 뒤 한국어 대상·원문과 숫자 보존·읽기 전용 소견을 확인하세요. 파일 변경이 없어야 하며, 확인하지 않은 항목을 passed로 보고하면 안 됩니다.

ko-KR의 상품 소개 페이지를 검토해 주세요. 상품명, 가격, 원산지와 숫자는 바꾸지 말고 줄바꿈과 정보 구조만 확인해 주세요.

04 / 업데이트와 한계

업데이트는 같은 한국어 패키지의 릴리스와 체크섬을 확인한 뒤 백업한 폴더를 교체합니다. 호스트를 다시 읽고 첫 검토를 반복하세요. 자동 교정·원어민 교열·Office/PDF·네이티브 호스트 동작은 보장하지 않습니다. 일반 마켓플레이스에는 미등록입니다.
