# Install KUMIHAN｜تراز v0.1.0

Download published, checksum-verified ZIPs from GitHub Release tag kumihan-fa-v0.1.0. Compare each ZIP with SHA256SUMS.txt and MANIFEST.json first. Technical slug kumihan-fa supports host plugin registration; **display name is KUMIHAN｜تراز**.

Claude Code: extract kumihan-fa-Claude-Code-plugin-v0.1.0.zip into a separate directory and use: claude --plugin-dir /absolute/path/kumihan-fa . For Claude chat where Skills are supported, import an individual Claude skill ZIP. Local install is not marketplace publishing.

Gemini CLI: extract kumihan-fa-Gemini-CLI-extension-v0.1.0.zip and use: gemini extensions install /absolute/path/kumihan-fa . Gemini Apps standalone skill ZIPs are separate and product-import availability depends on the client's current capability. A CLI extension is not a Gemini chat plugin.

ChatGPT/Codex: use a supported plugin or skill import surface if available. Codex project skills may be extracted to .agents/skills/. Merely attaching a ZIP to chat is not installation.

Each host offers a plugin/extension and four individual skills for a total of five packages. The archives contain independent rule references, locale profiles and bounded static checks. Native app invocation is not claimed until observed.
