# KUMIHAN｜تراز

Open-source Persian typography, design and review skills. Persian/English host descriptions and the official L&Co. LLC logo are included. v0.1.0, Apache-2.0, free worldwide.

Human-facing plugin display name: **KUMIHAN｜تراز** only. The internal host slug is kumihan-fa; ZIP filenames include v0.1.0. Four standalone skills: kumihan-fa, kumihan-fa-web, kumihan-fa-documents and kumihan-fa-review.

Persian-specific typography: preserve original ZWNJ, Persian Kaf and Yeh, ezafe, mixed-direction identifiers, numeric/calendar integrity and content-specific visual decisions. Includes web, documents, graphics and read-only reviews. fa-IR primary; fa-AF requires a separately validated editorial policy.

Installation: INSTALL.md. Research: https://drive.google.com/file/d/1TGDbVOHr7q7oZAsEQxYsu-VivMXTYEEG/view . Landing: https://landco-llc.github.io/kumihan/kumihan-fa.html .

Provider-host installation, native rendering and native Persian editorial proofreading need independent verification. Static tests alone are not host proof.
