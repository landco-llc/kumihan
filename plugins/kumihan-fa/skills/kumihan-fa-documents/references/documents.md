# Persian documents, slides, print and graphics

Select medium, paper/display size, audience and practical reading distance before typography. Preserve an editable Unicode text source even if a logo or display heading is outlined. Use a shaping-capable Arabic-script engine; configure complex-script font, RTL paragraph, Bidi and editable logical source independently from visual alignment.

Office: verify actual Word/PowerPoint host paragraph direction and export. Adobe: verify World-Ready shaping settings supported by chosen version. Print: check joining, dots, marks and minimum sizes at physical output dimensions. Do not mirror photos, maps or code to simulate RTL.

A PDF is accepted only when both visual rendering and source round-trip work: dots/marks/joins, fonts, reading order, search, select and copy preserve logical order and ZWNJ. If text extraction loses a half-space, preserve MD/JSON as source truth and mark PDF copy as failed or needs-review. Native-language editing and commercial print proof remain independent tests.
