# KUMIHAN｜Grafía

Composición tipográfica y diseño editorial en español, con protección del original. | Spanish typography and editorial-design guidance with source preservation.

Version 0.1.0 · Apache-2.0 · L&Co. LLC

Four independent Skills: `kumihan-grafia`, `kumihan-grafia-web`, `kumihan-grafia-documents`, `kumihan-grafia-review`. Each folder includes its own rules, public sources, profiles, schema, references and offline helper. No Japanese or other language installation is required.

48 catalog records provide bounded guidance; five static patterns produce review candidates. They do not certify Spanish correctness, glyph coverage, WCAG, Office/PDF or native host support. Original research's 60 case identifiers remain not-checked; synthetic tests and actual site observations are separate.
