# Русская типографика / Russian type

- Style candidates: outer quotes «…», inner „…“; do not rewrite code/foreign quotation/approved house style.
- Hyphen (-), em dash (—), en dash (–) and minus (−) are different functions.
- A short preposition may stay with the following word; particles can bind backward. No global NBSP insertion.
- Russian hyphenation requires valid `lang="ru"`, browser dictionary and actual rendered verification; never assume `hyphens:auto` works by itself.
- Preserve numeric source and select locale, currency and timezone independently. Count-dependent plural forms and ordinal endings require syntax/context.
- For fonts test Cyrillic repertoire, true italics, stress marks, fallback and PDF extraction. Avoid mechanically repeated cards and gratuitous AI visual effects. Decide typography from purpose.
