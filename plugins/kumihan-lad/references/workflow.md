# Workflow / Порядок

1. Identify task, audience, intended medium, editing authorization, protected spans, explicit locale/house style.
2. Read rule catalog (48), relevant references and original content.
3. Design a brand-specific typographic hierarchy; align line breaks with meaning, protect names and data, avoid generic AI styling.
4. The static checker supplies advisory candidates only, never automatic fixes.
5. Validate changed content against protected spans; record diffs and actual rendered observations separately.
6. Report findings, evidence class, exceptions, `needs-review` and `not-checked` honestly.
