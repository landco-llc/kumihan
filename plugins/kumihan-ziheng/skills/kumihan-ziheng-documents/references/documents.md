# 文件、簡報與 PDF

選 [報告](../profiles/report-document.json) 或 [簡報](../profiles/presentation.json)，並記錄已明示地域（TW/HK／未定／MO）、字型可用性、原生格式與匯出格式。依 [共通流程](workflow.md) 記錄目的、權限及保護欄位。

確認每頁／每張的標題層級、圖表說明、註解、頁碼、閱讀順序、對比、溢出與可編輯性。簡報密度過高時，先調整資訊結構；不要刪除原稿或縮字來假裝通過。

匯出後另開結果檢查文字、地區字形、特殊 Unicode、超連結與裁切。文字擷取只有在工具能完整且精確擷取時才適合逐 byte 比較；擷取缺漏不能證明內容被保存，也不能直接斷定來源有錯。PDF 視覺檢查不等於 DOCX/PPTX 的原生編輯驗收。

直排、注音／ruby、複雜分頁與跨應用程式的字型替換僅提供指引。本套件沒有 Office/PDF renderer 或轉檔服務。使用者環境不支援時明示 `unsupported`；尚未執行時標記 `not-checked`。

依 [表現與用途別尺度](expression-and-scale.md) 區分投影、分享、報告與題字；數值為比較起點。地域不明可繼續原稿保護及資訊結構工作。

直排逐段選擇方向、混植、注音與語意標記，參見 [直排布局](vertical-layout.md)。記錄實際 [字型實例](vertical-fonts.md)，原生應用的開啟／編輯／儲存／重新開啟與PDF的搜尋／複製／讀序分開留證；native-application不等於native-proofreading。
