# 地區、語體與編輯工作

先沿用專案已有的 metadata，只確認會影響結果的缺項。`content_locale`（內容語言）、`editorial_region`（TW/HK/MO/unknown）、`register`、`editorial_style` 是不同欄位。香港讀者不代表必須改寫為書面粵語；繁體字也不能證明臺灣地域。`zh-Hant` 可保留未定地域，MO 保留 MO，只繼續中立工作；澳門機構名稱與中葡對照須另查。本版沒有澳門完整語彙或地域字形驗收。[ZR-H04/H17/H19、ZR-T15/T16，見來源台帳]

## 語體與資訊順序

現代標準書面中文適合一般說明；臺灣華語口語需依說話者、對象與語境調整，不是大量附加語助詞。書面粵語是另一種寫作選擇，須安排熟悉該媒體的香港校閱。歷史會話語料不能證明當代 SNS 詞頻。文言式短句、對偶和四字句可服務題字，但不是繁體中文的必要形式。[ZR-H16/H17/H18/H21]

製作時依讀者的行動排列：主題 → 對象與條件 → 步驟 → 下一個行動。每段負責一件事；說明、注意、不同步驟可分段。香港公文的段首空兩字是指定公文體例，不能自動套在 Web 卡片或表單。功能頁的標題先提示內容，例如「預約所需資料」；表現性主標可搭配具體副標。CTA 要對應實際結果：`查看可預約時段` 不等於 `確認預約`，只有下載確定的檔案才寫 `下載活動簡章`。

## 自作的對照草案（非實際活動）

固定事實：週六讀書活動、每節四十分鐘、需先預約、填寫時段與聯絡資料、完成後寄確認通知。

| 用途 | 草案與採用條件 |
|---|---|
| TW 說明 | 週六讀書活動每場四十分鐘。請先選擇時段並填寫聯絡資料；完成預約後，我們會寄送確認信。 |
| HK 標準書面中文 | 周六閱讀活動每節四十分鐘。請先選擇時段並填寫聯絡資料；完成預約後，我們會以電郵確認。 |
| TW 口語比較 | 週六有讀書活動，一場四十分鐘。先選好時段、填寫聯絡資料，我們就會寄確認信。這是語體試稿，須依說話者調整。 |
| HK 書面粵語比較 | 周六有閱讀活動，每節四十分鐘。請先揀時段同填聯絡資料；完成預約後會寄確認電郵。此為未經母語校閱的比較草稿，不是香港標準範文。 |
| display + reading | 題字「翻開一頁，留一刻。」搭配完整的條件說明與 CTA；題字不能取代日期、時間與預約條件。 |

以上是獲准新寫時的候選。固定原稿不可直接替換為這些草案。提出改稿時保留原版、差異、理由及採用範圍；approved-revision 也不代表可重寫其他段落。

## 語彙不是一對一替換器

Apple 同一說明文章的 TW/HK 版本採用印表機／打印機、軟體／軟件、網路／網絡、隱私權／私隱等詞；兩版亦有共用「按一下」「列印」。這是產品語境中的採用實例，不能把每個「提示」改成「貼士」。詞表應記錄地域、領域、產品正式 UI 名稱、例句、來源與品牌體例，再校閱整句與實際操作對象。[ZR-H22/H23]

## 標點、引號與原稿權限

`請備妥姓名、電話和電子郵件，再選擇時段。` 中「、」列舉項目，「，」分開後續動作；`平日開放預約；假日另有活動。` 使用分號區分相關分句。這是自作示例，不能全域把 ASCII 或日文頓號替換為另一符號。[ZR-H09]

臺灣教育部的「」外層與『』內層可作新寫正文的起點，出版社與原樣引用另依指定體例。香港公文可見 “ ” 與 ‘ ’，也提到直角引號；不能升格成全香港唯一規格。v2 未選體例時不推定引號，v1 helper 的 TW 既定建議保持相容。三種選項 corner/curly/preserve 只是靜態候選的有限設定；引用層次、語法、句義和例外仍須人讀。[ZR-H09/H21]
