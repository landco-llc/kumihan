## 文字、字形與歷史

文字、code point、glyph、書體與字型資源要分開。相同 code point 可由不同地域字形顯示；`lang` 和 font-family 宣告不是實際 glyph 的證明。[ZR-H04] 六書是結構與使用的分類，不是六個連續考古時期；漢字也包含形聲和假借的音義關係。[ZR-H02/H26] 現存成熟甲骨資料不是文字發明的瞬間。[ZR-H01]

篆、隸、草、行、楷有並存、過渡與復古；題字引用古字時記錄字、年代、資料和此次解釋，不把現代字型變形稱作出土字形。[ZR-H03] 宋／明名稱、刻版書風、近代字模與數位字型是不同歷史層；臺灣活版史包含不同技術來源，不代表現代日文字型自動適合臺灣。[ZR-H10/H11/H15] 選明體看橫豎對比與字面，黑體看畫線與空間，楷體看運筆和用途；不能只憑名稱保證讀性或文化印象。

臺灣標準字體與香港參考字形各有用途，不能把教育細部標準泛化為所有印刷字設計。正體不是「筆畫最多」，舊字形標籤也不是唯一規格。人名、引用和原字序列先保全，再依指定體系校閱。[ZR-H05/H06] 注音需處理基底對應、聲調與直橫位置；輕聲點的位置不能當普通縮小橫文，且不是每個臺灣案都需要注音。[ZR-H08]
