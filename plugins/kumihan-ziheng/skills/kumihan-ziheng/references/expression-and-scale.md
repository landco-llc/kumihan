# 表現、角色與用途別尺度

先定義讀者要理解、比較、到場或操作什麼，再分配字級。記錄 element_role（title/prose/date/price/note/cta 等）、expression_mode、audience_and_distance、font、weight、medium、writing_mode、採用理由及驗證結果。不要從大小推定角色；大字警告可屬 reading，小型標誌可屬 display。

| mode | 設計與檢查 |
|---|---|
| reading | 優先連續閱讀、資訊搜尋、語意順序與可選取文字；測理解和查找。 |
| display | 題字的識別、印象、刻意斷行和留白；限定造形範圍並說明目的。 |
| hybrid | 題字吸引注意，本文、日期、價格、CTA 提供穩定資訊；逐元素檢查。 |

固定原稿只調整版面，不刪標點、不換異體字、不插入不可見字元、不做 NFC/NFKC 或繁簡轉換。擷取句子做題字也是編輯；需有改稿權限，保留原版。範例的錯誤外觀不授權修復內容。

## 條件式起點（獨自設計提案，非規範閾值）

| 用途 | 本文／主要資訊 | 行高起點 | 主標／本文比 | 必須比較的條件 |
|---|---|---|---|---|
| Web 長文 | 18–20 CSS px | 1.65–1.90 | 1.8–2.6 | 實際行長、放大、段落追讀 |
| 商品說明 | 16–18 CSS px | 1.55–1.80 | 1.5–2.2 | 價格、規格與 CTA 的查找 |
| 業務 UI | 16–18 CSS px | 1.40–1.65 | 1.3–1.8 | 長標籤、錯誤訊息、200% |
| UI 補助資訊 | 14–16 CSS px | 1.45–1.70 | 隨正文階層 | 補注是否實為必要條件 |
| A4 報告 | 10.5–12 pt | 1.55–1.80 | 1.6–2.1 | 100%印刷、PDF 搜尋 |
| 投影簡報 | 24–32 pt | 1.35–1.65 | 1.4–1.8 | 最後列、照明、投影實寸 |
| 螢幕分享簡報 | 18–24 pt | 1.40–1.70 | 1.5–2.0 | 分享視窗縮小後的結果 |
| 冊子正文 | 10.5–12 pt | 1.60–1.90 | 依章節 | 紙材、墨色、直排進行 |
| 手持菜單 | 14–18 pt 試作 | 1.40–1.70 | 1.5–2.0 | 手持／牆面、價格查找、照度 |
| SNS／橫幅 | 最終顯示正文相當18px試作 | 1.3–1.6 | 2–4可試 | 縮圖、裁切、實際顯示寬 |
| 海報／標示 | 依距離決定實體字高 | 依任務 | 2–5可試 | 移動速度、反射、設置高度 |
| 包裝 | 依實寸、材料與標示內容 | 依任務 | 品牌與必要資訊分設 | 曲面、箔、反白、印刷校樣 |

數值來自本次設計整理，不是臺港全體最適值；超出範圍本身不 fail，也不是 WCAG 固定最小字級。justfont 的投影24pt／分享18pt是實務建議而非規範。[ZR-Q04] 字級研究 Q01 是24名大學生在5.5吋螢幕找錯字，2倍與3倍行高的速度和主觀偏好不同；不是一般閱讀理解。Q02只確認抄錄／摘要，Q03只有會議摘要，不能導出10pt最適或繁體普遍效果。[ZR-Q01/Q02/Q03]

橫排長文可先比較桌面26–40全形字、窄幅15–22字；表格和查找頁另定。WCAG 1.4.8 的 CJK40字是 AAA 調整機制條件，不能當 AA 全文上限。320px / 18px ≈17.8字只是等寬假設估計。

CSS px不是實體像素。CSS 12pt=16px，但不能據此推定螢幕mm或投影字高。em/rem/ic各有基準；同字級不同字面、字重和 fallback 的視覺大小不等。18px×1.75=31.5px是 line-height 使用值，不證明行間空白13.5px。1080px圖縮為360px時，54px字高約18px，是幾何估計，還需最終畫面確認。[ZR-Q05/Q07]

投影／標示可用角度 2×atan(h/2D) 比較實體字高與距離；沒有「此角度所有人可讀」的合格線。會場未定就保留 not-checked。大數值可比標題大；不建立全域固定字級階層。表情、古典感、親切感需依文字、材料與品牌實證，不能直接以明體／黑體／手寫分類斷定。[ZR-D01/D05/D13/D14]
