# 文件、簡報與 PDF

選 [報告](../profiles/report-document.json) 或 [簡報](../profiles/presentation.json)，並明示臺灣／香港、字型可用性、原生格式與匯出格式。依 [共通流程](workflow.md) 記錄目的、權限及保護欄位。

確認每頁／每張的標題層級、圖表說明、註解、頁碼、閱讀順序、對比、溢出與可編輯性。簡報密度過高時，先調整資訊結構；不要刪除原稿或縮字來假裝通過。

匯出後另開結果檢查文字、地區字形、特殊 Unicode、超連結與裁切。文字擷取只有在工具能完整且精確擷取時才適合逐 byte 比較；擷取缺漏不能證明內容被保存，也不能直接斷定來源有錯。PDF 視覺檢查不等於 DOCX/PPTX 的原生編輯驗收。

直排、注音／ruby、複雜分頁與跨應用程式的字型替換僅提供指引。本套件沒有 Office/PDF renderer 或轉檔服務。使用者環境不支援時明示 `unsupported`；尚未執行時標記 `not-checked`。
