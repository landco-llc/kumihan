# KUMIHAN｜विन्यास -Vinyāsa

संस्कृतपाठस्य अक्षरविन्यासे साहाय्यम्। मूलपाठं रक्षति। | Source-preserving Sanskrit typography guidance for Devanagari and explicitly identified IAST, web, documents and read-only review.

## प्रयोगः / Use

मूलपाठं मा परिवर्तय। / Keep the original text unchanged. Choose entry, web, documents or read-only review. Explicit Sanskrit locale and script are required; Hindi is not Sanskrit. Supports sa, sa-Deva and explicitly identified sa-Latn IAST. For sa alone confirm the script. Other Sanskrit scripts and Vedic correctness need specialist review.

Four independently installable Skills include their own guidance, public source references, fixtures, checker, license and official icon. The checker only compares UTF-8 bytes and returns bounded static diagnostics. It never writes or normalizes text.

## सीमा / Limits

शुद्धता परीक्ष्या। / Check correctness with qualified readers. Native hosts, browsers, shaping, Office/PDF and assistive technology are not_checked. Suggested size ranges are contextual untested starting points. No fonts or research images are bundled.
