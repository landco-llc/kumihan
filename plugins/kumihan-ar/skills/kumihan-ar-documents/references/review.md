# Read-only review

Read target files without rewriting, normalization or invisible-character cleanup. Record pre/post hashes when using external tools. Establish language, locale and editing contract; distinguish source text, design code and rendered evidence. A candidate anti-pattern is needs-review until a real defect is observed. Native wording, dialect and semantic plural review require an Arabic reviewer and remain needs-native-review otherwise.

Report each finding with rule ID, scope, observed evidence, host, remediation, dependencies and notes. Separate static diagnostics from actual screenshots, interaction, copy and export tests. State which rules were not checked. No overall quality score, unverified render PASS, shaper, automatic Kashida, religious-text certification or dialect autocorrection is supplied.
