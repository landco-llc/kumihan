# Source and evidence contract

Preserve the exact supplied Unicode sequence and original bytes, source URL/ID and supplied metadata. Retain names, prices, punctuation, Tashkeel, Tatweel, ZWJ/ZWNJ and directional controls. Derived NFC is comparison evidence, never authorization to overwrite. Keep raw/source, derived/display and evidence separately. Confirm permitted edits and protected spans before build/refine; audit never writes target files.

Start with explicit language (Modern Standard Arabic by default only after confirmation), region, audience, medium, register, number system, currency, calendar and timezone. ar-SA/ar-AE are initial profiles; ar-EG/ar-MA are contrast profiles, not universal number recipes. fa and ur are separate languages: generic preservation checks apply; Arabic editorial validation is unsupported. Do not infer language from script.

Modes: study = examine references and report options; build = implement within approved scope; audit = read-only review; refine = propose or apply explicitly scoped changes. Never infer scope from an attached document alone.

Use status passed, failed, needs-review, not-checked, unsupported, waived or not-applicable with rule_id, scope, evidence, host, remediation, dependencies and notes. Waivers need rationale and owner. Unknown native copy remains needs-native-review; never convert an unrun research scenario into a test pass. Renderer, native host, accessibility tree and export tests need actual evidence.
