# Arabic web playbook

Set lang for language and paragraph dir for semantic direction; text-align is visual alignment only. Retain logical source order; never reverse strings to produce RTL. Use logical CSS properties and inspect nested LTR components. Isolate LTR URLs, email, version and product codes locally (bdi dir="ltr" when direction is known); use bdi/dir="auto" for unknown user text. Do not isolate every numeral blindly. Check parentheses, currency and signs using actual intended content and renderer.

Delegate BiDi, shaping and diacritics to the host engine and licensed available fonts. Do not split joining text into letter elements. Intl.Segmenter neither guarantees copy quality nor Arabic semantic hyphenation. Compare candidate fonts with real content, Tashkeel, marks, line-height, weight and fallback; no fixed pair or canned palette. Preserve intended Tatweel; never add U+0640 as automatic justification.

Review tracking, nowrap, break-all and hidden overflow as candidates; intentional chips/code labels can be exceptions. A static match is needs-review, not proof of a defect. Review focus and DOM reading order, icon orientation by meaning, field value/copy round-trip and CTA target/action. Test 320/375/768/1280 px and 200% text size with long values and visible focus; use screenshots and actual computed layout. Do not hide overflow globally to manufacture a pass.

Run `python runtime/check_source.py page.html` for bounded source-only checks. Inline HTML inheritance and inline styles only; external styles, scripts, shadow DOM, rendered ordering and native copy are not checked. Run `python runtime/check_source.py original.txt --candidate candidate.txt` for exact UTF-8 bytes. The CLI only reads supplied paths and emits JSON to stdout. Imported Python `compare` also compares supplied metadata dictionaries. Compare exact protected-span bytes separately if the rest of a document has authorized edits; whole-file equality is not a span correspondence engine.
