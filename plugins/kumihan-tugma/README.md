# KUMIHAN｜Tugma

Gabay sa pag-aayos ng tekstong Tagalog para sa web, dokumento, presentasyon at pagsusuri, na pinangangalagaan ang orihinal na teksto. | Tagalog typography guidance for web, documents, presentations and review, preserving original text.

Version **0.1.0** · L&Co. LLC · Apache-2.0.

Apat na hiwalay na Skill: entry, web, documents at review. Panatilihin ang orihinal; hiwalay ang mungkahing edit. / Four standalone Skills cover entry routing, web, documents/presentations and read-only review. Each includes its own rules, public source links, fixtures, runtime, license and official icon.

Tagalog `tl` / `tl-PH` is explicit. Filipino `fil` is a separate requested profile, not silently substituted. Coverage includes tuldik, ñ/Ñ, ₱, code-switching, names, ng/nang and din/rin review boundaries, lexical hyphens and Baybayin preservation. Baybayin transliteration requires an explicit request and specialist review.

See [INSTALL](INSTALL.md), [rules](rules/catalog.json), [public sources](sources.json), [workflow](references/workflow.md), [coverage](inventory.json) and [rights](THIRD_PARTY_NOTICES.md). The runtime checks exact UTF-8 integrity and scoped risk indicators; it does not proofread, shape fonts, render layouts or rewrite source. Native host/browser/Office/PDF and native-speaker editorial acceptance are not_checked. / Hindi pa nasusubukan ang mga native host, browser, Office/PDF at pagsusuri ng katutubong patnugot.
