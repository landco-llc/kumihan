# KUMIHAN｜Samspel

Stöd för svensk typografi på webb, i dokument och vid granskning, med originaltexten bevarad.

Swedish typography guidance for web, documents and read-only review, preserving original text.

## Svenska

Version 0.1.0 · L&Co. LLC · Apache-2.0. Fyra fristående Skills: ingång, webb, dokument och granskning. Ange sv, sv-SE eller sv-FI; svenska är inte danska eller norska. Regionen avgör inte automatiskt valuta. Original, namn, tal, citat, kod och kombinerande tecken bevaras. Omskrivning kräver uttryckligt uppdrag. Förslag redovisas separat.

Reglerna är villkorade råd, inte automatisk korrekturläsning. ÅÄÖ, sammansättningar, nattåg-avstavning, citat, regionala uttryck och tillgänglighet granskas i sitt sammanhang. Typsnitt och tredje parts bilder ingår inte. Webbläsare, Office, PDF och värdprogram är `not_checked` tills de faktiskt har provats.

## English

Version 0.1.0 · L&Co. LLC · Apache-2.0. Four independently installable Skills: entry, web, documents, review. Select sv, sv-SE or sv-FI explicitly; Swedish is distinct from Danish and Norwegian. Region does not infer currency. Preserve source bytes, names, numbers, quotations, code and combining marks. Rewriting requires an explicit request; return proposals separately.

Guidance is conditional, not automatic proofreading. Review ÅÄÖ, compounds, nattåg hyphenation, quotes, regional wording and accessibility in context. No fonts or third-party images are bundled. Native browsers, Office, PDF and host invocation remain `not_checked` until exercised.
