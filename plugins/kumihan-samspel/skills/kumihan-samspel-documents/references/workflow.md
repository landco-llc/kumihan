# KUMIHAN｜Samspel

1. Fastställ medium, målgrupp, region och texttillstånd. / Establish medium, audience, region and text permissions.
2. Bevara originalets byte, namn, tal, citat och kod. / Preserve exact bytes, names, numbers, quotations and code.
3. Välj relevant regel efter villkor, undantag och medium. / Choose guidance by condition, exceptions and medium.
4. Skilj löptext, reklam och UI; bedöm sv-FI utan att ersätta med sv-SE. / Separate prose, advertising and UI; do not replace sv-FI with sv-SE.
5. Rapportera regel-ID, källa och belägg. Förslag kräver tillstånd. / Report rule ID, source and evidence; suggestions require permission.
6. Ange vad som inte körts. / Record unrun checks. Native fonts, browsers, Office, PDF, screen readers and host installation remain not_checked until actually exercised.

Sizing proposals need real font/version, viewport or paper size, audience, viewing distance, and root size for rem. Preserve meaningful punctuation in display copy and accessibility information in readable text. Never rank a Swedish brand’s design scale as a national norm.
