# Workflow / Quy trình

Modes: study (research only); build (new content); audit (read-only review); refine (authorized limited edits). Before doing anything record language vi/vi-VN, medium, brief, house style, source origin and protected spans. Review existing brand design if available. Use 36 Vietnamese rules as decision aids, not automated replacement instructions. Protect text exactly as provided. Never substitute fonts, body copy, prices, facts or diacritics silently. Prioritize typographic integrity and meaningful information hierarchy; avoid stock AI gradients, generic cards and uniform rounded-block layouts when they serve no communicative purpose. For CSS/HTML output set lang=vi, choose font with verified Vietnamese glyph coverage and keep word-break:normal for running text; audit at narrow and zoomed widths. Treat actual render and native review as separate checks.
