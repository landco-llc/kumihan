# Vietnamese Web / Web tiếng Việt

Start from user-provided site structure and current UI, not from generic AI templates. For running text: word-break:normal; overflow-wrap:normal; hyphens:manual until language-specific dictionary/render behavior is verified. Only break long identifiers/URLs locally with overflow-wrap:anywhere. Headings: review semantic groups, person names and brand phrases manually; don't force nowrap across all syllables. Test Vietnamese uppercase and combined diacritics at 320px and 200% font zoom, system font fallback, bold/italic and line-height. Text must reflow rather than clip. No automatic accent-removal, new claims or invented calls to action. Audit CSS and actual browser rendering separately. Responsive screenshots alone do not prove all reader contexts.
