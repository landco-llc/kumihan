# KUMIHAN｜Nhịp Chữ

Bộ kỹ năng mã nguồn mở hỗ trợ thiết kế chữ tiếng Việt cho web, tài liệu và bản trình bày; giữ nguyên nội dung gốc và rà soát mà không sửa tệp.

Open-source skills for Vietnamese typography in websites, documents and presentations; preserve source text and support read-only review.

Use only the four skills under `skills/`: `kumihan-nhip-chu`, `kumihan-nhip-chu-web`, `kumihan-nhip-chu-documents`, `kumihan-nhip-chu-review`. Identify locale vi-VN, medium and permission scope before acting. Audit mode is read-only. All diacritics, canonical forms, prices, names, protected spans and supplied words must remain unchanged unless a separate explicit edit is authorized. Do not confuse typography recommendations with grammar correction or native linguistic verification.
