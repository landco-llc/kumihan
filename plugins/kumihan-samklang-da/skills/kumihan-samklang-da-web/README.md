Dansk typografisk vejledning til web, dokumenter og gennemgang med bevaring af originalteksten. | Danish typography guidance for web, documents and review while preserving the original text.

Fire selvstændige Skills: entry, web, documents, review. Vælg dansk eksplicit; norsk er en anden udgave. / Four independently installable Skills; select Danish explicitly. Norwegian is a separate edition.
