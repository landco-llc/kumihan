## Included capabilities

Four independent skills cover entry/scoping, web/UI, documents/presentations and read-only review. Each includes its own 32-rule advisory catalog, locale and medium profiles, source checker, fixtures, report schema, license and official PNG. Supported explicit contexts: el, el-GR, el-CY. Language and script are separate; original text, marks, controls, names, quantities and IDs stay intact.

The optional Python checker performs bounded UTF-8 byte comparisons and static diagnostics. Its guidance is not a spelling correction, locale case-mapping engine, formatter, renderer or native proofreader. Jawi, if requested, remains guarded preservation/guidance with shaping and real-text review unverified.

## Evidence and next checks

`guidance-only` identifies catalog advice; `needs-review` identifies a contextual question; `not-checked` identifies an unrun host or output test. Exact source comparison is a separate `passed`/`failed` result. Browser/Office/PDF rendering, font/glyph coverage, screen readers, native language proofreading and GPT/Codex/Claude/Gemini invocation are **NOT_CHECKED**. Test each in the target environment using [web](references/web.md) or [document](references/documents.md) checks before making those claims.
