# Web guidance / Guía web
- HTML lang=fr and locale-dependent language spans; context-specific nonbreaking spaces and quotes.
- Review widths, long URLs, fonts, zoom, hyphenation dictionaries, keyboard navigation and copied DOM text in browsers.
- Avoid blanket overflow-wrap:anywhere and unmotivated symmetric cards.
- Preserve source text exactly; CSS/layout modifications are distinct from editorial rewrites.
- Static results do not certify WCAG or rendered line breaks.
