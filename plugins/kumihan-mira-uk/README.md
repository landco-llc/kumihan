# KUMIHAN｜Міра

Поради з української типографіки для вебсторінок, документів і перевірки зі збереженням оригіналу.
Ukrainian typography guidance for web pages, documents and source-preserving review.

v0.1.0 · uk / uk-UA · L&Co. LLC · Apache-2.0

Чотири незалежні навички: вступ, веб, документи, перевірка. Оригінал зберігається; пропозиції подаються окремо.
Four independently installable Skills: entry, web, documents and review. Explicit Ukrainian locale, original text preservation and separate suggestions. No MCP or external service is needed.

24 conditional rules cite public sources and cover Ukrainian Cyrillic, apostrophes, combining accents, historical quotations, mixed-script names, typography, locale formatting and access. This is guidance and bounded static diagnostics, not a dictionary, renderer or compliance certificate. Native hosts, expert proofreading and Office/PDF rendering are not-checked.
