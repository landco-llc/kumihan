# Evidence baseline
- W3C: https://www.w3.org/TR/beng-lreq/ and https://www.w3.org/International/ilreq/bengali/
- Unicode Bengali chapter: https://www.unicode.org/versions/Unicode17.0.0/core-spec/chapter-12/
- Previous internal research: KUMIHAN project Drive RESEARCH/BN, report 2026-10-19 and its source register (not bundled for redistribution).
- Font evaluation candidates: Noto Sans Bengali, Noto Serif Bengali, Hind Siliguri, Tiro Bangla, Anek Bangla. Check their current license and actual host glyph coverage before redistribution.

Research-derived rule severity is a product proposal. It is not a W3C/Unicode certification.
