# KUMIHAN｜অক্ষরসজ্জা

**Version:** v0.1.0 · **Developer:** L&Co. LLC · **License:** Apache-2.0

বাংলা অক্ষরবিন্যাস ও উদ্দেশ্যভিত্তিক ডিজাইনের জন্য উন্মুক্ত AI দক্ষতা; মূল লেখা অক্ষত রাখুন এবং প্রমাণসহ যাচাই করুন। | Open-source AI skills for Bangla typography and purposeful design; preserve source text and review with evidence.

A standalone, free and open-source Bangla typography and design package for AI-assisted web, UI, editorial, reports, slides and read-only review. It preserves approved source content while reducing context-free, repetitive AI design.

The four independent skills are `kumihan-bn`, `kumihan-bn-web`, `kumihan-bn-documents`, `kumihan-bn-review`. Each contains its own rules, references, locale profiles, fixtures, offline static checker and official logo. The full directory has Claude plugin metadata, Gemini CLI extension metadata and compatible plugin interface metadata. Plugin and skill ZIPs are different formats; attaching a ZIP to a chat does not install it.

Start with `INSTALL.md`. Research baseline: KUMIHAN BN Research (19 October 2026) in project Drive `RESEARCH/BN`. Bengali script is not a substitute for a native Bangla editor. The Bengali layout draft is not a formal conformance standard. Report what was actually tested.
