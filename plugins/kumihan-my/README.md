မြန်မာစာ မူရင်း၊ နာမည်များနှင့် ကိန်းဂဏန်းများကို ထိန်းသိမ်းပါ။ Unicode/Zawgyi ကို ခွင့်ပြုချက်မရှိဘဲ မပြောင်းပါနှင့်။
Preserve original text, names and numbers. Unicode and Zawgyi are not interchangeable font styles; no silent conversion is performed.

Four independent Skills: entry, web, documents and read-only review. Select explicit my or my-MM; other languages using Myanmar script are outside this edition. Each Skill contains its own catalog, locale, fixtures, runtime, public references, rights and official icon. See [installation](INSTALL.md) and [workflow](references/workflow.md).

20 conditional rules cover shaping-cluster integrity, phrase-aware wrapping, punctuation/digits, register, responsive hierarchy, display versus reading roles, fonts and accessibility. Numeric examples are contextual prototype comparisons. Static diagnostics cannot certify spelling, Zawgyi detection, shaping, readability or native-host rendering; these remain not_checked.
