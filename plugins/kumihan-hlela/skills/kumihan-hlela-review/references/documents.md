# isiZulu documents / Amadokhumenti

Design headings, columns, long words, type scale and visual hierarchy according to newspaper, teaching, report, slides or poster media. Preserve concords, numeric prefixes, place names and foreign names; advise but do not auto-correct. Review font embedding, manual approved line breaks, PDF extracted text, final page crops and figure reading order. Externally published examples are design references, not spelling dictionaries.
