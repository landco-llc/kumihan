Open-source Khmer typography and purposeful design guidance for web, documents and graphics. It preserves source text, protects conjuncts and records what has not been verified.

**v0.1.0 · L&Co. LLC · Apache-2.0 · Free / Open Source.**

Four standalone agent skills: `kumihan-lumnung`, `kumihan-lumnung-web`, `kumihan-lumnung-documents`, `kumihan-lumnung-review`. Thirty research-backed advisory rules (KM-01..KM-30), 24 acceptance scenarios, a read-only UTF-8 preservation checker, 15 deterministic host ZIP distributions. Plugins for Claude Code, Gemini CLI and ChatGPT/Codex.

Visible edition name: **KUMIHAN｜លំនឹង**. ASCII slugs are only technical file/package identifiers. The production modules do not auto-correct Khmer text.
