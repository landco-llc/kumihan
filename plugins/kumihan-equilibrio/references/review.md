# Revisione in sola lettura / Read-only review
Never write, normalize, replace, translate or save changes to the target, even when a candidate is supplied. Compare original and candidate bytes; report differences and optional proposals in a separate report. Use the local catalog and source registry; rule registration does not mean detection. Record rule_id, reference, scope, before, after_proposal, edits_authorized=false, status, test_method and observed_environment. Context-dependent grammar is needs-review. Unmeasured rendering, dictionaries and assistive technology stay not-checked.

The offline helper only compares exact UTF-8 bytes and flags bounded CSS patterns for manual review (R21). It does not diagnose spelling, quote consistency, hyphenation, meaning or native host import. Review all source-protection counterexamples before suggesting edits. Do not classify apostrophe wrapping, legitimate quote styles, foreign spelling or brand typography as automatic errors.
