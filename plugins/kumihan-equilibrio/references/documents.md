# Documenti e presentazioni / Documents and presentations
Choose report-document, presentation or display-copy. Apply R22–R30 and the context/protection workflow. Set document language and verified hyphenation dictionary independently of locale. Use paragraph/character styles, hierarchy, stable figure captions, repeating table headings and source notes. Keep headings with following paragraphs and inspect orphan lines/page breaks. Do not delete words, reduce data precision or shrink all slide text to fit. Separate a slide's principal claim from supporting explanation through authorized structure.

Inspect accents, bold/italic, font substitution, reading order and copy/search in the actual Office/PDF export. Font web use, embedding and redistribution are distinct rights; no external font is bundled here. Use tabular figures only when supported by the chosen font. Format typed values only with explicit locale, currency, precision and time zone; never infer a date or numeric type from a string. Native Office/PDF rendering remains not-checked without that environment.
