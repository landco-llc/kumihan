# Documents, presentations and display copy

Select document, slide, print or display intent before proposing hierarchy. Preserve all original names, numbers, quotations, Unicode marks and logical text order. Choose size and line spacing using actual fonts, readers, viewing distance, content role and available area; there is no universal language-specific pixel size.

For documents, inspect the actual Word/publishing engine and reopen the saved file. For slides, inspect every slide at presentation scale and ensure essential labels and conditions remain readable. For PDF, compare visual output separately from Unicode extraction/copy, links, font embedding and reading order. A screenshot, a successful export command or source XML alone cannot substitute for those checks.

Display lettering and logos may have approved graphic exceptions; keep them localized and preserve official identity. Record actual font license, version and hashes before embedding or distributing files. No fonts or external specimen graphics are bundled with this product.

Use [language catalog](../rules/catalog.json) and [workflow](workflow.md); retain unsupported host acceptance as `not-checked`.
