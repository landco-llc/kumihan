# KUMIHAN｜Szyk
**Polski:** Otwarte umiejętności polskiej typografii i projektowania z AI.
**English:** Open-source Polish typography, content design and source-preserving review.

v0.1.0 · Apache-2.0 · L&Co. LLC

Four independent skills: kumihan-szyk, kumihan-szyk-web, kumihan-szyk-documents, kumihan-szyk-review. Packages for GPT/Codex, Claude Code and Gemini CLI, each with skill ZIPs. All 40 research rules and 64 proposed cases are included; automatic review is bounded, read-only and is not a full spelling engine.

Website: https://landco-llc.github.io/kumihan/kumihan-pl.html
