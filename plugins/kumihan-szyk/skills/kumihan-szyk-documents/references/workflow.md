# Workflow / Proces
PL: Ustal tryb (tworzenie, autoryzowana korekta, przegląd), język i medium. Zapisany oryginał, nazwy, cyfry, kod, URL i cytaty pozostają niezmienione bez osobnej zgody. Dobieraj rytm, siatkę, typografię i odstępy do znaczenia tekstu oraz potrzeb odbiorcy. Nie narzucaj wyglądu typowego dla AI.
EN: Determine scope, audience, format and source permissions. Distinguish normative RJP rules, CLDR locale, GUM SI, house-style advice and visual suggestions. Never treat a research fixture as an executed result. Change only authorized content/presentation and return a reviewable diff.
