# Web and UI

Declare actual content language and independently select known paragraph direction. Preserve original DOM text and semantic order; localize only explicitly supplied values under an agreed formatting contract. Scope markup or layout suggestions to the requested component. Review labels, error recovery, complete amounts/URLs, mixed-script spans, long words, fixed heights and font fallback.

Inspect actual browser output at the required narrow width, real text resize/zoom and applicable user text-spacing changes. Check keyboard and assistive-technology order separately. Static HTML parsing sees inherited attributes and inline styles only; it does not resolve CSS, scripts, layout, glyphs or an accessibility tree. A CSS.supports response does not establish a working language hyphenation dictionary.

Use [language catalog](../rules/catalog.json) and [workflow](workflow.md). Never change spelling, numbers or source line breaks simply to make a layout fit.
