# KUMIHAN｜अक्षर-संगति

हिंदी अक्षर-विन्यास और डिज़ाइन में सहायता; मूल पाठ सुरक्षित रखें। | Hindi typography and design guidance with source preservation.

निःशुल्क · खुला स्रोत · v0.1.0 · Apache-2.0 · L&Co. LLC
Free and public worldwide. Four standalone Skills for modern Hindi/Devanagari: entry, web, documents and read-only review. 24 traceable rules, 24 QA cases, six profiles and offline source comparison. See INSTALL.md, references/ and sources.json.

Source preservation is the default. Hindi ≠ Devanagari ≠ India. No automatic rewriting, punctuation/digit conversion or full Hindi grammar correction. New Hindi copy is a draft without native-speaker approval.

ChatGPT/Codex portable/local plugin, Claude Code plugin and Gemini CLI extension are packaged separately with 12 standalone host-labelled Skill ZIPs (15 total). A packaged descriptor is not evidence of actual host installation. Claude/Gemini machine IDs remain ASCII; public identity appears in Skill/context documentation where their schemas do not offer display names. No public marketplace submission or provider approval is claimed.

Rendering, mobile devices, Office, IME and screen readers require operation-specific evidence. See docs/hi in the repository for actual product verification and limitations. Research observations are not product PASS.
