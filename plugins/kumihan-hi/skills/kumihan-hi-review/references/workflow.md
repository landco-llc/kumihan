# हिंदी कार्यप्रवाह | Hindi workflow

Record language, script, locale, market, medium, reader, purpose, profile, task mode and content policy. Hindi ≠ Devanagari ≠ India. Default hi-IN/Deva is a scoped assumption, not language detection. Do not absorb Marathi, Nepali or Sanskrit.

Task modes: study / build / audit / refine. Content policy: preserve (default) / propose / rewrite (explicit scope only). build/refine does not permit changes to supplied wording. audit is read-only even if rewrite also appears; report the conflict. Keep source bytes, invisible characters, numbers, proper nouns, URLs and tokens. NFC is for derived comparison/search only.

Read rules/catalog.json, sources.json, locales/hi-IN.json, profiles/profiles.json and fixtures/qa.json within THIS package. All four standalone Skills contain the same reference set; siblings and runtime downloads are unnecessary. The optional Python 3.12 stdlib checker is read-only, not a shaper, Hindi grammar engine, normalizer or segmentation implementation.

Sources distinguish specifications from drafts and product-specific style guides. Research source index was accessed 2026-10-19 JST; research observations date 2026-10-18 UTC and are not product tests. Preserve source IDs and source versions; do not claim all cited specifications have been re-tested in this runtime.

Report location, rule_id, observation, impact, severity (source corruption / environment defect / editorial choice), recommendation, evidence_kind, environment and unresolved limitations. Evidence kinds: static / rendered / operation / research / editorial / NOT_CHECKED. Keep remediation proposals separate from the original. Native fluency, Office, IME and screen-reader checks require actual evidence.
