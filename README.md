# KUMIHAN

**Japanese typography for thoughtful AI-assisted design.**  
**日本語の文字組みから、AIのデザインをもっと自然に。**

## About KUMIHAN

KUMIHAN is an open-source project developing skills to help AI create and review Japanese websites, articles, documents, and presentations. It brings Japanese typography and clear information design together, encouraging layouts that suit the content rather than relying on repetitive templates.

Our focus is on readable line breaks, punctuation and spacing, Japanese–Latin text, balanced layouts, and preserving the meaning of the original content.

## KUMIHANについて

KUMIHANは、AIによる日本語のWebサイト・記事・文書・プレゼンテーション資料の制作とレビューを支援するオープンソースプロジェクトです。

日本語の改行や禁則、約物、和欧混植、文字と余白のバランスを大切にしながら、**読みやすく、伝わりやすいデザイン**を目指します。決まりきったテンプレートに頼らず、内容と目的にふさわしい構成を考えることを重視しています。

## What to expect / 目指していること

- **Better Japanese typography / 読みやすい文字組み** — Thoughtful line breaks, spacing and type choices.
- **Purposeful design / 内容に合ったデザイン** — Clear information hierarchy and layouts suited to each project.
- **Content integrity / 原稿を大切に** — Careful handling of names, numbers and original text.
- **Practical review / 制作後の見直し** — Guidance for checking readability and layout.

**Status / 開発状況:** v0.1 is in development. Installation instructions will be provided when the first version is ready.  
v0.1を開発中です。初版の公開時に導入・利用方法を案内します。
