# Conditional task recipes

| Reader task | Comparison start | Observe | Does not establish |
| --- | --- | --- | --- |
| Sustained Web reading | 16px or 18px, 30–40 characters, ordinary spacing | Actual font, width, line ends, overrides and reflow | Universal minimum or optimum |
| UI operation | Full label, wrapping, ordinary spacing | Focus, activation, narrow width, user enlargement | All native host behavior |
| A4 report | 11.5pt / 18pt leading as one comparison | All pages, notes, tables, print scale | Native Office from PDF preview |
| Projection | 24pt as one comparison | Smallest required role, projected dimensions, farthest seat | Readability from pt alone |
| Display / hybrid | Ordinary spacing then optional palt variant | Whole composition and complete required-information map | Blanket exception for artwork |
| Values and labels | Emphasize the value when task requires it | Association and scan-find performance | Error just because value exceeds title size |

Use [context](typography-context.md) and [writing/type knowledge](japanese-writing-and-type.md). Values are provisional authoring comparisons, not new rules. Preserve original source throughout. No automatic beauty, meaning-break or AI-origin score is supplied.
