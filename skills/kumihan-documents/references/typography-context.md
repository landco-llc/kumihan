# Typography context and scoped evidence

Use a short brief, extended only when useful: region, role (title/body/label/value/note/mandatory-info/artwork), readingTask (read/find/operate/compare), intent with declared / inferred / unknown attribution, and expressionMode prose / display / hybrid. Spoken/written register is a separate axis. Unknown intent remains unknown; display intent grants no exception or editing permission.

## Required information

Map each protected source field to its exact Unicode text, required usage and presentation region. Classify each relation as exact-repeat / authorized-derived / decorative-echo. Derived text requires actual authorization. Check every occurrence for contradictions, visibility and reachability in the intended state. Hidden DOM, inaccessible QR destinations and speaker notes are not automatically usable substitutes. Decorative cropping can coexist with complete information elsewhere; evaluate the local artwork separately from the whole artifact.

## Evidence contract

Use existing report scope, reason, evidence_refs and limitations for static / rendered / assisted / manual observations. Do not add unknown report properties. Static equality may pass while visibility fails or glyphs remain not-checked. CSS.supports, a family name, DOM presence, PDF extraction and schema validity prove only their own narrow observations. Never promote them into rendered, native or physical acceptance.

Record input digest, region, source fields, font/renderer/version, dimensions, state and actual method. CSS size simulation is not native text zoom. PDF preview is not native Office. Unattempted checks are not-checked; confirmed tool incompatibility is unsupported. N/A requires an actual inapplicable scope. Negative fixtures remain failed artifacts even when their regression test succeeds.

Optional research packets in experimental/ are independent drafts, not extensions of the frozen report schema. See task recipes and research-claims.json for source limits.
