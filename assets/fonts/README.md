# Site web fonts (assets/fonts/google)

Copies of the Google Fonts stylesheets and WOFF2 files the site uses, made by
`tools/fetch_fonts.py` so pages load fonts from this site instead of Google.
Unmodified files from Google Fonts; each family is under the SIL Open Font
License 1.1 (`google/licenses/<family>.txt`). Re-run `python tools/fetch_fonts.py`
after changing a family, an axis or the name characters in `tools/web_fonts.py`.
