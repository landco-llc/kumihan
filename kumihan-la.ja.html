01 / THE IDEA

「見た目をそろえる」より
「伝わる形を考える」

目的も読み手も違うのに、同じ構成を繰り返さない。文章の意味や情報の優先順位を踏まえて、文字組み・余白・レイアウトを考える。KUMIHAN｜Concinnitasは、デザインを画一化するためではなく、一つひとつの制作物をよりよくするための指針を提供します。ラテン語では、まずその文章が続けて読むものか、注を見ながら学ぶものか、声に出して読むものか、題字や標語として見せるものかを見極めます。

02 / WHAT MATTERS

伝えるための4つの視点

制作と見直しに共通する、KUMIHAN｜Concinnitasが大切にする考え方。

01 / TYPE
ā æ

ラテン語の文字組み

言語としてのラテン語（la）と、文字体系としてのラテン文字（Latn）は別のものです。ラテン文字で書かれた文章がすべてラテン語とは限らないため、言語と文字体系を分けて記録します。長音記号・短音記号・アクセント（ā、ĭ、á）は文字から切り離さず、字間のために文字の間へ空白を入れません。書体はファイルごとに ā、ȳ、æ、œ、ǣ の収録を確かめます。

02 / STRUCTURE
▮▮▯

内容に合う構成

伝える順番と情報の重要度を整理し、目的に合ったレイアウトを考えます。続けて読む本文、注を見ながら学ぶ本文、朗読、短い題字や標語を別の読み方として設計します。注・訳・音声は文字を小さくするだけでなく、位置と参照で本文に結び、詩の行と画面上の折り返しを区別します。

03 / FIDELITY
I/J U/V

原稿を大切に

名前・引用・数値・日時・コード・意味を守ります。I/J と U/V、ae/æ と oe/œ、長音記号やアクセント、略記、語順、-que のような後接語は底本のとおりに保ち、「中世だから e」のように時代名だけで書き換えません。原文にUnicode正規化を黙って適用することもしません（ſ、ﬁ）。略記の展開、欠損の補い、翻訳は編集にあたるため、提案として記録し、黙って書き換えません。

04 / REVIEW
◌̄

制作後の見直し

完成物の気になる点を、対象を変更せずに確認・整理するための指針です。大きさは字号ではなく小文字の高さと実測の幅で判断し（調査では、同じ文を12ptで組んだ2書体の幅に約15％の差）、狭い画面、拡大表示、ハイフネーション、PDFからの文字抽出を別々に確かめます。

DESIGNED FOR THE MESSAGE

文字を並べるだけでなく
読む体験を組み立てる

KUMIHAN｜Concinnitasは完成デザインを一律に指定しません。使う媒体や条件に合わせて考えるための知識を提供します。ラテン語に決まった見た目はなく、古代の碑文や教会だけの言語でもありません。いまもニュース、雑誌、学習アプリで読まれています。書体はファイル、版、収録文字、利用条件まで比べます。たとえばEB Garamondは1592年の活字見本に由来する復刻で、Trajanは古代碑文に由来する現代の表示用書体です。

03 / THE SKILLS

4つのスキル
ひとつの考え方

制作の入口から、Web・資料制作・レビューまで。

01 / ENTRYā æ

kumihan-concinnitas

目的・読者・媒体・読み方（散文、韻文、注釈、朗読、見せる文字）・時代と表記方針（I/J、U/V、æ、長音記号）・編集権限を先に整理します。

スキルを見る↗
02 / WEB↗

kumihan-concinnitas-web

ラテン語のWebサイト、記事、LP、UIの文字組みとデザインを支援。長音記号やアクセントに必要な行送り、長い語とハイフネーション、狭い画面も扱います。

スキルを見る↗
03 / DOCUMENTS¶

kumihan-concinnitas-documents

報告書、資料、プレゼンテーションの構成と読みやすさを支援。本文・注・訳の対応、書体の利用条件、PDFの文字抽出も扱います。

スキルを見る↗
04 / REVIEW◎

kumihan-concinnitas-review

制作物を変更せず、組版・情報・デザインの見直しを支援。

スキルを見る↗
