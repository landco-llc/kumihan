01 / 導入形式を選ぶ

プラグインには4つのスキルがすべて入っています。各スキルは、ルールと参考資料をそろえた単体でも配布しています。チャットにファイルを添付しただけでは導入されません。

02 / ダウンロードと照合

GitHub Release v0.1.0からZIPを取得し、導入前にSHA256SUMS.txtとSHA-256を照合してください。

  • プラグイン: kumihan-mizani-claude-code-plugin-v0.1.0.zip
  • 個別スキル: kumihan-mizani-claude-skill-v0.1.0.zip
  • 個別スキル: kumihan-mizani-web-claude-skill-v0.1.0.zip
  • 個別スキル: kumihan-mizani-documents-claude-skill-v0.1.0.zip
  • 個別スキル: kumihan-mizani-review-claude-skill-v0.1.0.zip

SHA256SUMS.txt · MANIFEST.json · GitHub Release v0.1.0

03 / 導入する

kumihan-mizaniフォルダを保ってClaude Codeプラグインを展開し、claude plugin validateで確認します。対応する場合はclaude --plugin-dirを使います。単独スキルは.claude/skills/へ配置できます。

claude --plugin-dir /absolute/path/kumihan-mizani
claude plugin validate /absolute/path/kumihan-mizani
/plugin marketplace add landco-llc/kumihan
/plugin install kumihan-mizani@kumihan-marketplace

04 / 原稿を変えずに試す

対象地域（sw-TZ・sw-KEなど）と媒体・文体・編集権限を指定します。依頼例：

kumihan-mizani-reviewでスワヒリ語ページを原稿変更なしで確認してください。ng’などの表記を保ち、根拠と未検証事項を区別してください。

任意の静的確認（読み取り専用）：

python runtime/checks.py input.txt --locale sw-TZ

05 / 更新

カスタマイズを保存し、新しいバージョンとチェックサムを確認してから、ツールが対応する方法で更新します。新しいコミットだけでは既存の導入は更新されません。他言語のプラグインは上書きしないでください。

06 / 対応範囲と限界

スワヒリ語の24要件と原文字列のバイト比較を収録しています。ブラウザ実表示、各サービスへの登録、公式カタログ掲載、母語校閲は未検証です。
