DOCUMENTATION / GeminiInstallation steps

01 / Installation steps

  1. Prerequisite: Gemini CLI with Extensions support. Gemini App Skills upload is NOT VERIFIED.
  2. Extract the extension ZIP into an empty folder with gemini-extension.json at its root. Run gemini extensions install /absolute/path/to/folder and review its permission prompt.
  3. Extract an individual skill ZIP into its own directory and use the CLI Skills workflow supported by your version. Do not install this monorepo root URL expecting ZiLu. App import is conditional on an actual account interface.

02 / Downloads & checksums

From downloads/, run sha256sum -c SHA256SUMS.txt (or shasum -a 256 -c on macOS). For one ZIP, compare its hash with the matching MANIFEST.json entry.
