ツールへの導入

  1. Extensions対応のGemini CLIが必要です。Gemini AppsのSkills導入は未検証です。
  2. 拡張ZIPを空フォルダに展開し、gemini-extension.jsonが直下にあることを確認します。gemini extensions install /絶対パス/フォルダを実行し、権限確認を読んでください。
  3. このモノレポのルートをGrafíaとして導入しないでください。独立Skillsは使用中CLIの導入手順に従います。Appsの利用可否はアカウントで別途確認します。

ダウンロードと照合

導入前にMANIFEST.jsonのSHA256とバイト数を照合します。Releaseの17ファイルを同じフォルダに置き、sha256sum -c SHA256SUMS.txt（macOSはshasum -a 256 -c SHA256SUMS.txt）を実行。単体ZIPは該当項目を照合してください。
