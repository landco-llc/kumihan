01 / Выбрать пакет

Четыре самостоятельных Skills и объединяющий плагин.

02 / Скачать и проверить

Скачайте архивы ZIP v0.1.0 и проверьте SHA256SUMS.txt.

  • Плагин: kumihan-lad-chatgpt-codex-plugin-v0.1.0.zip
  • Отдельный Skill: kumihan-lad-chatgpt-skill-v0.1.0.zip
  • Отдельный Skill: kumihan-lad-web-chatgpt-skill-v0.1.0.zip
  • Отдельный Skill: kumihan-lad-documents-chatgpt-skill-v0.1.0.zip
  • Отдельный Skill: kumihan-lad-review-chatgpt-skill-v0.1.0.zip

SHA256SUMS.txt · MANIFEST.json · GitHub Release v0.1.0

03 / Установить

В Codex установите Skill в .agents/skills/. Для ChatGPT требуется поддерживаемый интерфейс, а не ZIP в чате.

INSTALL.md

04 / Протестировать

Проверьте доступность четырёх Skills и сохранность текста; одна проверка JSON недостаточна.

Проверьте русскую типографику без изменения оригинала.

python runtime/checks.py original.txt --locale ru-RU

python runtime/checks.py input.txt --locale ru-RU

05 / Обновить

Проверьте новые контрольные суммы, сохраните настройки и переустановите пакет.
