DOCUMENTATION / ChatGPT / Codex절차와 주의 사항

KUMIHAN｜글짜임을 ChatGPT와 Codex에서 사용하기 위한 절차입니다.

v0.1.0 안내 직접 사용하는 환경에서 설치를 시험해 보실 수 있도록 제공하는 버전입니다. 각 도구에서의 동작은 아직 충분히 확인되지 않아 제대로 작동하지 않을 수 있습니다.

1. 설치 방법 선택

사용할 곳권장 방법
ChatGPT(스킬 업로드가 가능한 경우)A. 스킬을 하나씩 추가하기
ChatGPT(나만의 플러그인으로 등록하려는 경우)B. 플러그인으로 한 번에 등록하기
Codex(컴퓨터에서 사용하는 경우)C. 폴더 복사하기

스킬은 기능 하나이고, 플러그인은 네 가지 스킬을 하나로 묶은 패키지입니다.

2. 파일 다운로드

파일은 릴리스 페이지에 있습니다. 링크를 누르면 ZIP 파일이 다운로드됩니다.

플러그인(네 가지 스킬을 묶은 것)

  • kumihan-geuljjaim-plugin-v0.1.0.zip

스킬(개별)

  • kumihan-geuljjaim — 시작점
  • kumihan-geuljjaim-web — 웹페이지
  • kumihan-geuljjaim-documents — 보고서·슬라이드
  • kumihan-geuljjaim-review — 검토

A. ChatGPT에 스킬 추가하기

ChatGPT 화면에 'Skills'와 업로드 항목이 있는 경우에 사용할 수 있는 방법입니다.

  1. 스킬 ZIP 파일을 하나 선택해 업로드합니다.
  2. 표시된 내용을 확인하고 추가합니다.
  3. 필요한 스킬 수만큼 같은 절차를 반복합니다.

주의 사항

  • 이 방법에서는 플러그인 ZIP을 사용할 수 없습니다. 스킬 ZIP을 사용하세요.
  • 채팅에 파일을 첨부하는 것만으로는 스킬로 추가되지 않습니다.
  • 화면에서 항목이 보이지 않는다면 사용 중인 요금제나 앱에서 아직 제공되지 않을 수 있습니다. OpenAI 공식 안내를 확인하세요.

B. ChatGPT에 플러그인으로 등록하기

네 가지 스킬을 묶어 나만의 플러그인으로 등록하는 방법입니다.

  1. ChatGPT에서 새 대화를 열고 @plugin-creator를 선택합니다.
  2. 플러그인 ZIP 파일을 첨부합니다.
  3. 다음과 같이 요청합니다.

    이 패키지를 나만 사용하는 비공개 플러그인으로 등록해 주세요. 공개 디렉터리에는 제출하지 마세요.

  4. 등록되면 Plugins의 'Personal' 또는 'Created by me'에 KUMIHAN｜글짜임이 표시됩니다.
  5. 필요하면 설치한 뒤 새 대화에서 활성화합니다.

주의 사항

  • 팀 워크스페이스에 등록될 수 있습니다. 나만 사용하려면 등록하기 전에 저장 위치를 확인하세요.
  • 요금제나 워크스페이스 설정에 따라 이 기능을 사용할 수 없을 수 있습니다. 자세한 내용은 Build plugins와 Plugins를 참고하세요.
  • 이 방법으로 등록한 플러그인은 내 계정에서만 사용할 수 있으며, 공개 디렉터리에는 게시되지 않습니다.

C. Codex에 폴더 복사하기

스킬 ZIP의 압축을 풀면 kumihan-geuljjaim 등의 폴더가 생깁니다. 이 폴더를 Codex가 읽어 들이는 위치에 복사합니다.

사용 범위복사할 위치
특정 프로젝트에서만 사용프로젝트 안의 .agents/skills/
모든 프로젝트에서 사용홈 폴더의 ~/.agents/skills/

예를 들어 프로젝트에 kumihan-geuljjaim를 추가하려면 다음과 같이 합니다.

mkdir -p /path/to/your-project/.agents/skills
cp -R kumihan-geuljjaim /path/to/your-project/.agents/skills/

주의 사항

  • 폴더는 안의 내용까지 통째로 복사하세요. 일부 파일만으로는 제대로 작동하지 않습니다.
  • 같은 이름의 폴더가 이미 있다면 덮어쓰기 전에 내용을 확인하세요.

설치가 끝나면 새 대화를 열고 스킬을 호출합니다.

파일이 올바른지 확인하기(선택)

다운로드한 파일이 손상되지 않았는지 확인하려면 SHA256SUMS.txt를 사용합니다.

다운로드한 ZIP 파일과 같은 폴더에 SHA256SUMS.txt를 두고, 터미널에서 다음 명령을 실행합니다. shasum이 없는 환경에서는 Windows PowerShell의 Get-FileHash 등으로 SHA-256을 대조하세요.

shasum -a 256 -c --ignore-missing SHA256SUMS.txt

다운로드한 파일의 행에 OK가 표시되면 문제가 없습니다.
