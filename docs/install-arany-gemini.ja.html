DOCUMENTATION / Gemini手順と注意事項

KUMIHAN｜ArányをGemini CLIやGeminiアプリで使うための手順です。

v0.1.0について ご自身の環境で導入を試していただくための版です。各ツールでの動作はまだ十分に確認できていないため、うまく動かない場合があります。

1. 導入方法を選ぶ

使いたい場所おすすめの方法
Gemini CLI（4つまとめて）A. 拡張機能として導入する
Gemini CLI（必要なものだけ）B. スキルを選んで導入する
Geminiアプリ（Web・Mac・スマートフォン）C. スキルをアップロードする

A. Gemini CLI：拡張機能として導入する

4つのスキルをまとめて導入する方法です。

  1. 拡張機能のZIP (Source ZIP) をダウンロードします。
  2. ZIPを展開すると、kumihan-arany フォルダーができます。
  3. フォルダーを指定して導入します。
    gemini extensions install "/absolute/path/kumihan-arany"

確認画面が表示されたら、内容を確認して進めてください。拡張機能は、導入するとすべてのプロジェクトで有効になります。

ZIPから導入した場合は、自動では更新されません。新しい版が出たら、ZIPを入れ替えてください。

B. Gemini CLI：スキルを選んで導入する

必要なスキルだけを、プロジェクト単位で導入する方法です。Aで導入した場合、この手順は不要です。

たとえば kumihan-arany を導入する場合は、対象のプロジェクトで次を実行します。

gemini skills install https://github.com/landco-llc/kumihan --path plugins/kumihan-arany/skills/kumihan-arany --scope workspace

ほかのスキルを導入するときは、--path を次のように変えてください。

  • plugins/kumihan-arany/skills/kumihan-arany-web — Webページ
  • plugins/kumihan-arany/skills/kumihan-arany-documents — 報告書・スライド
  • plugins/kumihan-arany/skills/kumihan-arany-review — レビュー

--scope workspace は「このプロジェクトだけ」で使う設定です。省略すると、すべてのプロジェクトで使えるようになります。

更新するとき

同じコマンドをもう一度実行します。導入済みのスキルは置き換えられるため、ご自身で編集した内容がある場合は先に保存してください。

C. Geminiアプリ：スキルをアップロードする

  1. 使いたいスキルのZIPをダウンロードします。
    • kumihan-arany (Source ZIP) — 最初の入口
    • kumihan-arany-web (Source ZIP) — Webページ
    • kumihan-arany-documents (Source ZIP) — 報告書・スライド
    • kumihan-arany-review (Source ZIP) — レビュー
  2. Geminiの Customize（見当たらない場合は More）→ Skills → Upload を開きます。
  3. ZIPを1つずつ選び、内容を確認して Create を押します。

ご注意

  • 利用できるのは、18歳以上の個人のGoogleアカウントです。仕事用・学校用のアカウントでは、現在は使えません。
  • 「Keep Activity（アクティビティの保存）」をオンにしておく必要があります。
  • 機能は順次提供されているため、まだ表示されない場合があります。詳しくは Geminiの公式ヘルプ をご覧ください。
  • 拡張機能のZIP（Gemini CLI用）は、ここでは使えません。
  • アップロードしたスキルは自動では更新されません。新しい版が出たら、もう一度アップロードしてください。

2. 使ってみる

最初は、ファイルを変更しない依頼で試すのがおすすめです。

ハンガリー語のプレゼン資料をつくる予定です。気をつけるポイントを教えてください。ファイルは変更しないでください。

ファイルが正しいか確認する（任意）

ダウンロードしたファイルが壊れていないかを確認したい場合は、SHA256SUMS.txt を使います。

ダウンロードしたZIPファイルと同じフォルダーに SHA256SUMS.txt を置き、ターミナルで次のコマンドを実行します。shasum がない環境では、Windows PowerShellの Get-FileHash などでSHA-256を照合してください。

shasum -a 256 -c --ignore-missing SHA256SUMS.txt

ダウンロードしたファイルの行に OK と表示されれば問題ありません。

画面や提供条件は変わることがあります。最新の情報は各サービスの公式案内をご確認ください（本ページの確認日：2026年10月14日）。
