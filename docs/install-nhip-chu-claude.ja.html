導入ガイド

導入形式を選ぶ

プラグインは4スキルをまとめたものです。単独スキルにもルールと参考資料を同梱しています。会話へのZIP添付はインストールではありません。

  • プラグイン一式: kumihan-nhip-chu-claude-code-plugin-v0.1.0.zip
  • 単独スキル: kumihan-nhip-chu-claude-skill-v0.1.0.zip

ダウンロードと照合

GitHub Releaseから利用ホスト用のv0.1.0 ZIPをダウンロードし、SHA256SUMS.txtと照合してください。

kumihan-nhip-chu-claude-code-plugin-v0.1.0.zip

SHA256SUMS.txt · MANIFEST.json

4 Skills

  • kumihan-nhip-chu-claude-skill-v0.1.0.zip
  • kumihan-nhip-chu-web-claude-skill-v0.1.0.zip
  • kumihan-nhip-chu-documents-claude-skill-v0.1.0.zip
  • kumihan-nhip-chu-review-claude-skill-v0.1.0.zip

インストール

ZIPを展開し製品フォルダを保持したままClaude Codeで読み込みます。対応する環境ではリポジトリのマーケットプレイスから導入できます。

コマンド例

claude --plugin-dir /absolute/path/kumihan-nhip-chu
claude plugin validate /absolute/path/kumihan-nhip-chu
/plugin marketplace add landco-llc/kumihan
/plugin install kumihan-nhip-chu@kumihan-marketplace

元原稿を変更せずに確認

静的チェッカーは候補を示すだけです。フォントの実描画とAIホストでの起動は別途実行して確認してください。

KUMIHAN｜Nhịp Chữを使って、このベトナム語ページを読み取り専用でレビューしてください。声調記号と原文を保持し、実測と未検証を区別してください。

python runtime/checks.py input.txt --locale vi-VN

更新する

カスタマイズを保管し、バージョンとハッシュを確認して更新します。GitHubの更新は既存インストールには自動反映されません。

制限事項

ネイティブ校正・実機描画・全ホスト動作は未保証です。レビューでは元ファイルを変更しません。
