ขั้นตอนการใช้ KUMIHAN｜ดุลอักษร กับ Gemini CLI และแอป Gemini

เกี่ยวกับ v0.1.1 รุ่นนี้จัดทำขึ้นเพื่อให้คุณทดลองติดตั้งในสภาพแวดล้อมของคุณเอง เรายังตรวจสอบการทำงานในแต่ละเครื่องมือได้ไม่ครบถ้วน จึงอาจมีบางขั้นตอนที่ทำงานไม่ได้ตามที่คาดไว้

1. เลือกวิธีติดตั้ง

ที่ที่ต้องการใช้วิธีที่แนะนำ
Gemini CLI (ทั้ง 4 รายการพร้อมกัน)A. ติดตั้งเป็นส่วนขยาย
Gemini CLI (เฉพาะที่ต้องการ)B. เลือกติดตั้ง Skill
แอป Gemini (เว็บ Mac และสมาร์ตโฟน)C. อัปโหลด Skill

A. Gemini CLI: ติดตั้งเป็นส่วนขยาย

วิธีนี้จะติดตั้ง Skill ทั้ง 4 รายการพร้อมกัน

  1. ดาวน์โหลดไฟล์ ZIP ของส่วนขยาย
  2. เมื่อแตกไฟล์ ZIP จะได้โฟลเดอร์ kumihan-th
  3. ติดตั้งโดยระบุโฟลเดอร์
    gemini extensions install "/absolute/path/kumihan-th"

เมื่อหน้าจอยืนยันปรากฏขึ้น โปรดตรวจสอบรายละเอียดก่อนดำเนินการต่อ เมื่อติดตั้งแล้ว ส่วนขยายจะเปิดใช้งานในทุกโปรเจกต์

หากติดตั้งจาก ZIP ส่วนขยายจะไม่อัปเดตอัตโนมัติ เมื่อมีรุ่นใหม่ โปรดเปลี่ยนเป็นไฟล์ ZIP รุ่นใหม่

B. Gemini CLI: เลือกติดตั้ง Skill

วิธีนี้ใช้ติดตั้งเฉพาะ Skill ที่ต้องการเป็นรายโปรเจกต์ หากติดตั้งด้วยวิธี A แล้ว ไม่ต้องทำขั้นตอนนี้

ตัวอย่างเช่น หากต้องการติดตั้ง kumihan-th ให้รันคำสั่งต่อไปนี้ในโปรเจกต์ที่ต้องการ

gemini skills install https://github.com/landco-llc/kumihan --path plugins/kumihan-th/skills/kumihan-th --scope workspace

หากต้องการติดตั้ง Skill อื่น ให้เปลี่ยน --path ดังนี้

  • plugins/kumihan-th/skills/kumihan-th-web — หน้าเว็บ
  • plugins/kumihan-th/skills/kumihan-th-documents — รายงานและสไลด์
  • plugins/kumihan-th/skills/kumihan-th-review — การตรวจทาน

--scope workspace คือการตั้งค่าให้ใช้ได้ “เฉพาะโปรเจกต์นี้” หากไม่ระบุ Skill จะใช้ได้ในทุกโปรเจกต์

เมื่อต้องการอัปเดต

รันคำสั่งเดิมอีกครั้ง Skill ที่ติดตั้งไว้จะถูกแทนที่ หากคุณแก้ไขเนื้อหาเอง โปรดบันทึกไว้ก่อน

C. แอป Gemini: อัปโหลด Skill

  1. ดาวน์โหลดไฟล์ ZIP ของ Skill ที่ต้องการใช้
    • kumihan-th — จุดเริ่มต้น
    • kumihan-th-web — หน้าเว็บ
    • kumihan-th-documents — รายงานและสไลด์
    • kumihan-th-review — การตรวจทาน
  2. ใน Gemini ให้เปิด Customize (หากไม่พบ ให้เปิด More) → Skills → Upload
  3. เลือกไฟล์ ZIP ทีละไฟล์ ตรวจสอบรายละเอียด แล้วกด Create

ข้อควรทราบ

  • ใช้ได้กับบัญชี Google ส่วนบุคคลของผู้ที่มีอายุ 18 ปีขึ้นไป ขณะนี้ยังใช้กับบัญชีสำหรับที่ทำงานหรือสถานศึกษาไม่ได้
  • ต้องเปิด “Keep Activity (การเก็บกิจกรรม)” ไว้
  • ฟีเจอร์นี้ทยอยเปิดให้บริการ จึงอาจยังไม่แสดงในบัญชีของคุณ ดูรายละเอียดได้ที่ศูนย์ช่วยเหลืออย่างเป็นทางการของ Gemini
  • ใช้ไฟล์ ZIP ของส่วนขยาย (สำหรับ Gemini CLI) ที่นี่ไม่ได้
  • Skill ที่อัปโหลดจะไม่อัปเดตอัตโนมัติ เมื่อมีรุ่นใหม่ โปรดอัปโหลดอีกครั้ง

2. ลองใช้งาน

ในครั้งแรก เราแนะนำให้ลองด้วยคำขอที่ไม่แก้ไขไฟล์

ฉันกำลังวางแผนจะทำสไลด์นำเสนอภาษาไทย มีจุดไหนที่ควรระวังบ้าง โปรดอย่าแก้ไขไฟล์ใด ๆ

ตรวจสอบความถูกต้องของไฟล์ (ไม่บังคับ)

หากต้องการตรวจสอบว่าไฟล์ที่ดาวน์โหลดมาไม่เสียหาย ให้ใช้ SHA256SUMS.txt

วาง SHA256SUMS.txt ไว้ในโฟลเดอร์เดียวกับไฟล์ ZIP ที่ดาวน์โหลดมา แล้วรันคำสั่งต่อไปนี้ในเทอร์มินัล หากไม่มี shasum ให้ตรวจสอบค่า SHA-256 ด้วยคำสั่งอื่น เช่น Get-FileHash ของ Windows PowerShell

shasum -a 256 -c --ignore-missing SHA256SUMS.txt

หากบรรทัดของไฟล์ที่ดาวน์โหลดมาแสดง OK แสดงว่าไฟล์ไม่มีปัญหา
