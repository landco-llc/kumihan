DOCUMENTATION / GeminiКроки та примітки

Тут пояснено, як користуватися KUMIHAN｜Міра у Gemini CLI та застосунку Gemini.

Про версію v0.1.0 Ця версія призначена для того, щоб ви могли спробувати встановлення у своєму середовищі. Роботу в кожному інструменті ще не перевірено достатньою мірою, тому деякі кроки можуть працювати не так, як очікується.

1. Виберіть спосіб встановлення

Де ви хочете користуватисяРекомендований спосіб
Gemini CLI (усі чотири навички)A. Встановити як розширення
Gemini CLI (лише потрібні навички)B. Встановити окремі навички
Застосунок Gemini (веб, Mac, мобільні пристрої)C. Завантажити навички

A. Gemini CLI: встановлення як розширення

Так ви встановите всі чотири навички одразу.

  1. Завантажте ZIP-файл розширення (Source ZIP).
  2. Після розпакування ZIP-файлу з’явиться тека kumihan-mira-uk.
  3. Встановіть розширення з цієї теки:
    gemini extensions install "/absolute/path/kumihan-mira-uk"

Перш ніж продовжити, перегляньте запит на підтвердження. Після встановлення розширення діє в усіх проєктах.

Розширення, встановлене із ZIP-файлу, не оновлюється автоматично. Коли вийде нова версія, замініть його новим ZIP-файлом.

B. Gemini CLI: встановлення окремих навичок

Так ви встановите лише потрібні навички й лише для одного проєкту. Якщо ви вже скористалися способом A, це не потрібно.

Наприклад, щоб встановити kumihan-mira-uk, виконайте у своєму проєкті:

gemini skills install https://github.com/landco-llc/kumihan --path plugins/kumihan-mira-uk/skills/kumihan-mira-uk --scope workspace

Для інших навичок змініть --path на:

  • plugins/kumihan-mira-uk/skills/kumihan-mira-uk-web — вебсторінки
  • plugins/kumihan-mira-uk/skills/kumihan-mira-uk-documents — звіти й слайди
  • plugins/kumihan-mira-uk/skills/kumihan-mira-uk-review — перевірка

--scope workspace обмежує дію навички цим проєктом. Без цього параметра навичка буде доступна в усіх ваших проєктах.

Як оновити

Виконайте ту саму команду ще раз. Встановлену навичку буде замінено, тому спершу збережіть зміни, які ви в ній зробили.

C. Застосунок Gemini: завантаження навичок

  1. Завантажте ZIP-файли потрібних навичок.
    • kumihan-mira-uk (Source ZIP) — відправна точка
    • kumihan-mira-uk-web (Source ZIP) — вебсторінки
    • kumihan-mira-uk-documents (Source ZIP) — звіти й слайди
    • kumihan-mira-uk-review (Source ZIP) — перевірка
  2. У Gemini відкрийте Customize (або More, якщо цього пункту немає) → Skills → Upload.
  3. Вибирайте ZIP-файли по одному, переглядайте відомості й натискайте Create.

Зверніть увагу

  • Функція доступна для особистих облікових записів Google користувачів від 18 років. Робочі й навчальні облікові записи наразі не підтримуються.
  • Має бути ввімкнено Keep Activity.
  • Функція з’являється поступово й може бути ще недоступна для вас. Докладніше — в довідці Gemini.
  • ZIP-файл розширення (для Gemini CLI) тут не підійде.
  • Завантажені навички не оновлюються автоматично. Коли вийде нова версія, завантажте їх ще раз.

Перевірте файли (необов’язково)

Якщо хочете переконатися, що завантажені файли не пошкоджено, скористайтеся SHA256SUMS.txt.

Покладіть SHA256SUMS.txt у ту саму теку, що й завантажені ZIP-файли, і виконайте в терміналі таку команду. Якщо shasum недоступна, звірте SHA-256 іншим способом, наприклад за допомогою Get-FileHash у Windows PowerShell.

shasum -a 256 -c --ignore-missing SHA256SUMS.txt

Якщо в рядках завантажених файлів указано OK, усе гаразд.
