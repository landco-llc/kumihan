DOCUMENTATION / Claude手順と注意事項

01 / 導入形式を選ぶ

ホストの対応に合わせて独立プラグイン、または単体Skillを選びます。日本語版KUMIHANや字衡の事前導入は不要です。プラグインZIPとSkill ZIPは異なります。チャットへの添付はプラグインのインストールではありません。

02 / ダウンロード

15本のZIPはGitHub Release v0.1.1から取得できます。導入前にSHA256SUMS・MANIFESTを照合してください。実ホストでの導入・呼び出しは未検証です。

  • 独立プラグイン: kumihan-th-Claude-Code-plugin-v0.1.1.zip
  • 単体Skill: kumihan-th-Claude-skill-v0.1.1.zip
  • 単体Skill: kumihan-th-web-Claude-skill-v0.1.1.zip
  • 単体Skill: kumihan-th-documents-Claude-skill-v0.1.1.zip
  • 単体Skill: kumihan-th-review-Claude-skill-v0.1.1.zip

03 / 導入手順

必要なSkillをダウンロードして展開し、SKILL.mdと同梱資料を読みます。対応する導入機能がない場合は作業の文脈として資料を渡し、ネイティブ導入ではなく指示文に沿った利用であると明示します。

Claude Code：プラグインを展開し、claude --plugin-dir /absolute/path/kumihan-th で読み込みます。技術IDはkumihan-thです。Claude Apps：アカウントが対応する場合のみ単体Skillをインポートします。実ホスト受入：not-checked。

ソースの導入資料を読む

04 / 原稿を変更しないテスト

「น้ำชา เก่ง ภาษาไทย」の改行と声調記号の表示を、元の原稿を変更せずにレビューしてください。実際に検査した項目と未検証事項を分けてください。

native installation: not-checked · native invocation: not-checked

05 / 更新

更新前に旧版を保存してください。新しいタグとSHA256SUMSを確認し、本製品のフォルダーのみ置き換えます。旧版への差し戻しでロールバックできます。削除はホストの管理機能で行うか、作業の文脈から資料を取り除きます。

06 / 対応範囲と限界

各ホストでのネイティブ導入・呼び出し：not-checked。語分割と表示はエンジン・フォント・環境に依存します。実描画と意味は人による確認が必要です。すべての組版を自動修正する保証はありません。
