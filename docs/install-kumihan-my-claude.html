DOCUMENTATION / Claudeအဆင့်များနှင့် သတိပြုရန်များ

ဤလမ်းညွှန်သည် KUMIHAN｜ဟန်ချက် ကို Claude Code နှင့် Claude chat တွင် အသုံးပြုပုံကို ရှင်းပြသည်။

v0.1.0 အကြောင်း ဤဗားရှင်းသည် သင့်ကိုယ်ပိုင် ပတ်ဝန်းကျင်တွင် တပ်ဆင်စမ်းသပ်ရန် ဖြစ်သည်။ ကိရိယာတစ်ခုချင်းစီတွင် လုပ်ဆောင်ပုံကို အပြည့်အဝ မစစ်ဆေးရသေးသဖြင့် အချို့အဆင့်များ မျှော်လင့်ထားသလို အလုပ်မလုပ်နိုင်ပါ။

1. တပ်ဆင်နည်းကို ရွေးပါ

အသုံးပြုလိုသည့်နေရာအကြံပြုထားသော နည်းလမ်း
Claude Code (ZIP မှ)A. ZIP မှ တပ်ဆင်ရန်
Claude chat (claude.ai နှင့် app များ)B. ကျွမ်းကျင်မှုများကို upload လုပ်ရန်

Claude Code နှင့် Claude chat တို့သည် တပ်ဆင်နည်း မတူပါ။

A. Claude Code— ZIP မှ တပ်ဆင်ပါ

  1. Claude Code plugin ZIP ကို ဒေါင်းလုဒ်လုပ်ပါ။
  2. ZIP ကို ဖြည်လိုက်လျှင် kumihan-my folder ရမည်။
  3. ထို folder ကို သတ်မှတ်၍ Claude Code ကို စတင်ပါ—
    claude --plugin-dir "/absolute/path/kumihan-my"

သတိပြုရန်

  • folder ကို ရှိသည့်အတိုင်း အသုံးပြုပါ။ ဖိုင်များကို မဖယ်ရှားပါနှင့်၊ အခြားဖိုင်များကိုလည်း မထည့်ပါနှင့်။
  • ဤနည်းသည် အလိုအလျောက် update မလုပ်ပါ။ ဗားရှင်းအသစ် ထွက်လာလျှင် ZIP အသစ်ဖြင့် folder ကို အစားထိုးပါ။

B. Claude chat— ကျွမ်းကျင်မှုများကို upload လုပ်ပါ

claude.ai နှင့် Claude app များအတွက် ဤနည်းကို အသုံးပြုပါ။

  1. အသုံးပြုလိုသော ကျွမ်းကျင်မှု ZIP များကို ဒေါင်းလုဒ်လုပ်ပါ။
    • kumihan-my — စတင်ရာ
    • kumihan-my-web — ဝဘ်စာမျက်နှာ
    • kumihan-my-documents — အစီရင်ခံစာနှင့် ဆလိုက်
    • kumihan-my-review — ပြန်လည်သုံးသပ်ခြင်း
  2. Claude တွင် Customize → Skills ကို ဖွင့်ပြီး ထည့်ရန်ခလုတ်မှ Upload a skill ကို ရွေးပါ။
  3. ZIP များကို တစ်ခုချင်း upload လုပ်ပြီး ကျွမ်းကျင်မှုတစ်ခုချင်းကို ဖွင့်ပါ။

သတိပြုရန်

  • Claude Code plugin ZIP သည် ဤနေရာတွင် အလုပ်မလုပ်ပါ။ ကျွမ်းကျင်မှု တစ်ခုချင်း၏ ZIP များကို အသုံးပြုပါ။
  • ZIP ဖိုင်အမည်များကို မပြောင်းဘဲ upload လုပ်ပါ။
  • ကျွမ်းကျင်မှုများ အသုံးပြုရန် ဆက်တင်တွင် code execution ကို ဖွင့်ထားရမည်။ Claude ၏ လမ်းညွှန် ကို ကြည့်ပါ။
  • အဖွဲ့အစည်း အကောင့်များတွင် admin ၏ ဆက်တင်ပေါ် မူတည်၍ အသုံးပြုနိုင်မှု ကွာခြားနိုင်သည်။
  • upload လုပ်ထားသော ကျွမ်းကျင်မှုများသည် အလိုအလျောက် update မဖြစ်ပါ။ ဗားရှင်းအသစ် ထွက်လာလျှင် ထပ်မံ upload လုပ်ပါ။

2. စမ်းသုံးကြည့်ပါ

ဖိုင်များကို မပြောင်းလဲသော တောင်းဆိုချက်ဖြင့် စတင်ရန် အကြံပြုပါသည်—

မြန်မာဘာသာဖြင့် ဝဘ်စာမျက်နှာတစ်ခု ပြုလုပ်ရန် စီစဉ်နေပါသည်။ ဘာတွေကို သတိထားသင့်ပါသလဲ။ ဖိုင်များကို မပြောင်းပါနှင့်။

ဒေါင်းလုဒ်လုပ်ထားသော ဖိုင်များကို စစ်ဆေးပါ (ရွေးချယ်နိုင်)

ဒေါင်းလုဒ်လုပ်ထားသော ဖိုင်များ ပျက်စီးမှုမရှိကြောင်း စစ်ဆေးလိုလျှင် SHA256SUMS.txt ကို အသုံးပြုပါ။

ဒေါင်းလုဒ်လုပ်ထားသော ZIP ဖိုင်များနှင့် folder တစ်ခုတည်းတွင် SHA256SUMS.txt ကို ထားပြီး terminal တွင် အောက်ပါ command ကို run ပါ။ shasum မရှိလျှင် Windows ၏ PowerShell Get-FileHash ကဲ့သို့ တူညီသော SHA-256 command ဖြင့် တိုက်စစ်ပါ။

shasum -a 256 -c --ignore-missing SHA256SUMS.txt

ဒေါင်းလုဒ်လုပ်ထားသော ဖိုင်များ၏ စာကြောင်းတွင် OK ပြလျှင် ဖိုင်များ ပြည့်စုံမှန်ကန်ပါသည်။

အခြား ကိရိယာများ— ChatGPT / Codex · Gemini

မျက်နှာပြင်များနှင့် ရရှိနိုင်မှုတို့ ပြောင်းလဲနိုင်သည်။ နောက်ဆုံးအချက်အလက်အတွက် ဝန်ဆောင်မှုတစ်ခုချင်းစီ၏ တရားဝင်လမ်းညွှန်ကို ကြည့်ပါ (နောက်ဆုံးစစ်ဆေးသည့်ရက်— ၂၀၂၆ ခုနှစ် အောက်တိုဘာလ ၁၄ ရက်)။
