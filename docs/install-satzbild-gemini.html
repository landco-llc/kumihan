DOCUMENTATION / GeminiSchritte und Hinweise

01 / Format wählen

Das Plugin enthält alle vier Skills. Jeder Skill ist auch einzeln mit eigenen Regeln und Referenzen verfügbar. Das Anhängen einer ZIP-Datei an einen Chat installiert nichts.

02 / Herunterladen und prüfen

Laden Sie die Dateien dieser Version herunter. Prüfen Sie vor der Einrichtung SHA-256 und Dateigröße anhand von MANIFEST.json. Mit allen 17 Dateien im selben Ordner ausführen (unter macOS: shasum -a 256 -c SHA256SUMS.txt):

sha256sum -c SHA256SUMS.txt
  • Plugin: kumihan-satzbild-Gemini-CLI-extension-v0.1.0.zip
  • Einzelner Skill: kumihan-satzbild-Gemini-Apps-skill-v0.1.0.zip
  • Einzelner Skill: kumihan-satzbild-web-Gemini-Apps-skill-v0.1.0.zip
  • Einzelner Skill: kumihan-satzbild-documents-Gemini-Apps-skill-v0.1.0.zip
  • Einzelner Skill: kumihan-satzbild-review-Gemini-Apps-skill-v0.1.0.zip

SHA256SUMS.txt · MANIFEST.json · GitHub Release v0.1.0

03 / Einrichten

Entpacken Sie die Erweiterung in einen leeren Ordner mit gemini-extension.json direkt im Wurzelverzeichnis. Installieren Sie sie über diesen Pfad und lesen Sie die Berechtigungsabfrage. Installieren Sie nicht das gesamte Repository als Satzbild. Der Import in Gemini Apps ist nicht geprüft.

gemini extensions install /absolute/path/to/folder
gemini extensions list

INSTALL.md

04 / Ohne Änderung am Original testen

Geben Sie Sprachvariante (de-DE/de-AT/de-CH), Anrede (du/Sie), Medium und Arbeitsmodus an. Beispiel:

Nutze kumihan-satzbild-review. Bewahre Originaltext, Zahlen und Namen; trenne Beobachtungen von Vorschlägen.

Optionaler statischer Test (nur lesend):

python skills/kumihan-satzbild/runtime/checks.py original.txt --locale de-DE --candidate candidate.txt

05 / Aktualisieren

Sichern Sie eigene Einstellungen und prüfen Sie neue Version und Prüfsumme. Aktualisieren Sie über die unterstützte Methode Ihres Werkzeugs. Ein neuer Commit aktualisiert eine bestehende Installation nicht. Andere Sprachplugins bleiben erhalten.

06 / Umfang und Grenzen

44 Regelkandidaten und eine begrenzte CSS-Kandidatenregel; 48 vorgeschlagene Forschungsfälle werden getrennt geführt. Kein vollständiges Korrektorat und keine visuelle Zertifizierung. Nativer Import, Symboldarstellung und Aufnahme in Anbieter-Verzeichnisse sind nicht verifiziert.
