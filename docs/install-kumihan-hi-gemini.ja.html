01 / 導入形式を選ぶ

プラグインには4つのスキルがすべて入っています。各スキルは、ルールと参考資料をそろえた単体でも配布しています。チャットにファイルを添付しただけでは導入されません。

02 / ダウンロードと照合

GitHub Release v0.1.0からZIPを取得し、導入前にSHA256SUMS.txtとSHA-256を照合してください。

  • プラグイン: kumihan-hi-gemini-cli-extension-v0.1.0.zip
  • 個別スキル: kumihan-hi-gemini-skill-v0.1.0.zip
  • 個別スキル: kumihan-hi-web-gemini-skill-v0.1.0.zip
  • 個別スキル: kumihan-hi-documents-gemini-skill-v0.1.0.zip
  • 個別スキル: kumihan-hi-review-gemini-skill-v0.1.0.zip

SHA256SUMS.txt · MANIFEST.json · GitHub Release v0.1.0

03 / 導入する

拡張を空のフォルダに展開し、kumihan-hiフォルダ内にgemini-extension.jsonがあることを確認してから、そのパスを指定して導入します。リポジトリのルートは日本語版の製品のため、この拡張として導入しないでください。Geminiアプリへの取り込みは確認していません。

gemini extensions install /absolute/path/kumihan-hi
gemini extensions list

INSTALL.md

04 / 原稿を変えずに試す

Hindi/Devanagari、locale、読者、媒体、作業モード、原稿の変更権限を指定します。例：

kumihan-hi-reviewでक्षि क्षी त्रि ज्ञ श्र स्त्रीを原稿を変えずにレビューしてください。静的確認、実表示、未検証を分けてください。

任意の静的チェック（読み取り専用）：

python runtime/checks.py original.txt --candidate candidate.txt

05 / 更新

カスタマイズを保存し、新しいバージョンとチェックサムを確認してから、ツールが対応する方法で更新します。新しいコミットだけでは既存の導入は更新されません。他言語のプラグインは上書きしないでください。

06 / 対応範囲と限界

GitHubでの公開は、ChatGPT・Claude・Geminiの公式ディレクトリへの掲載を意味しません。各ツールでの動作と実際の表示は、実行して確かめる必要があります。静的チェックは、ヒンディー語の母語話者による確認の代わりにはなりません。
