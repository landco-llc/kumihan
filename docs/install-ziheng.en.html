01 / OPTIONS

Choose the method supported by your host

▣

Full plugin ZIP

Contains four standalone skills and local references. Import it only through a plugin workflow actually supported by the host. Uploading a ZIP as a normal ChatGPT attachment does not install a plugin.

文

Individual Skill ZIPs

Install only the role you need. For Codex environments supporting local Skills, place the complete folder under your project’s .agents/skills/ directory.

i

Publication status

Source and preview archives are available on GitHub. ZiHeng is not claimed to be listed in the public plugin marketplace. Dedicated Claude/Gemini preview ZIPs are available; live host invocation still requires verification.

02 / STEPS

Setup steps

01

Download and verify

Get the complete ZIP from the official KUMIHAN repository and compare its SHA-256 with SHA256SUMS.txt. The filename is versioned; the plugin’s display name is not.

02

Use an installation entrypoint your host supports

Private ChatGPT plugin import depends on your account’s available features; Codex may provide local Skills support. Simply attaching the ZIP to a chat does not activate it.

03

Standalone skills in Codex

Extract the archive, then copy the complete kumihan-ziheng* skill folder(s) to .agents/skills/ in your project. Retain SKILL.md and its references, rules, profiles, schemas and other files. Back up any existing folder first.

04

Run Taiwan and Hong Kong samples

Explicitly invoke the skill and locale in a new conversation. Check regional selection, exact source preservation and that read-only reviews do not modify the target.

03 / DOWNLOADS

ZIP and SHA-256

Checksum for the complete plugin archive. Compare after downloading with sha256sum or an equivalent utility; for future versions use the matching release manifest.

05 / VERIFY

Verify and limitations

TW / zh-Hant-TW

Taiwan

Plan this article for zh-Hant-TW without changing the source: 「陳𠮷、臺／台、ＨＫ＄１２３」. Mark checks without rendered evidence as not-checked.
HK / zh-Hant-HK

Hong Kong

Review this text read-only for zh-Hant-HK. Keep its quotes and URLs; first establish the institution’s editorial conventions rather than applying Taiwan defaults.

What is not automatically verified

This is typography guidance, not a layout renderer. True line-edge behavior, native 200% zoom, regional glyph appearance, vertical writing, Bopomofo, Word, PowerPoint and PDF need separate checks in the actual target. A static finding is not an automatically corrected error.
