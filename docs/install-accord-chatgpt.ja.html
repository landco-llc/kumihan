01 / 導入形式を選ぶ

プラグインには4つのスキルがすべて入っています。各スキルは、ルールと参考資料をそろえた単体でも配布しています。チャットにファイルを添付しただけでは導入されません。

02 / ダウンロードと照合

GitHub Release v0.1.0からZIPを取得し、導入前にSHA256SUMS.txtとSHA-256を照合してください。

  • プラグイン: kumihan-accord-chatgpt-codex-plugin-v0.1.0.zip
  • 個別スキル: kumihan-accord-chatgpt-skill-v0.1.0.zip
  • 個別スキル: kumihan-accord-web-chatgpt-skill-v0.1.0.zip
  • 個別スキル: kumihan-accord-documents-chatgpt-skill-v0.1.0.zip
  • 個別スキル: kumihan-accord-review-chatgpt-skill-v0.1.0.zip

SHA256SUMS.txt · MANIFEST.json · GitHub Release v0.1.0

03 / 導入する

ChatGPT / Codex用プラグインは、対応するプラグインの取り込み機能で使います。Skillsの画面がある場合は、個別スキルを1つずつ導入できます。公式プラグインディレクトリへの掲載は別の手続きです。

INSTALL.md

04 / 原稿を変えずに試す

言語・編集スタイル・作業モードを明示します。依頼の例：

kumihan-accord-reviewで、このフランス語のページを編集スタイルfr-fr-editorialで、原文を変えずにレビューしてください。確認できた点と、まだ確認が必要な点を分けてください。

任意の静的チェック（読み取り専用）：

python runtime/checks.py input.txt --locale fr-FR --house-style fr-fr-editorial

05 / 更新

カスタマイズを保存し、新しいバージョンとチェックサムを確認してから、ツールが対応する方法で更新します。新しいコミットだけでは既存の導入は更新されません。他言語のプラグインは上書きしないでください。

06 / 対応範囲と限界

GitHubでの公開は、ChatGPT・Claude・Geminiの公式ディレクトリへの掲載を意味しません。各ツールでの動作と実際の表示は、実行して確かめる必要があります。静的チェックは、フランス語の編集者による確認の代わりにはなりません。
