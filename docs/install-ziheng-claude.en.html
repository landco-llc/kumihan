DOCUMENTATION / ClaudeSteps & guidance

01 / SETUP

Installation steps

01

Register the KUMIHAN Marketplace

Claude Code: register the KUMIHAN marketplace from GitHub without replacing the Japanese plugin.

claude plugin marketplace add "https://github.com/landco-llc/kumihan.git#main"
02

Install the ZiHeng plugin

Install the ZiHeng plugin by its distinct name from within Claude Code.

/plugin install kumihan-ziheng@kumihan-marketplace
03

Load the local plugin ZIP

Alternatively extract the plugin ZIP and load its local folder directly.

claude --plugin-dir "/absolute/path/kumihan-ziheng"
04

Import skills in Claude chat

Claude chat: if Skill import is supported on your account, import one standalone skill ZIP at a time; the Claude Code plugin ZIP is not the chat skill upload format.
