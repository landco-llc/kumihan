導入手順

  1. 前提：Extensions対応のGemini CLI。Gemini AppのSkillsアップロードは未検証です。
  2. Extension ZIPを空フォルダへ展開し、直下のgemini-extension.jsonを確認します。gemini extensions install /absolute/path/to/folderを実行し、権限確認を読んでください。
  3. 単体Skill ZIPは独立フォルダへ展開し、使用中CLIのSkills導入手順で利用します。リポジトリroot URLは別製品を選ぶため使いません。App導入は実際のアカウントに入口がある場合のみです。

ダウンロードと検証

downloads内で sha256sum -c SHA256SUMS.txt（macOSは shasum -a 256 -c）を実行します。単体ZIPのみならMANIFEST.jsonの該当SHA256と照合します。
