English-language installation guide This installation guide is provided in English while a reviewed local-language translation is unavailable. The EL edition and its four skills are language-specific; native-host import and actual rendering have not been fully verified.

This guide explains how to use KUMIHAN｜Μέτρο with Claude Code and Claude chat.

About v0.1.0 This version is for trying KUMIHAN｜Μέτρο in your own environment. Behavior in each tool has not yet been fully verified, so some steps may not work as expected.

1. Choose an installation method

Where you want to use itRecommended method
Claude Code (from a ZIP)A. Install from a ZIP
Claude chat (claude.ai and apps)B. Upload skills

Claude Code and Claude chat use different installation methods.

A. Claude Code: install from a ZIP

  1. Download the Claude Code plugin ZIP.
  2. Extract it to get a kumihan-metro folder.
  3. Start Claude Code with that folder:
    claude --plugin-dir "/absolute/path/kumihan-metro"

Notes

  • Use the folder as is. Don't remove files or add other files to it.
  • This method does not update automatically. When a new version is released, replace the folder with the new ZIP.

B. Claude chat: upload skills

Use this method for claude.ai and the Claude apps.

  1. Download the skill ZIPs you want to use.
    • kumihan-metro — starting point
    • kumihan-metro-web — web pages
    • kumihan-metro-documents — reports and slides
    • kumihan-metro-review — review
  2. In Claude, open Customize → Skills, then choose Upload a skill from the add button.
  3. Upload the ZIPs one at a time and enable each skill.

Notes

  • The Claude Code plugin ZIP does not work here. Use the individual skill ZIPs.
  • Upload the ZIPs without renaming them.
  • Skills require code execution to be turned on in your settings. See Claude's guide.
  • On organization accounts, availability may depend on your admin's settings.
  • Uploaded skills do not update automatically. When a new version is released, upload it again.

2. Try it out

We recommend starting with a request that doesn't change any files:

I'm planning a web page in Ελληνικά. What should I keep in mind? Please don't change any files.

Verify your downloads (optional)

To check that your downloads are intact, use SHA256SUMS.txt.

Put SHA256SUMS.txt in the same folder as the ZIP files you downloaded, then run this in a terminal. If shasum is unavailable, use an equivalent SHA-256 command such as PowerShell Get-FileHash on Windows:

shasum -a 256 -c --ignore-missing SHA256SUMS.txt

If the lines for your downloaded files show OK, the files are intact.
