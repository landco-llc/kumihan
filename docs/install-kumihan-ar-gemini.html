01 / التثبيت حسب المنصة

  1. يلزم Gemini CLI يدعم Extensions. فك الأرشيف وتأكد من وجود gemini-extension.json في جذر المجلد.
  2. ثبّت المجلد المحلي باستخدام الأمر أدناه، وراجع مطالبة الصلاحيات.
  3. أرشيفات المهارات مستقلة. الاستيراد في Gemini Apps يدوي وغير متحقق؛ لا تستخدم حزمة CLI على أنها حزمة تطبيق المحادثة.
gemini extensions install /absolute/path/kumihan-ar

Gemini CLI Extensions · Gemini CLI Skills

02 / التنزيل والتحقق

حزم الإصدار

  • kumihan-ar-Gemini-CLI-extension-v0.1.0.zip
  • kumihan-ar-Gemini-Apps-skill-v0.1.0.zip
  • kumihan-ar-web-Gemini-Apps-skill-v0.1.0.zip
  • kumihan-ar-documents-Gemini-Apps-skill-v0.1.0.zip
  • kumihan-ar-review-Gemini-Apps-skill-v0.1.0.zip

قارن بصمة SHA-256 بالملف المنشور. ضع الحزم الخمس المختارة في مجلد واحد ونفّذ أمر GNU التالي، وتحقق من ظهور OK لكل الملفات الخمسة. لملف واحد أو macOS قارن ناتج shasum -a 256 مع MANIFEST.json.

sha256sum --ignore-missing -c SHA256SUMS.txt

SHA256SUMS.txt · MANIFEST.json

03 / الاستخدام والتحديث

استخدم kumihan-ar-review لمراجعة هذه الصفحة دون تغيير النص الأصلي أو الأسماء أو الأرقام. افصل الملاحظات الثابتة عن العرض الذي شاهدته.

احتفظ بنسخة من تخصيصاتك، وتحقق من الإصدار الجديد قبل إعادة التثبيت. إرفاق ملف بالمحادثة لا يثبت تثبيت المهارة.

هذه إرشادات مساعدة، وليست شهادة لجودة التنضيد. التثبيت والاستدعاء في التطبيقات الأصلية غير مفحوصين. الصياغة العربية تحتاج مراجعة متحدث أصلي.
