01 / OPTIONS

依主機選擇適用方式

▣

完整插件 ZIP

包含四個獨立技能及本地參考檔。僅能透過主機實際支援的插件匯入功能安裝；在 ChatGPT 對話直接上傳 ZIP 並不等於完成安裝。

文

單一 Skill ZIP

也可只取得需要的技能。對支援本地 Skills 的 Codex，完整資料夾可放在專案的 .agents/skills/ 之下。

i

公開狀態

GitHub 已提供程式碼和預覽 ZIP；字衡並未宣稱已在公開插件商店完成上架。Claude／Gemini 已備有專用預覽 ZIP；實際主機呼叫仍須另外驗證。

02 / STEPS

分步安裝

01

下載並核對來源

從 KUMIHAN 正式 GitHub repository 取得完整 ZIP，對照 SHA256SUMS.txt。檔名包含版本，插件顯示名稱不包含版本。

02

選擇主機支援的安裝入口

ChatGPT 的私人插件匯入需使用帳戶實際提供的插件功能；Codex 可使用相容的技能安裝入口。不要把 ZIP 當作普通附件就認為插件已啟用。

03

Codex 本地獨立技能

解壓後，將需要的完整 kumihan-ziheng* 技能資料夾複製到專案 .agents/skills/；保留其 SKILL.md、references、rules、profiles、schemas 及其他檔案。請先備份同名資料夾。

04

用兩個地區的小樣本驗收

在新對話中明示技能名與地區，檢查臺灣與香港規則是否分開、原稿是否原樣保留，以及唯讀審閱是否沒有改動檔案。

03 / DOWNLOADS

ZIP 與 SHA-256

對完整插件 ZIP 的核對值。下載後可執行 sha256sum（或等效工具）比較；實際發行檔若改版，以當版的校驗清單為準。

05 / VERIFY

驗證與限制

TW / zh-Hant-TW

臺灣

以 zh-Hant-TW 規劃這段文章的版面，保留原稿：「陳𠮷、臺／台、ＨＫ＄１２３」。未描畫的項目請標為 not-checked。
HK / zh-Hant-HK

香港

以 zh-Hant-HK 唯讀檢視這段文字，保留引號及網址，先確認機構的編輯體例，不要自動套用臺灣引號規則。

尚未驗證的項目

這套插件是組版指引，不是自動渲染器。實際行末禁則、200% 原生縮放、區域字形、直排、注音、Word、PowerPoint 與 PDF，需在指定環境另外檢查。靜態候選不等於已修正的錯誤。
