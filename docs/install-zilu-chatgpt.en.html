Installation steps

  1. Prerequisite: an account and client with a plugin or Skills installation interface. A plugin bundle and individual skills are different packages.
  2. Extract the full plugin and select the kumihan-zilu folder in the supported plugin import interface. For Skills-only clients, install the four individual skill ZIPs through the Skills interface.
  3. Attaching a file to chat is not installation. Native discovery, icon display and invocation remain unverified. Without an import interface, use the source as manual guidance.

Downloads & checksums

From downloads/, run sha256sum -c SHA256SUMS.txt (or shasum -a 256 -c on macOS). For one ZIP, compare its hash with the matching MANIFEST.json entry.
