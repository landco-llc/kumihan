01 / パッケージを選ぶ

02 / ダウンロードと照合

v0.1.0付きZIPとSHA256SUMS.txtを確認してください。

03 / 導入

Claude Codeではclaude --plugin-dir /absolute/path/kumihan-ladを利用し認識を確認してください。

claude --plugin-dir /absolute/path/kumihan-lad
claude plugin validate /absolute/path/kumihan-lad
/plugin marketplace add landco-llc/kumihan
/plugin install kumihan-lad@kumihan-marketplace

04 / 動作確認

言語・地域（ru-RU・ru-RU）・編集スタイル・作業モードを明示します。依頼の例：

原稿を変えずにロシア語の文字組をレビューして。

python runtime/checks.py original.txt --locale ru-RU

python runtime/checks.py input.txt --locale ru-RU

05 / 更新

チェックサムを確認し、独自設定を保存して再導入します。
