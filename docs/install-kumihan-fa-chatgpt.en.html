01 / Install for your platform

  1. Check that your account and client offer a plugin or Skills installation interface. Availability differs between ChatGPT and Codex.
  2. For Codex, extract an individual skill folder into your project’s .agents/skills/, then request the skill by name. Consult your client’s documentation for plugin installation.
  3. In ChatGPT, use the actual import interface if available. Otherwise read SKILL.md as manual guidance; that is not plugin installation.

02 / Downloads and verification

Compare SHA-256 with the published checksum file. With your five selected ZIPs in one directory, run the GNU command below and confirm that all five are reported OK. For a single ZIP, compare its hash with MANIFEST.json; on macOS use shasum -a 256 and compare the matching entry.

sha256sum --ignore-missing -c SHA256SUMS.txt

03 / Use and update

Use kumihan-fa-review to review this page without changing source text, names or numbers. Separate static findings from rendering you actually observed.

Back up customizations and verify the new version before reinstalling. Attaching a file to chat does not establish skill installation.
