Installation guide

Choose a format

The plugin bundles four skills. Every standalone skill includes its rules and references. Attaching a ZIP to a chat does not install anything.

  • Plugin package: kumihan-nhip-chu-claude-code-plugin-v0.1.0.zip
  • Standalone Skill: kumihan-nhip-chu-claude-skill-v0.1.0.zip

Download and verify

Get v0.1.0 host-specific archives from GitHub Release and verify SHA256SUMS.txt before installation.

kumihan-nhip-chu-claude-code-plugin-v0.1.0.zip

SHA256SUMS.txt · MANIFEST.json

4 Skills

  • kumihan-nhip-chu-claude-skill-v0.1.0.zip
  • kumihan-nhip-chu-web-claude-skill-v0.1.0.zip
  • kumihan-nhip-chu-documents-claude-skill-v0.1.0.zip
  • kumihan-nhip-chu-review-claude-skill-v0.1.0.zip

Install

Unzip into an empty directory, keep the product folder and load it from Claude Code. The repository marketplace is an alternative where supported.

Example install commands

claude --plugin-dir /absolute/path/kumihan-nhip-chu
claude plugin validate /absolute/path/kumihan-nhip-chu
/plugin marketplace add landco-llc/kumihan
/plugin install kumihan-nhip-chu@kumihan-marketplace

Test without editing

The static checker reports advisory candidates only; font rendering and host activation require real execution.

Use KUMIHAN｜Nhịp Chữ to review the Vietnamese typography of this page without changing the source. Keep all tone marks and distinguish observed findings from unverified items.

python runtime/checks.py input.txt --locale vi-VN

Update

Back up customizations and verify version/checksum before updating. Existing installs do not update from GitHub automatically.

Limitations

Real host, device and native Vietnamese copy reviews are not certified. Audits never edit source content.
