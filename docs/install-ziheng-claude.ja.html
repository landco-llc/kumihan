DOCUMENTATION / Claude手順と注意事項

01 / SETUP

導入手順

01

KUMIHANマーケットプレイスを登録

Claude Code：GitHubからKUMIHANマーケットプレイスを登録します。日本語版は変更しません。

claude plugin marketplace add "https://github.com/landco-llc/kumihan.git#main"
02

字衡プラグインをインストール

Claude Code内で、区別された字衡のプラグイン名を指定して導入します。

/plugin install kumihan-ziheng@kumihan-marketplace
03

ローカルZIPから起動

代わりに専用ZIPを解凍し、そのフォルダを指定してローカル起動できます。

claude --plugin-dir "/absolute/path/kumihan-ziheng"
04

Claudeチャットにスキルを追加

Claudeチャット：Skillsのアップロードが利用できる場合に限り、個別スキルZIPを1本ずつ追加します。Claude Code用の一括ZIPとは異なります。
