DOCUMENTATION / Claude安装步骤

01 / 安装步骤

  1. 前提：Claude Code CLI；Claude chat 的Skills上传取决于账户功能。
  2. 解压完整插件，然后以 claude --plugin-dir /absolute/path/kumihan-zilu 启动。用 claude plugin validate /absolute/path/kumihan-zilu 验证目录（若当前版本支持）。
  3. Claude chat 使用下方单个Skill ZIP，在真正的Skills上传入口导入。会话本地加载与官方商店上架是不同事实。

Claude Code plugins · Claude Skills

02 / 下载与核验

在 downloads 目录使用 sha256sum -c SHA256SUMS.txt（macOS 可用 shasum -a 256 -c）。只下载单个ZIP时对照 MANIFEST.json 对应项校验。

  • kumihan-zilu-claude-plugin-v0.1.0.zip
  • kumihan-zilu-entry-claude-skill-v0.1.0.zip
  • kumihan-zilu-web-claude-skill-v0.1.0.zip
  • kumihan-zilu-documents-claude-skill-v0.1.0.zip
  • kumihan-zilu-review-claude-skill-v0.1.0.zip
