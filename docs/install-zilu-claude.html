DOCUMENTATION / Claude步骤与注意事项

本指南介绍如何在 Claude Code 和 Claude 聊天中使用 KUMIHAN｜字律。

关于 v0.1.0 此版本供你在自己的环境中试用。各工具中的实际运行尚未经过充分验证，因此部分步骤可能无法按预期工作。

1. 选择安装方式

使用场景推荐方式
Claude Code（希望通过 ZIP 安装时）A. 从 ZIP 安装
Claude 聊天（claude.ai 和应用）B. 上传技能

Claude Code 和 Claude 聊天的安装方式不同。

A. Claude Code：从 ZIP 安装

  1. 下载 Claude Code 插件 ZIP (Source ZIP)。
  2. 解压 ZIP 后，会得到 kumihan-zilu 文件夹。
  3. 指定该文件夹并启动 Claude Code。
    claude --plugin-dir "/absolute/path/kumihan-zilu"

注意事项

  • 请直接使用文件夹中的内容，不要删除文件或混入其他文件。
  • 此方式不会自动更新。新版本发布后，请替换 ZIP。

B. Claude 聊天：上传技能

适用于 claude.ai 和 Claude 应用。

  1. 下载想要使用的技能 ZIP。
    • kumihan-zilu (Source ZIP) — 起点
    • kumihan-zilu-web (Source ZIP) — 网页
    • kumihan-zilu-documents (Source ZIP) — 报告与演示文稿
    • kumihan-zilu-review (Source ZIP) — 审阅
  2. 在 Claude 中打开 Customize → Skills，通过添加按钮选择 Upload a skill。
  3. 逐个上传 ZIP，并启用技能。

注意事项

  • 此处不能使用 Claude Code 插件 ZIP，请使用技能 ZIP。
  • 上传时请不要更改 ZIP 的文件名。
  • 使用技能需要在设置中启用“代码执行”。详情请参阅 Claude 官方说明。
  • 组织账户可能会因管理员的设置而无法使用。
  • 上传的技能不会自动更新。新版本发布后，请重新上传。

2. 开始试用

建议先用不会修改文件的请求进行测试：

我准备制作一个中文网页。请告诉我需要注意哪些要点。请不要修改任何文件。

检查文件是否完整（可选）

如果想确认下载的文件没有损坏，请使用 SHA256SUMS.txt。

将 SHA256SUMS.txt 放在与下载的 ZIP 文件相同的文件夹中，然后在终端中运行以下命令。如果环境中没有 shasum，请使用 Windows PowerShell 的 Get-FileHash 等工具核对 SHA-256。

shasum -a 256 -c --ignore-missing SHA256SUMS.txt

如果下载文件所在的行显示 OK，即表示文件没有问题。
