03 / ইনস্টল করুন

For Gemini CLI, extract the extension and install the directory containing gemini-extension.json and GEMINI.md using your current CLI's extension workflow.

ডাউনলোড করা ফোল্ডার খুলে আপনার টুলের বর্তমান নির্দেশিকা অনুযায়ী রেজিস্টার করুন।

04 / মূল লেখা না বদলে পরীক্ষা

প্রথমে read-only পর্যালোচনা করুন: কি কো কৌ ক্ষ স্ত্র র‍্য অ্যা। মূল Unicode ক্রম ও ZWJ/ZWNJ অক্ষত রাখুন।

Gemini Apps and Gemini CLI are different products. Installing a CLI extension does not install it in the Gemini Apps interface.

05 / আপডেট করুন

নতুন সংস্করণ এলে ম্যানিফেস্ট এবং পরিবর্তনের তালিকা যাচাই করে আপডেট করুন।
