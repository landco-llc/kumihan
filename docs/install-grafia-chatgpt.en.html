Install in your tool

  1. Requires an actual compatible plugin or Skills interface. Codex also supports project Skills directories.
  2. The full plugin extracts to kumihan-grafia/ with plugin.json and .codex-plugin/plugin.json. Import only through the feature your client exposes. For Codex Skills, extract the individual folder into the project’s .agents/skills/ directory.
  3. ChatGPT Skills upload depends on account capabilities. Attaching a ZIP to a conversation does not register a plugin. Without an install interface, use the source as manual guidance.

Download and verify

Compare SHA256 and byte length with MANIFEST.json before installation. With all 17 Release files in one directory: sha256sum -c SHA256SUMS.txt (macOS: shasum -a 256 -c SHA256SUMS.txt). For a single ZIP verify its individual entry.
