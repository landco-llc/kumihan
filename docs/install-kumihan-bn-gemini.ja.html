Gemini CLI extension or portable Skills.

03 / 導入する

For Gemini CLI, extract the extension and install the directory containing gemini-extension.json and GEMINI.md using your current CLI's extension workflow.

配布物を展開し、各ホストの現行ドキュメントに従ってフォルダを登録してください。

04 / 原稿を変えずに試す

最初は読み取り専用で「কি কো কৌ ক্ষ স্ত্র র‍্য অ্যা」を確認し、Unicode格納順とZWJ/ZWNJを保持してください。

Gemini Apps and Gemini CLI are different products. Installing a CLI extension does not install it in the Gemini Apps interface.

05 / 更新する

更新時はマニフェストと変更履歴を確認してからパッケージを入れ替えます。

06 / 対象と制約

静的検査だけでは実際の描画・言語の正確さ・導入成功は証明できません。別途検証が必要です。
