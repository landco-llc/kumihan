01 / Wybierz format

Plugin zawiera cztery umiejętności. Każda jest też dostępna jako osobny pakiet ZIP z zasadami, profilami i źródłami. Samo dodanie ZIP do rozmowy nie musi oznaczać instalacji.

02 / Pobierz i sprawdź

Pobierz paczki ZIP tej wersji. Zweryfikuj pliki za pomocą MANIFEST.json i SHA256SUMS.txt przed instalacją. W systemie macOS użyj polecenia shasum -a 256 -c SHA256SUMS.txt.

sha256sum -c SHA256SUMS.txt
  • Plugin: kumihan-szyk-Claude-Code-plugin-v0.1.0.zip
  • Pojedyncza umiejętność: kumihan-szyk-Claude-skill-v0.1.0.zip
  • Pojedyncza umiejętność: kumihan-szyk-web-Claude-skill-v0.1.0.zip
  • Pojedyncza umiejętność: kumihan-szyk-documents-Claude-skill-v0.1.0.zip
  • Pojedyncza umiejętność: kumihan-szyk-review-Claude-skill-v0.1.0.zip

SHA256SUMS.txt · MANIFEST.json · GitHub Release v0.1.0

03 / Zainstaluj

Rozpakuj plugin dla Claude Code jako folder kumihan-szyk. Sprawdź dostępne polecenie claude plugin validate i zainstaluj zgodnie z oficjalną instrukcją. Do Claude można importować osobne umiejętności, jeśli interfejs obsługuje tę funkcję.

claude plugin validate /absolute/path/kumihan-szyk
claude --plugin-dir /absolute/path/kumihan-szyk

INSTALL.md

04 / Sprawdź bez zmian w źródle

Podaj język polski, profil regionalny, zakres i tryb pracy. Przykład:

Oceń polską typografię za pomocą kumihan-szyk-review, zachowaj oryginalne nazwy, liczby i tekst oraz oddziel uwagi od pomiarów.

Opcjonalny odczytowy skrypt kontroli statycznej:

python runtime/checks.py original.txt --locale pl --candidate candidate.txt

05 / Aktualizuj

Przed wymianą pakietu zachowaj lokalne zmiany. Sprawdź tag i sumy kontrolne. Nowy commit nie aktualizuje automatycznie zainstalowanej umiejętności.

06 / Zakres i ograniczenia

40 proponowanych reguł badawczych, 64 proponowane przypadki i ograniczone kontrole offline. To nie jest pełny korektor ani gwarancja wyglądu. Publikacja na GitHubie nie oznacza umieszczenia w oficjalnych katalogach narzędzi AI.
