導入手順

  1. 前提：Claude Code CLI。Claude chatのSkillsアップロードはアカウント機能に依存します。
  2. 完全プラグインを展開し、claude --plugin-dir /absolute/path/kumihan-ziluで起動します。対応版ではclaude plugin validate /absolute/path/kumihan-ziluで検証します。
  3. Claude chatでは単体Skill ZIPを実際のSkills導入口からアップロードします。セッション単位の読込みと公式商店掲載は別です。
