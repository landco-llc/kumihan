DOCUMENTATION / Claudeধাপ ও সতর্কতা

এই নির্দেশিকায় Claude Code ও Claude চ্যাটে KUMIHAN｜অক্ষরসজ্জা ব্যবহারের ধাপগুলো বলা হয়েছে।

v0.1.0 সম্পর্কে এই সংস্করণটি নিজের পরিবেশে ইনস্টল করে দেখার জন্য। প্রতিটি টুলে এটি কীভাবে কাজ করে, তা এখনও পুরোপুরি যাচাই করা হয়নি, তাই এটি ঠিকমতো কাজ নাও করতে পারে।

1. ইনস্টলের পদ্ধতি বেছে নিন

কোথায় ব্যবহার করতে চানপ্রস্তাবিত পদ্ধতি
Claude Code (ZIP থেকে ইনস্টল করতে চাইলে)A. ZIP থেকে ইনস্টল করুন
Claude চ্যাট (claude.ai ও অ্যাপ)B. স্কিল আপলোড করুন

Claude Code ও Claude চ্যাটে ইনস্টলের পদ্ধতি আলাদা।

A. Claude Code: ZIP থেকে ইনস্টল করুন

  1. Claude Code প্লাগইনের ZIP ডাউনলোড করুন।
  2. ZIP খুললে kumihan-bn ফোল্ডার তৈরি হবে।
  3. সেই ফোল্ডারটি নির্দিষ্ট করে Claude Code চালু করুন।
    claude --plugin-dir "/absolute/path/kumihan-bn"

লক্ষ করুন

  • ফোল্ডারের ভেতরের ফাইলগুলো যেমন আছে তেমনই ব্যবহার করুন। কোনো ফাইল মুছবেন না বা অন্য ফাইল মেশাবেন না।
  • এই পদ্ধতিতে স্বয়ংক্রিয়ভাবে আপডেট হয় না। নতুন সংস্করণ এলে ZIP বদলে দিন।

B. Claude চ্যাট: স্কিল আপলোড করুন

এটি claude.ai বা Claude অ্যাপে ব্যবহারের পদ্ধতি।

  1. যে স্কিলগুলো ব্যবহার করতে চান, সেগুলোর ZIP ডাউনলোড করুন।
    • kumihan-bn — শুরুর জায়গা
    • kumihan-bn-web — ওয়েব পৃষ্ঠা
    • kumihan-bn-documents — প্রতিবেদন ও স্লাইড
    • kumihan-bn-review — পর্যালোচনা
  2. Claude-এ Customize → Skills খুলুন এবং যোগ করার বোতাম থেকে Upload a skill বেছে নিন।
  3. ZIP ফাইলগুলো একটি একটি করে আপলোড করুন এবং স্কিল চালু করুন।

লক্ষ করুন

  • Claude Code প্লাগইনের ZIP এখানে কাজ করে না। স্কিলের ZIP ব্যবহার করুন।
  • ZIP ফাইলের নাম না বদলে আপলোড করুন।
  • স্কিল ব্যবহার করতে সেটিংসে “কোড এক্সিকিউশন” চালু থাকতে হবে। বিস্তারিত জানতে Claude-এর অফিশিয়াল নির্দেশিকা দেখুন।
  • প্রতিষ্ঠানের অ্যাকাউন্টে অ্যাডমিনের সেটিং অনুযায়ী এটি ব্যবহার করা নাও যেতে পারে।
  • আপলোড করা স্কিল স্বয়ংক্রিয়ভাবে আপডেট হয় না। নতুন সংস্করণ এলে আবার আপলোড করুন।

2. ব্যবহার করে দেখুন

শুরুতে এমন অনুরোধ দিয়ে চেষ্টা করা ভালো, যাতে কোনো ফাইল বদলায় না।

আমি বাংলায় একটি ওয়েব পৃষ্ঠা তৈরি করার পরিকল্পনা করছি। কোন কোন বিষয়ে খেয়াল রাখা উচিত, বলুন। কোনো ফাইল পরিবর্তন করবেন না।

ফাইল ঠিক আছে কি না যাচাই করুন (ঐচ্ছিক)

ডাউনলোড করা ফাইল নষ্ট হয়নি কি না যাচাই করতে চাইলে SHA256SUMS.txt ব্যবহার করুন।

ডাউনলোড করা ZIP ফাইলগুলো যে ফোল্ডারে আছে, সেখানেই SHA256SUMS.txt রাখুন এবং টার্মিনালে নিচের কমান্ডটি চালান। shasum না থাকলে Windows PowerShell-এর Get-FileHash বা অনুরূপ কোনো উপায়ে SHA-256 মিলিয়ে দেখুন।

shasum -a 256 -c --ignore-missing SHA256SUMS.txt

ডাউনলোড করা ফাইলের সারিতে OK দেখা গেলে ফাইলটি ঠিক আছে।
