DOCUMENTATION / GeminiSteps & guidance

01 / Install for your platform

  1. Use Gemini CLI with Extensions support. Extract the archive and locate gemini-extension.json at the folder root.
  2. Install the local folder with the command below and review the permission prompt.
  3. Individual skill archives are separate. Gemini Apps import is manual and unverified; a CLI extension is not a chat-app import package.
gemini extensions install /absolute/path/kumihan-ar

02 / Downloads and verification

Release packages

  • kumihan-ar-Gemini-CLI-extension-v0.1.0.zip
  • kumihan-ar-Gemini-Apps-skill-v0.1.0.zip
  • kumihan-ar-web-Gemini-Apps-skill-v0.1.0.zip
  • kumihan-ar-documents-Gemini-Apps-skill-v0.1.0.zip
  • kumihan-ar-review-Gemini-Apps-skill-v0.1.0.zip

Compare SHA-256 with the published checksum file. With your five selected ZIPs in one directory, run the GNU command below and confirm that all five are reported OK. For a single ZIP, compare its hash with MANIFEST.json; on macOS use shasum -a 256 and compare the matching entry.

sha256sum --ignore-missing -c SHA256SUMS.txt

03 / Use and update

Use kumihan-ar-review to review this page without changing source text, names or numbers. Separate static findings from rendering you actually observed.

Back up customizations and verify the new version before reinstalling. Attaching a file to chat does not establish skill installation.

These are assisted workflows, not typography certification. Native host installation and invocation are not checked. Arabic copy needs native-speaker review.
