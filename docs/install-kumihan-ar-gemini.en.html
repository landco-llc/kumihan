Install for your platform

  1. Use Gemini CLI with Extensions support. Extract the archive and locate gemini-extension.json at the folder root.
  2. Install the local folder with the command below and review the permission prompt.
  3. Individual skill archives are separate. Gemini Apps import is manual and unverified; a CLI extension is not a chat-app import package.
gemini extensions install /absolute/path/kumihan-ar
