01 / प्रारूप चुनें

प्लगइन में चारों Skills हैं। हर स्वतंत्र Skill में उसके नियम, संदर्भ और आइकन भी हैं। चैट में ZIP संलग्न करना प्लगइन स्थापित करना नहीं है।

02 / डाउनलोड और सत्यापन

GitHub Release v0.1.0 से ZIP लें और SHA256SUMS.txt से SHA-256 मिलाएँ।

  • स्वतंत्र Skill: kumihan-hi-web-gemini-skill-v0.1.0.zip

03 / स्थापना

एक्सटेंशन निकालें और kumihan-hi फ़ोल्डर में gemini-extension.json की पुष्टि करें। उसी पथ से CLI एक्सटेंशन स्थापित करें। Gemini ऐप में फ़ाइल संलग्न करने से CLI एक्सटेंशन स्थापित नहीं होता।

gemini extensions install /absolute/path/kumihan-hi
gemini extensions list

INSTALL.md

04 / मूल पाठ बदले बिना आज़माएँ

भाषा, लिपि, locale, पाठक, माध्यम, कार्य और पाठ बदलने का अधिकार बताएँ। उदाहरण:

kumihan-hi-review से क्षि क्षी त्रि ज्ञ श्र स्त्री की समीक्षा करें। मूल पाठ न बदलें। स्थिर जाँच, वास्तविक प्रदर्शन और NOT_CHECKED को अलग रखें।

वैकल्पिक स्थिर जाँच; केवल पढ़ती है:

python runtime/checks.py original.txt --candidate candidate.txt

05 / अपडेट

अपनी स्थानीय सेटिंग सुरक्षित रखें, नए संस्करण के चेकसम जाँचें और होस्ट के समर्थित तरीके से अपडेट करें। अन्य भाषा के प्लगइन न बदलें।

06 / सीमा और प्रमाण

GitHub पर प्रकाशन आधिकारिक ChatGPT, Claude या Gemini निर्देशिका की स्वीकृति नहीं है। स्थिर जाँच वास्तविक फ़ॉन्ट, उपकरण या मातृभाषी समीक्षा का विकल्प नहीं है। नई हिंदी प्रति मातृभाषी द्वारा जाँची नहीं गई है।
