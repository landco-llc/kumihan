KUMIHAN｜विन्यास Gemini CLI-मध्ये Gemini-अनुप्रयोगे च कथं प्रयोक्तव्यम् इति अस्यां मार्गदर्शिकायां वर्ण्यते।

v0.1.0 विषये एतत् संस्करणं स्वपरिवेशे स्थापनं परीक्षितुम् अभिप्रेतम्। प्रत्येकस्मिन् साधने अस्य व्यवहारः अद्यापि सम्पूर्णतया न परीक्षितः, अतः केचन क्रमाः यथापेक्षं न सिध्येयुः।

1. स्थापनविधिं वृणोतु

उपयोगस्थानम्अनुशंसितः विधिः
Gemini CLI (चत्वारि कौशलानि सह)A. विस्तारकरूपेण स्थापयतु
Gemini CLI (केवलम् आवश्यकानि कौशलानि)B. एकैकं कौशलं स्थापयतु
Gemini-अनुप्रयोगः (जालम्, Mac, चलदूरवाणी)C. कौशलानि उपारोपयतु

A. Gemini CLI : विस्तारकरूपेण स्थापयतु

अनेन चत्वारि कौशलानि एकवारं स्थाप्यन्ते।

  1. विस्तारक-ZIP (extension) अवतारयतु।
  2. तस्य विस्तारणेन kumihan-vinyasa इति कोशः प्राप्यते।
  3. तस्मात् कोशात् स्थापयतु —
    gemini extensions install "/absolute/path/kumihan-vinyasa"

अग्रे गमनात् पूर्वं पुष्टीकरणसन्देशं परीक्षताम्। स्थापनानन्तरं विस्तारकः सर्वासु परियोजनासु सक्रियः भवति।

ZIP-तः स्थापितः विस्तारकः स्वयम् अद्यतनः न भवति। नूतने संस्करणे प्रकाशिते नूतनेन ZIP-इत्यनेन परिवर्तयतु।

B. Gemini CLI : एकैकं कौशलं स्थापयतु

अनेन केवलम् आवश्यकानि कौशलानि एकस्यै परियोजनायै स्थाप्यन्ते। A-विधिना स्थापिते अयं क्रमः अनावश्यकः।

उदाहरणार्थं kumihan-vinyasa स्थापयितुं परियोजनायाम् अधोलिखितं चालयतु —

gemini skills install https://github.com/landco-llc/kumihan --path plugins/kumihan-vinyasa/skills/kumihan-vinyasa --scope workspace

अन्येषां कौशलानां कृते --path एवं परिवर्तयतु —

  • plugins/kumihan-vinyasa/skills/kumihan-vinyasa-web — जालपुटानि
  • plugins/kumihan-vinyasa/skills/kumihan-vinyasa-documents — प्रतिवेदनानि प्रस्तुतयः च
  • plugins/kumihan-vinyasa/skills/kumihan-vinyasa-review — समीक्षणम्

--scope workspace इति कौशलम् अस्याम् एव परियोजनायां सीमयति। तद्विना कौशलं सर्वासु परियोजनासु उपलभ्यते।

अद्यतनाय

समानम् आदेशं पुनः चालयतु। स्थापितं कौशलं परिवर्त्यते, अतः यदि भवता तस्मिन् परिवर्तनानि कृतानि, तर्हि तानि प्रथमं रक्षतु।

C. Gemini-अनुप्रयोगः : कौशलानि उपारोपयतु

  1. यानि कौशलानि प्रयोक्तुम् इच्छति तेषां ZIP-सञ्चिकाः अवतारयतु।
    • kumihan-vinyasa — प्रवेशद्वारम्
    • kumihan-vinyasa-web — जालपुटानि
    • kumihan-vinyasa-documents — प्रतिवेदनानि प्रस्तुतयः च
    • kumihan-vinyasa-review — समीक्षणम्
  2. Gemini-मध्ये Customize (न दृश्यते चेत् More) → Skills → Upload उद्घाटयतु।
  3. एकैकां ZIP-सञ्चिकां चित्वा विवरणं परीक्ष्य Create इति वृणोतु।

अवधेयम्

  • अष्टादशवर्षाधिकवयस्कानां वैयक्तिकेषु Google-खातेषु एव उपलभ्यते। कार्यालयस्य विद्यालयस्य वा खातेषु सम्प्रति न समर्थ्यते।
  • Keep Activity सक्रियं भवेत्।
  • इयं सुविधा क्रमशः प्रसार्यते, अतः भवतः कृते अद्यापि अनुपलब्धा स्यात्। Gemini-साहाय्यं पश्यतु।
  • विस्तारक-ZIP (Gemini CLI-कृते) अत्र न कार्यं करोति।
  • उपारोपितानि कौशलानि स्वयम् अद्यतनानि न भवन्ति। नूतने संस्करणे प्रकाशिते पुनः उपारोपयतु।

2. प्रयोगं करोतु

प्रथमं सञ्चिकाः अपरिवर्तयन्त्या प्रार्थनया आरभताम् इति अनुशंस्यते —

संस्कृत-भाषायां प्रस्तुतिं रचयितुम् इच्छामि। किं किम् अवधातव्यम्? कृपया काम् अपि सञ्चिकां मा परिवर्तयतु।

अवतारितसञ्चिकानां परीक्षणम् (वैकल्पिकम्)

अवतारिताः सञ्चिकाः अक्षताः इति परीक्षितुं SHA256SUMS.txt प्रयुज्यताम्।

अवतारिताभिः ZIP-सञ्चिकाभिः सह एकस्मिन् एव कोशे SHA256SUMS.txt स्थापयित्वा टर्मिनल्-मध्ये अधोलिखितम् आदेशं चालयतु। यदि shasum नास्ति, तर्हि Windows-मध्ये PowerShell Get-FileHash इत्यादिना समानेन SHA-256-आदेशेन मेलनं करोतु।

shasum -a 256 -c --ignore-missing SHA256SUMS.txt

अवतारितसञ्चिकानां पङ्क्तिषु OK इति दृश्यते चेत् सञ्चिकाः अक्षताः।

पटलानि उपलब्धिः च परिवर्तेरन्। नवीनतमसूचनायै प्रत्येकसेवायाः आधिकारिकमार्गदर्शनं पश्यतु (अन्तिमपरीक्षणम् : १४ अक्टोबर् २०२६)।
