導入ガイド

導入形式を選ぶ

プラグインは4スキルをまとめたものです。単独スキルにもルールと参考資料を同梱しています。会話へのZIP添付はインストールではありません。

  • プラグイン一式: kumihan-nhip-chu-gemini-cli-extension-v0.1.0.zip
  • 単独スキル: kumihan-nhip-chu-gemini-skill-v0.1.0.zip

ダウンロードと照合

GitHub Releaseから利用ホスト用のv0.1.0 ZIPをダウンロードし、SHA256SUMS.txtと照合してください。

kumihan-nhip-chu-gemini-cli-extension-v0.1.0.zip

SHA256SUMS.txt · MANIFEST.json

4 Skills

  • kumihan-nhip-chu-gemini-skill-v0.1.0.zip
  • kumihan-nhip-chu-web-gemini-skill-v0.1.0.zip
  • kumihan-nhip-chu-documents-gemini-skill-v0.1.0.zip
  • kumihan-nhip-chu-review-gemini-skill-v0.1.0.zip

インストール

gemini-extension.jsonが製品フォルダに入るよう展開してGemini CLIで導入します。Geminiチャットアプリへの導入は未検証です。

コマンド例

gemini extensions install /absolute/path/kumihan-nhip-chu
gemini extensions list

元原稿を変更せずに確認

静的チェッカーは候補を示すだけです。フォントの実描画とAIホストでの起動は別途実行して確認してください。

KUMIHAN｜Nhịp Chữを使って、このベトナム語ページを読み取り専用でレビューしてください。声調記号と原文を保持し、実測と未検証を区別してください。

python runtime/checks.py input.txt --locale vi-VN

更新する

カスタマイズを保管し、バージョンとハッシュを確認して更新します。GitHubの更新は既存インストールには自動反映されません。

制限事項
