KUMIHAN｜Grafía · Gemini CLI · v0.1.0

ChatGPT / CodexClaude CodeGemini CLI

Instalar en tu herramienta

  1. Necesitas Gemini CLI con Extensions. No se ha comprobado la importación de Skills en Gemini Apps.
  2. Extrae el ZIP de extensión en una carpeta vacía: gemini-extension.json debe estar directamente en su raíz. Ejecuta gemini extensions install /ruta/absoluta/carpeta y lee la solicitud de consentimiento.
  3. No instales la raíz de este monorepo como Grafía. Los Skills independientes siguen el flujo Skills de tu versión del CLI; la disponibilidad en Apps requiere comprobar la cuenta.

Descargar y verificar

Compara SHA256 y tamaño con MANIFEST.json antes de instalar. Con los 17 archivos del Release en una carpeta: sha256sum -c SHA256SUMS.txt (macOS: shasum -a 256 -c SHA256SUMS.txt). Para un ZIP, verifica su entrada individual.
