01 / 導入手順

  1. 前提：プラグインまたはSkillsの導入口があるアカウントとクライアント。完全プラグインと単体Skillは別の配布物です。
  2. 完全ZIPを展開し、クライアントが提供するプラグイン導入口でkumihan-ziluフォルダを選びます。Skillsのみ対応する場合は、下の独立Skill ZIPをSkills導入口でインストールします。
  3. 会話への添付だけではインストールになりません。実Hostの発見・アイコン表示・呼出は未検証です。導入口がなければソースを手動参照してください。

02 / ダウンロードと検証

downloads内で sha256sum -c SHA256SUMS.txt（macOSは shasum -a 256 -c）を実行します。単体ZIPのみならMANIFEST.jsonの該当SHA256と照合します。

  • kumihan-zilu-entry-skill-v0.1.0.zip
  • kumihan-zilu-web-skill-v0.1.0.zip
  • kumihan-zilu-documents-skill-v0.1.0.zip

03 / 起動と更新

kumihan-zilu-reviewで、原文・数字・商標を保持して簡体中国語ページをレビューしてください。

请保留原文与数字，使用 kumihan-zilu-web 检查页面。

Use kumihan-zilu-documents to review a report while preserving its source text.

更新前に独自設定を保存し、新版のハッシュを照合してHostの更新・再インストール手順を使います。導入口がない場合はGitHubのSKILL.mdを手動の指針として参照できます。プラグインの導入済みとは扱いません。

ソースとWebページを公開しています。各AIツールでのネイティブなプラグイン呼出、アプリストア掲載、Office・PDFの表示品質は別の検証事項です。

四个独立Skills：入口与范围、网页与界面、文档与演示、只读审查。

Four independent skills: start and scope, web and interfaces, documents and slides, read-only review.
