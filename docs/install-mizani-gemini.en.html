DOCUMENTATION / GeminiSteps and notes

01 / Choose a format

The plugin contains all four skills. Each skill is also distributed on its own, with its rules and references. Attaching a ZIP to a chat does not install anything.

02 / Download and verify

Download the ZIP files from GitHub Release v0.1.0 and compare their SHA-256 with SHA256SUMS.txt before installing.

  • Plugin: kumihan-mizani-gemini-cli-extension-v0.1.0.zip
  • Individual skill: kumihan-mizani-gemini-skill-v0.1.0.zip
  • Individual skill: kumihan-mizani-web-gemini-skill-v0.1.0.zip
  • Individual skill: kumihan-mizani-documents-gemini-skill-v0.1.0.zip
  • Individual skill: kumihan-mizani-review-gemini-skill-v0.1.0.zip

SHA256SUMS.txt · MANIFEST.json · GitHub Release v0.1.0

03 / Install

Extract the extension with gemini-extension.json under kumihan-mizani, then install from that folder with Gemini CLI. Gemini Apps use is a separate, unverified workflow.

gemini extensions install /absolute/path/kumihan-mizani
gemini extensions list

INSTALL.md

04 / Try it without changing the source

Specify Swahili locale (sw-TZ, sw-KE etc.), medium, house style and edit permission. Example:

Use kumihan-mizani-review for this Swahili page. Preserve ng’ and all source text; report confirmed issues and unchecked items separately.

Optional read-only static check:

python runtime/checks.py input.txt --locale sw-TZ

05 / Update

Save your customizations, verify the new version and its checksums, then update the way your tool supports. A new commit alone does not update an existing installation. Do not overwrite plugins for other languages.

06 / Scope and limits

24 proposed Swahili checks and a source-byte comparator are supplied. Browser rendering, native host registration, marketplace listing and native editorial review are not verified.
