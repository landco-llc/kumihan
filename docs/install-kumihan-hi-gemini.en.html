DOCUMENTATION / GeminiSteps and notes

01 / Choose a format

The plugin contains all four skills. Each skill is also distributed on its own, with its rules and references. Attaching a ZIP to a chat does not install anything.

02 / Download and verify

Download the ZIP files from GitHub Release v0.1.0 and compare their SHA-256 with SHA256SUMS.txt before installing.

  • Plugin: kumihan-hi-gemini-cli-extension-v0.1.0.zip
  • Individual skill: kumihan-hi-gemini-skill-v0.1.0.zip
  • Individual skill: kumihan-hi-web-gemini-skill-v0.1.0.zip
  • Individual skill: kumihan-hi-documents-gemini-skill-v0.1.0.zip
  • Individual skill: kumihan-hi-review-gemini-skill-v0.1.0.zip

SHA256SUMS.txt · MANIFEST.json · GitHub Release v0.1.0

03 / Install

Extract the extension into an empty folder, confirm that gemini-extension.json is inside the kumihan-hi folder, then install it from that path. Do not install the repository root as the extension: it is the Japanese product. Import into the Gemini app has not been verified.

gemini extensions install /absolute/path/kumihan-hi
gemini extensions list

INSTALL.md

04 / Try it without changing the source

State Hindi/Devanagari, locale, reader, medium, task mode and content policy. Example:

Use kumihan-hi-review to review क्षि क्षी त्रि ज्ञ श्र स्त्री without changing the original. Separate static evidence, rendering observations and NOT_CHECKED.

Optional static check (read-only):

python runtime/checks.py original.txt --candidate candidate.txt

05 / Update

Save your customizations, verify the new version and its checksums, then update the way your tool supports. A new commit alone does not update an existing installation. Do not overwrite plugins for other languages.

06 / Scope and limits

Publishing on GitHub is not a listing in the official ChatGPT, Claude, or Gemini directories. Actual behavior and rendering must be checked in each tool. Static checks do not replace review by a native Hindi editor.
