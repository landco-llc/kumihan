03 / Install

Place the extracted folder in the directory or plugin manager supported by your ChatGPT/Codex environment. Availability differs by client and account; a generic ZIP is not automatically a ChatGPT App.

Extract the package and register its directory using your host's current documentation.

04 / Test without editing

Begin with a read-only review: কি কো কৌ ক্ষ স্ত্র র‍্য অ্যা. Preserve Unicode order and ZWJ/ZWNJ.

For user-imported Skills, import the individual skill where the host supports it. Apps SDK requires a distinct MCP-backed app; this ZIP is not a remotely hosted ChatGPT App.

05 / Update

For each new version, check the manifest and release notes before replacing a package.

06 / Scope and limitations

Static checks do not prove glyph rendering, linguistic correctness or host installation. Verify these separately.
