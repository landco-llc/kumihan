01 / Выбрать пакет

Четыре самостоятельных Skills и объединяющий плагин.

02 / Скачать и проверить

Скачайте архивы ZIP v0.1.0 и проверьте SHA256SUMS.txt.

  • Плагин: kumihan-lad-gemini-cli-extension-v0.1.0.zip
  • Отдельный Skill: kumihan-lad-gemini-skill-v0.1.0.zip
  • Отдельный Skill: kumihan-lad-web-gemini-skill-v0.1.0.zip
  • Отдельный Skill: kumihan-lad-documents-gemini-skill-v0.1.0.zip
  • Отдельный Skill: kumihan-lad-review-gemini-skill-v0.1.0.zip

SHA256SUMS.txt · MANIFEST.json · GitHub Release v0.1.0

03 / Установить

В Gemini CLI используйте gemini extensions install /absolute/path/kumihan-lad и проверьте список расширений.

gemini extensions install /absolute/path/kumihan-lad
gemini extensions list

INSTALL.md

04 / Протестировать

Проверьте доступность четырёх Skills и сохранность текста; одна проверка JSON недостаточна.

Проверьте русскую типографику без изменения оригинала.

python runtime/checks.py original.txt --locale ru-RU

python runtime/checks.py input.txt --locale ru-RU

05 / Обновить

Проверьте новые контрольные суммы, сохраните настройки и переустановите пакет.
