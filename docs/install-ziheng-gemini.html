KUMIHAN｜字衡/Gemini CLI

PREVIEW 0.1.0 / Gemini CLI

在 Gemini 中安裝字衡

提供 Gemini CLI 專用擴充功能及 Gemini 應用程式的四個獨立技能 ZIP。

01 / SETUP

安裝步驟

01

下載專用的 Gemini CLI 擴充功能 ZIP 並解壓縮至新的空白資料夾。

unzip kumihan-ziheng-Gemini-CLI-extension-0.1.0-preview.zip -d /absolute/path/kumihan-ziheng
02

將此資料夾指定給 Gemini CLI 安裝指令，重新啟動工作階段後檢查技能。

gemini extensions install "/absolute/path/kumihan-ziheng"
03

GitHub monorepo 根目錄屬於「日文 KUMIHAN」擴充功能；不得直接使用根網址安裝並宣稱裝好了字衡。

gemini extensions list
04

Gemini 應用程式：若帳戶支援技能匯入，請使用下方的單一技能 ZIP，並於該主機重新驗收。
