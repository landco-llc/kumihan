DOCUMENTATION / Gemini手順と注意事項

01 / SETUP

導入手順

01

Gemini CLI拡張機能を解凍

Gemini CLI専用の拡張機能ZIPをダウンロードし、新しい空フォルダに解凍します。

unzip kumihan-ziheng-gemini-plugin-0.2.0.zip -d /absolute/path/kumihan-ziheng
02

ローカル拡張機能をインストール

そのローカルフォルダをGemini CLIに指定してインストールし、再起動後にSkillsを確認します。

gemini extensions install "/absolute/path/kumihan-ziheng"
03

字衡の導入を確認

GitHubリポジトリのルートは日本語版KUMIHANの拡張機能です。ルートURLのインストールは字衡の導入ではありません。

gemini extensions list
04

Geminiアプリにスキルを追加

Geminiアプリ：Skillsのアップロードに対応したアカウントでは、個別スキルZIPを追加して実際の動作を確認します。
