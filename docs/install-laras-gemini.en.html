DOCUMENTATION / GeminiSteps and notes

01 / Choose a format

The plugin contains all four skills. Each skill is also distributed on its own, with its rules and references. Attaching a ZIP to a chat does not install anything.

02 / Download and verify

Download the ZIP files from GitHub Release v0.1.0 and compare their SHA-256 with SHA256SUMS.txt before installing.

  • Plugin: kumihan-laras-gemini-cli-extension-v0.1.0.zip
  • Individual skill: kumihan-laras-gemini-skill-v0.1.0.zip
  • Individual skill: kumihan-laras-web-gemini-skill-v0.1.0.zip
  • Individual skill: kumihan-laras-documents-gemini-skill-v0.1.0.zip
  • Individual skill: kumihan-laras-review-gemini-skill-v0.1.0.zip

SHA256SUMS.txt · MANIFEST.json · GitHub Release v0.1.0

03 / Install

Extract the extension into an empty folder, confirm that gemini-extension.json is inside the kumihan-laras folder, then install it from that path. Do not install the repository root as the extension: it is the Japanese product. Import into the Gemini app has not been verified.

gemini extensions install /absolute/path/kumihan-laras
gemini extensions list

04 / Try it without changing the source

State the language, region (id-ID or id-ID), house style, and working mode. Example request:

Use kumihan-laras-review for this Indonesian page. Do not modify original copy; list grounded suggestions and what remains unchecked.

Optional read-only static check:

python runtime/checks.py input.txt --locale id-ID

05 / Update

Save your customizations, verify the new version and its checksums, then update the way your tool supports. A new commit alone does not update an existing installation. Do not overwrite plugins for other languages.

06 / Scope and limits

Publishing on GitHub is not a listing in the official ChatGPT, Claude, or Gemini directories. Actual behavior and rendering must be checked in each tool. Static checks do not replace review by a native Indonesian editor.
