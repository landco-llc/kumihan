DOCUMENTATION / Claude手順と注意事項

KUMIHAN｜ဟန်ချက်をClaude CodeやClaudeチャットで使うための手順です。

v0.1.0について ご自身の環境で導入を試していただくための版です。各ツールでの動作はまだ十分に確認できていないため、うまく動かない場合があります。

1. 導入方法を選ぶ

使いたい場所おすすめの方法
Claude Code（ZIPで導入したい場合）A. ZIPから導入する
Claudeチャット（claude.ai・アプリ）B. スキルをアップロードする

Claude CodeとClaudeチャットは、導入方法が異なります。

A. Claude Code：ZIPから導入する

  1. Claude Code用プラグインのZIP をダウンロードします。
  2. ZIPを展開すると、kumihan-my フォルダーができます。
  3. そのフォルダーを指定して、Claude Codeを起動します。
    claude --plugin-dir "/absolute/path/kumihan-my"

ご注意

  • フォルダーの中身は、そのまま使ってください。ファイルを削ったり、別のファイルを混ぜたりしないでください。
  • この方法では自動で更新されません。新しい版が出たら、ZIPを入れ替えてください。

B. Claudeチャット：スキルをアップロードする

claude.aiやClaudeアプリで使う方法です。

  1. 使いたいスキルのZIPをダウンロードします。
    • kumihan-my — 最初の入口
    • kumihan-my-web — Webページ
    • kumihan-my-documents — 報告書・スライド
    • kumihan-my-review — レビュー
  2. Claudeの Customize → Skills を開き、追加ボタンから Upload a skill を選びます。
  3. ZIPを1つずつアップロードし、スキルを有効にします。

ご注意

  • Claude Code用プラグインのZIPは、ここでは使えません。スキルのZIPを使ってください。
  • ZIPのファイル名は変えずにアップロードしてください。
  • スキルを使うには、設定で「コード実行」が有効になっている必要があります。詳しくは Claudeの公式案内 をご覧ください。
  • 組織のアカウントでは、管理者の設定によって使えない場合があります。
  • アップロードしたスキルは自動では更新されません。新しい版が出たら、もう一度アップロードしてください。

2. 使ってみる

最初は、ファイルを変更しない依頼で試すのがおすすめです。

ビルマ語のWebページをつくる予定です。気をつけるポイントを教えてください。ファイルは変更しないでください。

ファイルが正しいか確認する（任意）

ダウンロードしたファイルが壊れていないかを確認したい場合は、SHA256SUMS.txt を使います。

ダウンロードしたZIPファイルと同じフォルダーに SHA256SUMS.txt を置き、ターミナルで次のコマンドを実行します。shasum がない環境では、Windows PowerShellの Get-FileHash などでSHA-256を照合してください。

shasum -a 256 -c --ignore-missing SHA256SUMS.txt

ダウンロードしたファイルの行に OK と表示されれば問題ありません。
