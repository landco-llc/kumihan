KUMIHAN｜字衡/Claude Code

PREVIEW 0.1.0 / Claude Code

在 Claude 中安裝字衡

提供 Claude Code 插件，以及 Claude 應用程式可個別匯入的四個技能 ZIP。

01 / SETUP

安裝步驟

01

註冊 KUMIHAN Marketplace

Claude Code：從 GitHub 註冊 KUMIHAN marketplace（這不會修改現有日文插件）。

claude plugin marketplace add "https://github.com/landco-llc/kumihan.git#main"
02

安裝字衡插件

在 Claude Code 對話中安裝字衡插件，與日文版的名稱不同。

/plugin install kumihan-ziheng@kumihan-marketplace
03

從本機 ZIP 啟動

也可以下載 ZIP、解壓縮後以本機插件資料夾啟動。

claude --plugin-dir "/absolute/path/kumihan-ziheng"
04

匯入 Claude 應用程式技能

Claude 應用程式：若帳戶有技能匯入功能，請逐一匯入下方的單一技能 ZIP。完整插件 ZIP 不適用於此步驟。

02 / DOWNLOADS

下載與校驗
