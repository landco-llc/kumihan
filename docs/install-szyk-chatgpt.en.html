DOCUMENTATION / ChatGPT / CodexSteps and notes

01 / Choose a format

The plugin contains all four skills. Each skill is also distributed on its own, with its rules and references. Attaching a ZIP to a chat does not install anything.

02 / Download and verify

Download the ZIP files for this version and compare SHA-256 and byte length with MANIFEST.json before installing. With all 17 files in one folder, run (on macOS, shasum -a 256 -c SHA256SUMS.txt):

sha256sum -c SHA256SUMS.txt
  • Plugin: kumihan-szyk-GPT-Codex-plugin-v0.1.0.zip
  • Individual skill: kumihan-szyk-GPT-Codex-skill-v0.1.0.zip
  • Individual skill: kumihan-szyk-web-GPT-Codex-skill-v0.1.0.zip
  • Individual skill: kumihan-szyk-documents-GPT-Codex-skill-v0.1.0.zip
  • Individual skill: kumihan-szyk-review-GPT-Codex-skill-v0.1.0.zip

SHA256SUMS.txt · MANIFEST.json · GitHub Release v0.1.0

03 / Install

Use the ChatGPT / Codex plugin only through the plugin import feature your client provides; it extracts to kumihan-szyk/ with plugin.json and .codex-plugin/plugin.json. For Codex Skills, extract each folder into the project’s .agents/skills/ directory. ChatGPT Skills upload depends on your account.

mkdir -p .agents/skills

04 / Try it without changing the source

python runtime/checks.py original.txt --locale pl --candidate candidate.txt

05 / Update

Save your customizations, verify the new version and its checksum, then update the way your tool supports. A new commit alone does not update an existing installation. Do not overwrite plugins for other languages.

06 / Scope and limits

40 proposed research rules, 64 proposed fixtures and bounded offline static checks. Not a complete proofing engine or a guarantee of visual quality. GitHub Release does not mean marketplace listing or verified native-host installation.
