01 / Pilih format

Plugin memuat empat skill. Setiap skill juga tersedia sebagai arsip tersendiri bersama aturan dan sumbernya. Mengunggah ZIP ke percakapan tidak otomatis memasangnya.

02 / Unduh dan verifikasi

Unduh berkas ZIP dari GitHub Release v0.1.0 lalu cocokkan nilai SHA-256 dengan SHA256SUMS.txt.

  • Plugin: kumihan-laras-gemini-cli-extension-v0.1.0.zip
  • Skill mandiri: kumihan-laras-gemini-skill-v0.1.0.zip
  • Skill mandiri: kumihan-laras-web-gemini-skill-v0.1.0.zip
  • Skill mandiri: kumihan-laras-documents-gemini-skill-v0.1.0.zip
  • Skill mandiri: kumihan-laras-review-gemini-skill-v0.1.0.zip

SHA256SUMS.txt · MANIFEST.json · GitHub Release v0.1.0

03 / Pasang

Ekstrak ekstensi dengan gemini-extension.json di root folder kumihan-laras lalu pasang lewat Gemini CLI. Pengimporan skill di aplikasi Gemini perlu diverifikasi terpisah.

gemini extensions install /absolute/path/kumihan-laras
gemini extensions list

04 / Uji tanpa mengubah naskah

Sebutkan peran teks, medium, ragam bahasa dan izin penyuntingan. Contoh:

Gunakan kumihan-laras-review untuk meninjau halaman bahasa Indonesia ini tanpa mengubah naskah asli. Beri rekomendasi dan sebutkan hal-hal yang belum diperiksa.

Pemeriksaan statis opsional (baca-saja):

python runtime/checks.py input.txt --locale id-ID

05 / Perbarui

Simpan penyesuaian lokal, verifikasi versi serta checksum baru, lalu perbarui lewat alat yang sesuai. Pemasangan tidak otomatis diperbarui oleh commit GitHub.

06 / Cakupan dan batasan

Publikasi di GitHub tidak berarti terdaftar dalam direktori resmi ChatGPT, Claude atau Gemini. Hasil pengecekan statis tidak menggantikan pemeriksaan tampilan nyata atau penyunting manusia.
