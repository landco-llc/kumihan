သင့်ပတ်ဝန်းကျင်တွင် ဤနေရာ၌ ဖော်ပြထားသော အဆင့်အချို့ကို အသုံးပြု၍ မရနိုင်ပါ။ အသုံးပြုမည့် AI host တွင် တကယ့်လုပ်ဆောင်ပုံကို စစ်ဆေးပါ။

DOCUMENTATION / ChatGPT / Codexအဆင့်များနှင့် သတိပြုရန်များ

ဤလမ်းညွှန်သည် KUMIHAN｜ဟန်ချက် ကို ChatGPT နှင့် Codex တွင် အသုံးပြုပုံကို ရှင်းပြသည်။

v0.1.0 အကြောင်း ဤဗားရှင်းသည် သင့်ကိုယ်ပိုင် ပတ်ဝန်းကျင်တွင် တပ်ဆင်စမ်းသပ်ရန် ဖြစ်သည်။ ကိရိယာတစ်ခုချင်းစီတွင် လုပ်ဆောင်ပုံကို အပြည့်အဝ မစစ်ဆေးရသေးသဖြင့် အချို့အဆင့်များ မျှော်လင့်ထားသလို အလုပ်မလုပ်နိုင်ပါ။

1. တပ်ဆင်နည်းကို ရွေးပါ

အသုံးပြုလိုသည့်နေရာအကြံပြုထားသော နည်းလမ်း
ChatGPT (ကျွမ်းကျင်မှု upload လုပ်နိုင်လျှင်)A. ကျွမ်းကျင်မှုများကို တစ်ခုချင်း ထည့်ရန်
ChatGPT (ကိုယ်ပိုင် private plugin အဖြစ်)B. plugin အဖြစ် မှတ်ပုံတင်ရန်
Codex (သင့်ကွန်ပျူတာပေါ်တွင်)C. ကျွမ်းကျင်မှု folder များကို ကူးထည့်ရန်

ကျွမ်းကျင်မှု (skill) တစ်ခုသည် လုပ်ဆောင်ချက်တစ်ခု ဖြစ်သည်။ plugin သည် ကျွမ်းကျင်မှု လေးခုလုံးကို package တစ်ခုတည်းအဖြစ် စုစည်းထားသည်။

2. ဖိုင်များကို ဒေါင်းလုဒ်လုပ်ပါ

ဖိုင်အားလုံးကို ထုတ်ဝေမှုစာမျက်နှာ တွင် ရနိုင်သည်။ link ကို နှိပ်လျှင် ZIP ဖိုင် ဒေါင်းလုဒ်ဖြစ်မည်။

Plugin (ကျွမ်းကျင်မှု လေးခုလုံး)

  • kumihan-my-GPT-Codex-plugin-v0.1.0.zip (Source ZIP)

ကျွမ်းကျင်မှု တစ်ခုချင်း

  • kumihan-my (Source ZIP) — စတင်ရာ
  • kumihan-my-web (Source ZIP) — ဝဘ်စာမျက်နှာ
  • kumihan-my-documents (Source ZIP) — အစီရင်ခံစာနှင့် ဆလိုက်
  • kumihan-my-review (Source ZIP) — ပြန်လည်သုံးသပ်ခြင်း

A. ChatGPT တွင် ကျွမ်းကျင်မှုများ ထည့်ပါ

သင့် ChatGPT တွင် Skills နှင့် upload ရွေးချယ်စရာ ပေါ်နေလျှင် ဤနည်းကို အသုံးပြုပါ။

  1. ကျွမ်းကျင်မှု ZIP ဖိုင်တစ်ခုကို upload လုပ်ပါ။
  2. ပြသထားသော အချက်အလက်များကို စစ်ဆေးပြီး ထည့်ပါ။
  3. အသုံးပြုလိုသော ကျွမ်းကျင်မှုတိုင်းအတွက် ထပ်ခါ ပြုလုပ်ပါ။

သတိပြုရန်

  • plugin ZIP သည် ဤနည်းဖြင့် အလုပ်မလုပ်ပါ။ ကျွမ်းကျင်မှု တစ်ခုချင်း၏ ZIP ဖိုင်များကို အသုံးပြုပါ။
  • chat တွင် ဖိုင်ကို ပူးတွဲရုံဖြင့် ကျွမ်းကျင်မှုအဖြစ် မထည့်သွင်းနိုင်ပါ။
  • ရွေးချယ်စရာ မမြင်ရလျှင် သင့် plan သို့မဟုတ် app တွင် မရရှိနိုင်သေးခြင်း ဖြစ်နိုင်သည်။ OpenAI ၏ လမ်းညွှန် ကို ကြည့်ပါ။

B. ChatGPT တွင် plugin အဖြစ် မှတ်ပုံတင်ပါ

ဤနည်းဖြင့် ကျွမ်းကျင်မှု လေးခုလုံးကို သင့်ကိုယ်ပိုင် private plugin အဖြစ် မှတ်ပုံတင်နိုင်သည်။

  1. ChatGPT တွင် စကားဝိုင်းအသစ် ဖွင့်ပြီး @plugin-creator ကို ရွေးပါ။
  2. plugin ZIP ဖိုင်ကို ပူးတွဲပါ။
  3. ဤသို့ တောင်းဆိုပါ—

    ဤ package ကို ကျွန်ုပ်၏ private plugin အဖြစ် မှတ်ပုံတင်ပေးပါ။ public directory သို့ မတင်သွင်းပါနှင့်။

  4. မှတ်ပုံတင်ပြီးသည်နှင့် Plugins ၏ “Personal” သို့မဟုတ် “Created by me” အောက်တွင် KUMIHAN｜ဟန်ချက် ပေါ်လာမည်။
  5. လိုအပ်လျှင် install လုပ်ပြီး စကားဝိုင်းအသစ်တွင် ဖွင့်ပါ။

သတိပြုရန်

  • plugin ကို သင့်အဖွဲ့၏ workspace တွင် သိမ်းဆည်းနိုင်သည်။ ကိုယ်တိုင်သာ သုံးလိုလျှင် မှတ်ပုံမတင်မီ သိမ်းဆည်းမည့်နေရာကို စစ်ဆေးပါ။
  • သင့် plan သို့မဟုတ် workspace ဆက်တင်ပေါ် မူတည်၍ ဤလုပ်ဆောင်ချက်ကို မရနိုင်ပါ။ Build plugins နှင့် Plugins ကို ကြည့်ပါ။
  • ဤနည်းဖြင့် မှတ်ပုံတင်ထားသော plugin ကို သင့်အကောင့်တွင်သာ အသုံးပြုနိုင်သည်။ public directory တွင် မဖော်ပြပါ။

C. Codex အတွက် ကျွမ်းကျင်မှု folder များကို ကူးထည့်ပါ

ကျွမ်းကျင်မှု ZIP ကို ဖြည်လိုက်လျှင် kumihan-my ကဲ့သို့ folder တစ်ခု ရမည်။ ထို folder ကို Codex က ကျွမ်းကျင်မှုများ ရှာဖွေသည့်နေရာသို့ ကူးထည့်ပါ။

အသုံးပြုမည့် နယ်ပယ်ကူးထည့်ရမည့်နေရာ
project တစ်ခုတည်းတွင်သာproject အတွင်းရှိ .agents/skills/
project အားလုံးတွင်home folder ရှိ ~/.agents/skills/

ဥပမာ project တစ်ခုသို့ kumihan-my ကို ထည့်ရန်—

mkdir -p /path/to/your-project/.agents/skills
cp -R kumihan-my /path/to/your-project/.agents/skills/

သတိပြုရန်

  • folder ကို အတွင်းရှိ အရာအားလုံးနှင့်တကွ တစ်ခုလုံး ကူးပါ။ ဖိုင်အချို့သာ ပါလျှင် ကျွမ်းကျင်မှု မှန်ကန်စွာ အလုပ်မလုပ်ပါ။
  • အမည်တူ folder ရှိပြီးသားဖြစ်လျှင် overwrite မလုပ်မီ ၎င်း၏ အတွင်းရှိအရာများကို စစ်ဆေးပါ။

3. စမ်းသုံးကြည့်ပါ

စကားဝိုင်းအသစ် ဖွင့်ပြီး ကျွမ်းကျင်မှုကို ခေါ်ပါ။

ကိရိယာခေါ်ယူပုံ
ChatGPT@ မှ ရွေးပါ
Codex$ သို့မဟုတ် /skills မှ ရွေးပါ

ဖိုင်များကို မပြောင်းလဲသော တောင်းဆိုချက်ဖြင့် စတင်ရန် အကြံပြုပါသည်—

မြန်မာဘာသာဖြင့် အစီရင်ခံစာတစ်စောင် ပြုလုပ်ရန် စီစဉ်နေပါသည်။ ဘာတွေကို သတိထားသင့်ပါသလဲ။ ဖိုင်များကို မပြောင်းပါနှင့်။

ဒေါင်းလုဒ်လုပ်ထားသော ဖိုင်များကို စစ်ဆေးပါ (ရွေးချယ်နိုင်)

ဒေါင်းလုဒ်လုပ်ထားသော ဖိုင်များ ပျက်စီးမှုမရှိကြောင်း စစ်ဆေးလိုလျှင် SHA256SUMS.txt ကို အသုံးပြုပါ။

ဒေါင်းလုဒ်လုပ်ထားသော ZIP ဖိုင်များနှင့် folder တစ်ခုတည်းတွင် SHA256SUMS.txt ကို ထားပြီး terminal တွင် အောက်ပါ command ကို run ပါ။ shasum မရှိလျှင် Windows ၏ PowerShell Get-FileHash ကဲ့သို့ တူညီသော SHA-256 command ဖြင့် တိုက်စစ်ပါ။

shasum -a 256 -c --ignore-missing SHA256SUMS.txt

ဒေါင်းလုဒ်လုပ်ထားသော ဖိုင်များ၏ စာကြောင်းတွင် OK ပြလျှင် ဖိုင်များ ပြည့်စုံမှန်ကန်ပါသည်။

အခြား ကိရိယာများ— Claude · Gemini

မျက်နှာပြင်များနှင့် ရရှိနိုင်မှုတို့ ပြောင်းလဲနိုင်သည်။ နောက်ဆုံးအချက်အလက်အတွက် ဝန်ဆောင်မှုတစ်ခုချင်းစီ၏ တရားဝင်လမ်းညွှန်ကို ကြည့်ပါ (နောက်ဆုံးစစ်ဆေးသည့်ရက်— ၂၀၂၆ ခုနှစ် အောက်တိုဘာလ ၁၄ ရက်)။
