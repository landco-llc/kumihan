DOCUMENTATION / GeminiPassaggi e indicazioni

01 / Scegli il formato

Il plugin contiene tutte e quattro le skill. Ogni skill è disponibile anche da sola, con regole e riferimenti locali. Allegare uno ZIP a una chat non equivale a installarlo.

02 / Scarica e verifica

Scarica i file della stessa versione. Prima di estrarli, confronta SHA-256 e dimensioni con MANIFEST.json. Con tutti i 17 file nella stessa cartella, esegui (su macOS: shasum -a 256 -c SHA256SUMS.txt):

sha256sum -c SHA256SUMS.txt
  • Plugin: kumihan-equilibrio-Gemini-CLI-extension-v0.1.0.zip
  • Skill indipendente: kumihan-equilibrio-Gemini-Apps-skill-v0.1.0.zip
  • Skill indipendente: kumihan-equilibrio-web-Gemini-Apps-skill-v0.1.0.zip
  • Skill indipendente: kumihan-equilibrio-documents-Gemini-Apps-skill-v0.1.0.zip
  • Skill indipendente: kumihan-equilibrio-review-Gemini-Apps-skill-v0.1.0.zip

SHA256SUMS.txt · MANIFEST.json · GitHub Release v0.1.0

03 / Installa

Estrai l’estensione in una cartella vuota con gemini-extension.json alla radice. Installa da quel percorso e leggi la richiesta di autorizzazione. Non installare l’intero repository come Equilibrio. L’importazione in Gemini Apps non è verificata.

gemini extensions install /absolute/path/to/folder
gemini extensions list

INSTALL.md

04 / Prova senza modificare l’originale

Scegli separatamente it-IT o it-CH, mezzo, norme editoriali, tono e modalità di modifica. Esempio:

Usa kumihan-equilibrio-review. Conserva testo originale, numeri e nomi; separa osservazioni e proposte.

Controllo statico facoltativo, in sola lettura:

python skills/kumihan-equilibrio/runtime/checks.py original.txt --locale it-IT --candidate candidate.txt

05 / Aggiorna

Conserva le impostazioni personali e verifica versione e checksum. Aggiorna con il metodo supportato dal tuo strumento. Un nuovo commit non aggiorna automaticamente un’installazione. Mantieni gli altri plugin linguistici.

06 / Ambito e limiti

40 proposte di regole, un rilevatore limitato di candidati CSS e un confronto dei byte. I 48 casi di ricerca mantengono stati di verifica separati. Non è un correttore grammaticale completo né una certificazione visiva. Importazione nativa, icone, cataloghi dei fornitori e revisione madrelingua non verificati.
