# Package sources and verification

KUMIHAN provides standalone Skills and plugins. Consumer installation does not require the repository's build tools or a remote service.

The [public source registry](../skills/kumihan/sources/public-sources.json) identifies references and their adoption status. A citation or static check does not establish rights, language acceptance, host behavior or rendering quality. See [third-party references](../THIRD_PARTY_NOTICES.md), the [license](../LICENSE), [version policy](versioning.md) and [update instructions](updates.md).
