01 / 形式を選ぶ

4つの独立Skillを単体で導入できます。プラグインは4つをまとめて提供します。対応するホスト機能が必要です。

02 / ダウンロードと照合

GitHub Releaseからv0.1.0付きZIPを取得し、SHA256SUMS.txtで内容を照合してください。

  • プラグイン: kumihan-compasso-claude-code-plugin-v0.1.0.zip
  • 独立Skill: kumihan-compasso-claude-skill-v0.1.0.zip
  • 独立Skill: kumihan-compasso-web-claude-skill-v0.1.0.zip
  • 独立Skill: kumihan-compasso-documents-claude-skill-v0.1.0.zip
  • 独立Skill: kumihan-compasso-review-claude-skill-v0.1.0.zip

SHA256SUMS.txt · MANIFEST.json · GitHub Release v0.1.0

03 / インストール

claude --plugin-dir /absolute/path/kumihan-compasso でローカルプラグインとして読み込みます。ストア導入や単体Skillの登録は利用環境の公式手順に従ってください。

claude --plugin-dir /absolute/path/kumihan-compasso
claude plugin validate /absolute/path/kumihan-compasso
/plugin marketplace add landco-llc/kumihan
/plugin install kumihan-compasso@kumihan-marketplace

INSTALL.md

04 / 動作確認と更新

実際の一覧表示とSkillの呼び出しを確認してください。JSONの正常性だけでは動作保証になりません。

ポルトガル語の文章を原稿を変えずに文字組とデザイン面からレビューして。

python runtime/checks.py original.txt --locale pt-BR

python runtime/checks.py input.txt --locale pt-PT
