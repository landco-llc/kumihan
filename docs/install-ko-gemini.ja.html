INSTALLATION / ko-KR / v0.1.0

Gemini — 導入ガイド

KUMIHAN｜글짜임 v0.1.0は独立パッケージです。日本語版や字衡の導入は不要です。最初に利用するホストのSkill対応を確認してください。

他の導入方法

01 / 韓国語版の配布物を選ぶ

バンドルには4つのSkillを収録。1つだけ使う場合は単独ZIPを選びます。以下はすべて同じ韓国語版です。ダウンロードは一般ストア掲載や原生ホストでの導入成功を意味しません。

  • プラグインバンドルZIP — 0.1.0
  • 単独Skill — kumihan-geuljjaim
  • 単独Skill — kumihan-geuljjaim-web
  • 単独Skill — kumihan-geuljjaim-documents
  • 単独Skill — kumihan-geuljjaim-review

SHA256SUMS.txt · MANIFEST.json

取得後はファイルのSHA-256をSHA256SUMS.txtと照合して展開します。各SkillフォルダにはSKILL.mdとローカル参照が含まれます。通常のチャットへのファイル添付だけでは導入されません。

02 / 導入して再読み込み

本版には検証済みGemini拡張バンドルがありません。Gemini CLIの利用版がファイルベースSkillsに対応する場合は、各Skillフォルダをプロジェクトの .gemini/skills/ 以下へ配置し、その版の公式文書を確認してください。非対応ならローカルソースの指針を明示的に読んで利用します。原生導入済みとは表示しません。

  1. 設定と同名の既存Skillフォルダをバックアップします。韓国語版だけを置き換え、他言語版は変更しません。
  2. 選んだSkillフォルダ全体を配置します。SKILL.mdだけでは参照資料が不足します。パッケージ版は0.1.0です。
  3. ホストを開き直すかSkill一覧を再読み込みし、名前を確認します。続いて下の例文で動作を確かめます。

Gemini — Skills ↗

03 / 最初のレビュー

例文実行後、韓国語対象・原稿と数字の保持・読み取り専用の所見を確認してください。ファイル変更がなく、未実施の検査をpassedにしないことを確認します。

ko-KR의 상품 소개 페이지를 검토해 주세요. 상품명, 가격, 원산지와 숫자는 바꾸지 말고 줄바꿈과 정보 구조만 확인해 주세요.

04 / 更新と制限

同じ韓国語版のReleaseとチェックサムを確認し、旧フォルダをバックアップして交換します。再読み込み後に最初のレビューを繰り返してください。自動校正・母語話者校閲・Office/PDF・原生ホスト動作は保証しません。一般ストアには未掲載です。
