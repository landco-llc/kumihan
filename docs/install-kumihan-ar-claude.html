يشرح هذا الدليل كيفية استخدام KUMIHAN｜نضيد مع Claude Code ومحادثة Claude.

حول الإصدار v0.1.0 هذا الإصدار مخصص لتجربة التثبيت في بيئتك الخاصة. لم يُتحقَّق بعد بشكل كافٍ من عمله في كل أداة، لذا قد لا يعمل كما هو متوقع.

1. اختيار طريقة التثبيت

تختلف طريقة التثبيت بين Claude Code ومحادثة Claude.

A. Claude Code: التثبيت من ملف ZIP

  1. نزّل ملف ZIP لإضافة Claude Code.
  2. عند فك ضغط الملف، سيظهر المجلد kumihan-ar.
  3. شغّل Claude Code مع تحديد ذلك المجلد.
    claude --plugin-dir "/absolute/path/kumihan-ar"

ملاحظات

  • استخدم محتوى المجلد كما هو. لا تحذف منه ملفات ولا تضِف إليه ملفات أخرى.
  • لا تُحدَّث الإضافة تلقائيًا بهذه الطريقة. عند صدور إصدار جديد، استبدلها بملف ZIP الجديد.

B. محادثة Claude: رفع المهارات

هذه الطريقة مخصصة لاستخدام claude.ai أو تطبيقات Claude.

  1. نزّل ملفات ZIP للمهارات التي تريد استخدامها.
    • kumihan-ar — نقطة البداية
    • kumihan-ar-web — صفحات الويب
    • kumihan-ar-documents — التقارير والشرائح
    • kumihan-ar-review — المراجعة
  2. افتح Customize → Skills في Claude، ثم اختر Upload a skill من زر الإضافة.
  3. ارفع ملفات ZIP واحدًا تلو الآخر، ثم فعّل المهارة.

ملاحظات

  • لا يعمل هنا ملف ZIP الخاص بإضافة Claude Code. استخدم ملفات ZIP الخاصة بالمهارات.
  • ارفع ملفات ZIP دون تغيير أسمائها.
  • لاستخدام المهارات، يجب تفعيل «تنفيذ الشيفرة» في الإعدادات. للتفاصيل راجع الدليل الرسمي من Claude.
  • في حسابات المؤسسات، قد لا تتوفر هذه الميزة بحسب إعدادات المسؤول.
  • لا تُحدَّث المهارات المرفوعة تلقائيًا. عند صدور إصدار جديد، ارفعها مرة أخرى.

2. التجربة

ننصح بالبدء بطلب لا يغيّر أي ملفات.

أخطط لإنشاء صفحة ويب باللغة العربية. ما النقاط التي ينبغي أن أنتبه لها؟ يُرجى عدم تغيير أي ملفات.

التحقق من سلامة الملفات (اختياري)

إذا أردت التحقق من أن الملفات التي نزّلتها غير تالفة، فاستخدم SHA256SUMS.txt.

ضع SHA256SUMS.txt في المجلد نفسه الذي يحتوي على ملفات ZIP التي نزّلتها، ثم نفّذ الأمر التالي في الطرفية. إذا لم يتوفر shasum، فطابِق قيم SHA-256 باستخدام Get-FileHash في Windows PowerShell أو ما يماثله.

shasum -a 256 -c --ignore-missing SHA256SUMS.txt

إذا ظهرت OK في سطر الملف الذي نزّلته، فالملف سليم.
