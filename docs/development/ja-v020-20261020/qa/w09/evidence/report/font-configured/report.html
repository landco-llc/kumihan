表示と原稿の確認を分ける

PDFの文字抽出は原稿保存の限定的な証拠です。全ページの画像で表、注記、行末と行頭、必須情報の見え方を確認します。実際のOfficeでの表示・編集、印刷機、会場の投影距離はこの検証に含みません。

担当者への引継ぎ

元の原稿を保存し、実表示の問題は場所と条件を添えて記録します。条件不明のまま可読性を保証せず、実機で確認する項目を明示します。
