01 / パッケージを選ぶ

4つの独立スキルと、まとめて導入できるプラグインがあります。

02 / ダウンロードと照合

03 / 導入

Codexでは.agents/skills/へ展開します。ChatGPTは対応するプラグイン登録UIを利用します。ZIP添付だけでは登録されません。

04 / 動作確認

言語・地域（ru-RU・ru-RU）・編集スタイル・作業モードを明示します。依頼の例：

原稿を変えずにロシア語の文字組をレビューして。

python runtime/checks.py original.txt --locale ru-RU

python runtime/checks.py input.txt --locale ru-RU

05 / 更新
