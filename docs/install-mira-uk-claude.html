Тут пояснено, як користуватися KUMIHAN｜Міра у Claude Code та чаті Claude.

Про версію v0.1.0 Ця версія призначена для того, щоб ви могли спробувати встановлення у своєму середовищі. Роботу в кожному інструменті ще не перевірено достатньою мірою, тому деякі кроки можуть працювати не так, як очікується.

1. Виберіть спосіб встановлення

Де ви хочете користуватисяРекомендований спосіб
Claude Code (встановлення із ZIP)A. Встановити із ZIP
Чат Claude (claude.ai і застосунки)B. Завантажити навички

Claude Code і чат Claude встановлюються різними способами.

A. Claude Code: встановлення із ZIP

  1. Завантажте ZIP-файл плагіна для Claude Code (Source ZIP).
  2. Після розпакування ZIP-файлу з’явиться тека kumihan-mira-uk.
  3. Запустіть Claude Code, указавши цю теку:
    claude --plugin-dir "/absolute/path/kumihan-mira-uk"

Зверніть увагу

  • Використовуйте теку як є. Не видаляйте з неї файлів і не додавайте інших.
  • За цього способу оновлення не встановлюються автоматично. Коли вийде нова версія, замініть теку вмістом нового ZIP-файлу.

B. Чат Claude: завантаження навичок

Цей спосіб підходить для claude.ai і застосунків Claude.

  1. Завантажте ZIP-файли потрібних навичок.
    • kumihan-mira-uk (Source ZIP) — відправна точка
    • kumihan-mira-uk-web (Source ZIP) — вебсторінки
    • kumihan-mira-uk-documents (Source ZIP) — звіти й слайди
    • kumihan-mira-uk-review (Source ZIP) — перевірка
  2. У Claude відкрийте Customize → Skills і за допомогою кнопки додавання виберіть Upload a skill.
  3. Завантажте ZIP-файли по одному й увімкніть кожну навичку.

Зверніть увагу

  • ZIP-файл плагіна для Claude Code тут не підійде. Використовуйте ZIP-файли окремих навичок.
  • Завантажуйте ZIP-файли, не перейменовуючи їх.
  • Для роботи навичок у налаштуваннях має бути ввімкнено виконання коду. Докладніше — в офіційному посібнику Claude.
  • В облікових записах організацій доступність може залежати від налаштувань адміністратора.
  • Завантажені навички не оновлюються автоматично. Коли вийде нова версія, завантажте їх ще раз.

Перевірте файли (необов’язково)

Якщо хочете переконатися, що завантажені файли не пошкоджено, скористайтеся SHA256SUMS.txt.

Покладіть SHA256SUMS.txt у ту саму теку, що й завантажені ZIP-файли, і виконайте в терміналі таку команду. Якщо shasum недоступна, звірте SHA-256 іншим способом, наприклад за допомогою Get-FileHash у Windows PowerShell.

shasum -a 256 -c --ignore-missing SHA256SUMS.txt

Якщо в рядках завантажених файлів указано OK, усе гаразд.
