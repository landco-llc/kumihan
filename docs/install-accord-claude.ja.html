01 / 導入形式を選ぶ

プラグインには4つのスキルがすべて入っています。各スキルは、ルールと参考資料をそろえた単体でも配布しています。チャットにファイルを添付しただけでは導入されません。

02 / ダウンロードと照合

GitHub Release v0.1.1からZIPを取得し、導入前にSHA256SUMS.txtとSHA-256を照合してください。

  • プラグイン: kumihan-accord-claude-code-plugin-v0.1.1.zip
  • 個別スキル: kumihan-accord-claude-skill-v0.1.1.zip
  • 個別スキル: kumihan-accord-web-claude-skill-v0.1.1.zip
  • 個別スキル: kumihan-accord-documents-claude-skill-v0.1.1.zip
  • 個別スキル: kumihan-accord-review-claude-skill-v0.1.1.zip

SHA256SUMS.txt · MANIFEST.json · GitHub Release v0.1.1

03 / 導入する

Claude Codeプラグインを、kumihan-accordフォルダを保ったまま展開し、そのフォルダを指定してClaude Codeを起動します。リポジトリのマーケットプレイスからも導入できます。Claudeでは、アカウントにSkillsの画面がある場合に個別スキルを取り込みます。

claude --plugin-dir /absolute/path/kumihan-accord
claude plugin validate /absolute/path/kumihan-accord
/plugin marketplace add landco-llc/kumihan
/plugin install kumihan-accord@kumihan-marketplace

04 / 原稿を変えずに試す

言語・編集スタイル・作業モードを明示します。依頼の例：

kumihan-accord-reviewで、このフランス語のページを編集スタイルfr-fr-editorialで、原文を変えずにレビューしてください。確認できた点と、まだ確認が必要な点を分けてください。

任意の静的チェック（読み取り専用）：

python runtime/checks.py input.txt --locale fr-FR --house-style fr-fr-editorial

05 / 更新

カスタマイズを保存し、新しいバージョンとチェックサムを確認してから、ツールが対応する方法で更新します。新しいコミットだけでは既存の導入は更新されません。他言語のプラグインは上書きしないでください。

06 / 対応範囲と限界

GitHubでの公開は、ChatGPT・Claude・Geminiの公式ディレクトリへの掲載を意味しません。各ツールでの動作と実際の表示は、実行して確かめる必要があります。静的チェックは、フランス語の編集者による確認の代わりにはなりません。
