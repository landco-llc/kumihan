DOCUMENTATION / GeminiSteps & guidance

01 / Choose a delivery format

Choose the independent plugin or an individual skill for your host. Neither Japanese KUMIHAN nor ZiHeng is required. A plugin ZIP is not a skill ZIP; attaching a ZIP to a chat does not install a plugin.

02 / Download

Download the 15 versioned ZIP archives from GitHub Release v0.1.1 and verify SHA256SUMS and MANIFEST. Native installation and invocation remain unverified.

  • Independent plugin: kumihan-th-Gemini-CLI-extension-v0.1.1.zip
  • Individual skill: kumihan-th-Gemini-Apps-skill-v0.1.1.zip
  • Individual skill: kumihan-th-web-Gemini-Apps-skill-v0.1.1.zip
  • Individual skill: kumihan-th-documents-Gemini-Apps-skill-v0.1.1.zip
  • Individual skill: kumihan-th-review-Gemini-Apps-skill-v0.1.1.zip

03 / Installation steps

Download and extract the desired skill. Read SKILL.md and its bundled references. If your host has no supported installation flow, provide those files as task context and describe this as instruction-guided use, rather than native installation.

Gemini CLI: extract the extension and run gemini extensions link /absolute/path/kumihan-th. Technical installed ID: kumihan-th. Gemini Apps: use individual Skill ZIPs only if an import feature exists; otherwise use as task context. Native import acceptance: not-checked.

Read source documentation

04 / Test without editing

Review line breaks and Thai vowel/tone marks in “น้ำชา เก่ง ภาษาไทย” without modifying the source. Separate observed checks from items that need manual review.

native installation: not-checked · native invocation: not-checked

05 / Updates

Keep the previous version before updating. Verify the new tag and SHA256SUMS, then replace only this product’s directory. Restore the previous package to roll back. Uninstall through your host’s skill/plugin manager, or remove the instructions from task context.

06 / Known limits

Native installation and invocation across all hosts: not-checked. Segmentation and rendering depend on the engine, fonts and environment. Actual rendering and meaning need human review. No universal automatic typesetting correction is promised.

Native Thai editorial review: needs-review
