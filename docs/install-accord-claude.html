01 / Choisir le format

Le plugin regroupe les quatre skills. Chaque skill est aussi disponible seul, avec ses règles et ses références. Un fichier joint dans une conversation n’est pas une installation.

02 / Télécharger et vérifier

Téléchargez les ZIP depuis GitHub Release v0.1.1 et comparez leur empreinte SHA-256 avec SHA256SUMS.txt avant l’installation.

  • Plugin: kumihan-accord-claude-code-plugin-v0.1.1.zip
  • Skill individuel: kumihan-accord-claude-skill-v0.1.1.zip
  • Skill individuel: kumihan-accord-web-claude-skill-v0.1.1.zip
  • Skill individuel: kumihan-accord-documents-claude-skill-v0.1.1.zip
  • Skill individuel: kumihan-accord-review-claude-skill-v0.1.1.zip

SHA256SUMS.txt · MANIFEST.json · GitHub Release v0.1.1

03 / Installer

Décompressez le plugin Claude Code en conservant le dossier kumihan-accord, puis lancez Claude Code avec ce dossier. Vous pouvez aussi passer par le marketplace du dépôt. Pour Claude, importez un skill individuel via l’interface Skills si votre compte la propose.

claude --plugin-dir /absolute/path/kumihan-accord
claude plugin validate /absolute/path/kumihan-accord
/plugin marketplace add landco-llc/kumihan
/plugin install kumihan-accord@kumihan-marketplace

INSTALL.md

04 / Tester sans modifier le texte

Indiquez la langue, le style éditorial et le mode de travail. Exemple de demande :

Utilise kumihan-accord-review pour relire cette page en français avec le style fr-fr-editorial, sans modifier le texte d’origine. Sépare les constats vérifiés des points à confirmer.

Vérification statique facultative, en lecture seule :

python runtime/checks.py input.txt --locale fr-FR --house-style fr-fr-editorial

05 / Mettre à jour

Sauvegardez vos personnalisations, vérifiez la version et les empreintes, puis mettez à jour selon la méthode prise en charge par votre outil. Un nouveau commit ne met pas à jour une installation existante. N’écrasez pas les plugins des autres langues.

06 / Limites

Une publication sur GitHub ne signifie pas une approbation dans les répertoires officiels de ChatGPT, Claude ou Gemini. Le fonctionnement dans chaque outil et le rendu réel demandent une exécution effective. Les vérifications statiques ne remplacent pas une relecture par un éditeur francophone.
