Guía de instalación

KUMIHAN｜Grafía · Claude Code · v0.1.0

ChatGPT / CodexClaude CodeGemini CLI

Instalar en tu herramienta

  1. Necesitas Claude Code para el plugin. Los Skills de Claude chat dependen de las funciones de tu cuenta.
  2. Extrae el plugin y comprueba la carpeta kumihan-grafia/. Si la versión lo permite: claude plugin validate /ruta/absoluta/kumihan-grafia. Inicia con claude --plugin-dir /ruta/absoluta/kumihan-grafia.
  3. En Claude chat, usa cada ZIP de Skill solo en una interfaz real de Skills. La carga local y el listado en un marketplace son estados distintos.

Descargar y verificar

Compara SHA256 y tamaño con MANIFEST.json antes de instalar. Con los 17 archivos del Release en una carpeta: sha256sum -c SHA256SUMS.txt (macOS: shasum -a 256 -c SHA256SUMS.txt). Para un ZIP, verifica su entrada individual.

  • kumihan-grafia-Claude-Code-plugin-v0.1.0.zip
  • kumihan-grafia-Claude-skill-v0.1.0.zip
  • kumihan-grafia-web-Claude-skill-v0.1.0.zip
  • kumihan-grafia-documents-Claude-skill-v0.1.0.zip
  • kumihan-grafia-review-Claude-skill-v0.1.0.zip

Usar y actualizar

Usa kumihan-grafia-review. Conserva el original, las cifras y los nombres; separa observaciones y propuestas.

Guarda tus ajustes, verifica la nueva versión y usa el flujo de actualización o reinstalación del proveedor. Comprueba descubrimiento e invocación en tu cuenta.

Claude Code plugins

48 reglas de orientación y 5 patrones estáticos limitados. No es un corrector completo ni una certificación visual. Los 60 casos originales de investigación siguen sin comprobarse; las pruebas sintéticas y mediciones del sitio se registran aparte.

La publicación OSS, la web y los directorios de proveedores se verifican por separado. Consulta el Release para su estado real. La importación e invocación nativas y las tiendas no están verificadas.
