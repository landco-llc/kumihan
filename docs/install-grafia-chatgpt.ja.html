ツールへの導入

  1. 対応するプラグインまたはSkillsの導入口が必要です。CodexはプロジェクトのSkillsフォルダも利用できます。
  2. 完全プラグインはkumihan-grafia/に展開され、plugin.jsonと.codex-plugin/plugin.jsonを含みます。クライアントが提供する導入口から読み込みます。Codex単体Skillはプロジェクトの.agents/skills/へフォルダを展開してください。
  3. ChatGPTのSkillsアップロードはアカウント機能に依存します。会話へのZIP添付はプラグイン登録ではありません。導入口がなければコードを手動の指針として参照します。

ダウンロードと照合

導入前にMANIFEST.jsonのSHA256とバイト数を照合します。Releaseの17ファイルを同じフォルダに置き、sha256sum -c SHA256SUMS.txt（macOSはshasum -a 256 -c SHA256SUMS.txt）を実行。単体ZIPは該当項目を照合してください。
