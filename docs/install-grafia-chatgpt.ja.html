DOCUMENTATION / ChatGPT / Codex手順と注意事項

01 / 導入形式を選ぶ

プラグインには4つのスキルがすべて入っています。各スキルは、ルールと参考資料をそろえた単体でも配布しています。チャットにファイルを添付しただけでは導入されません。

02 / ダウンロードと照合

このバージョンのZIPを取得し、導入前にMANIFEST.jsonのSHA-256とバイト数を照合してください。17ファイルを同じフォルダに置いて、次を実行します（macOSはshasum -a 256 -c SHA256SUMS.txt）。

sha256sum -c SHA256SUMS.txt
  • プラグイン: kumihan-grafia-GPT-Codex-plugin-v0.1.0.zip
  • 個別スキル: kumihan-grafia-GPT-Codex-skill-v0.1.0.zip
  • 個別スキル: kumihan-grafia-web-GPT-Codex-skill-v0.1.0.zip
  • 個別スキル: kumihan-grafia-documents-GPT-Codex-skill-v0.1.0.zip
  • 個別スキル: kumihan-grafia-review-GPT-Codex-skill-v0.1.0.zip

SHA256SUMS.txt · MANIFEST.json · GitHub Release v0.1.0

03 / 導入する

ChatGPT / Codex用プラグインは、クライアントが提供するプラグインの取り込み機能からのみ使います。展開するとkumihan-grafia/にplugin.jsonと.codex-plugin/plugin.jsonが入っています。CodexのSkillsは、各フォルダをプロジェクトの.agents/skills/に展開します。ChatGPTのSkillsアップロードはアカウントの機能によります。

mkdir -p .agents/skills

04 / 原稿を変えずに試す

言語・地域・呼びかけ（tú・vos・usted）・作業モードを明示します。依頼の例：

kumihan-grafia-reviewで、原稿・数字・名前を変えずに確認し、確認した点と提案を分けてください。

任意の静的チェック（読み取り専用）：

python runtime/checks.py original.txt --locale es --candidate candidate.txt

05 / 更新

カスタマイズを保存し、新しいバージョンとチェックサムを確認してから、ツールが対応する方法で更新します。新しいコミットだけでは既存の導入は更新されません。他言語のプラグインは上書きしないでください。

06 / 対応範囲と限界

48件の指針と5種類の限定的な静的検査です。完全な校正や見た目の品質を保証するものではありません。GitHubでの公開は、ChatGPT・Claude・Geminiの公式ディレクトリへの掲載を意味しません。各ツールでの動作と実際の表示は、実行して確かめる必要があります。
