01 / เลือกวิธีติดตั้ง

เลือกไฟล์ปลั๊กอินอิสระ หรือ Skill เดี่ยวตามความสามารถของโฮสต์ ไม่ต้องติดตั้ง KUMIHAN ภาษาญี่ปุ่นหรือ字衡ก่อน ไฟล์ ZIP ของปลั๊กอินไม่ใช่ไฟล์ ZIP ของ Skill และการแนบไฟล์ในแชตไม่ใช่การติดตั้งปลั๊กอิน

02 / ดาวน์โหลดไฟล์

ดาวน์โหลดไฟล์ ZIP ทั้ง 15 ชุดจาก GitHub Release v0.1.1 และตรวจ SHA256SUMS กับ MANIFEST ก่อนติดตั้ง การเรียกใช้บนโฮสต์จริงยังไม่ได้ทดสอบ

  • ปลั๊กอินอิสระ: kumihan-th-Claude-Code-plugin-v0.1.1.zip
  • Skill เดี่ยว: kumihan-th-Claude-skill-v0.1.1.zip
  • Skill เดี่ยว: kumihan-th-web-Claude-skill-v0.1.1.zip
  • Skill เดี่ยว: kumihan-th-documents-Claude-skill-v0.1.1.zip
  • Skill เดี่ยว: kumihan-th-review-Claude-skill-v0.1.1.zip

03 / ขั้นตอนการติดตั้ง

ดาวน์โหลดและแตกไฟล์ Skill ที่ต้องการ อ่าน SKILL.md และไฟล์อ้างอิงที่ให้มาด้วย หากโฮสต์ไม่มีระบบติดตั้งที่รองรับ ให้ใช้เป็นคำแนะนำที่แนบในบริบทงานและระบุว่าเป็นการใช้งานตามเอกสาร ไม่ใช่การติดตั้งแบบเนทีฟ

Claude Code: แตกไฟล์ปลั๊กอินและโหลดด้วย claude --plugin-dir /absolute/path/kumihan-th โดยมีชื่อเทคนิค kumihan-th ส่วน Claude Apps ให้นำเข้า Skill เดี่ยวเมื่อบัญชีรองรับ การยอมรับบนโฮสต์จริง: not-checked

04 / ตรวจสอบการทำงาน

ช่วยตรวจทานการขึ้นบรรทัดและเครื่องหมายวรรณยุกต์ในข้อความ “น้ำชา เก่ง ภาษาไทย” โดยไม่แก้ไขต้นฉบับ และแยกสิ่งที่ตรวจจริงออกจากข้อสังเกตที่ต้องตรวจต่อ

native installation: not-checked · native invocation: not-checked

05 / การอัปเดต

เก็บรุ่นเดิมไว้ก่อนอัปเดต ตรวจสอบแท็กและ SHA256SUMS ของรุ่นใหม่ แล้วแทนที่เฉพาะโฟลเดอร์ผลิตภัณฑ์นี้ หากต้องการย้อนกลับให้ใช้ไฟล์รุ่นเดิม หากต้องการถอนการติดตั้งให้ลบ Skill หรือปลั๊กอินผ่านระบบของโฮสต์ หรือเอาเอกสารออกจากบริบทงาน

06 / ข้อจำกัด

การติดตั้งและการเรียกใช้แบบเนทีฟบนทุกโฮสต์: not-checked การแบ่งคำและการแสดงผลขึ้นอยู่กับเอนจิน ฟอนต์ และสภาพแวดล้อม ต้องตรวจภาพที่แสดงจริงและความหมายโดยคน ไม่รับรองการแก้จัดหน้าอัตโนมัติ

ข้อความภาษาไทยยังต้องตรวจทานโดยบรรณาธิการเจ้าของภาษา
