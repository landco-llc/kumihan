01 / 導入形式を選ぶ

プラグインには4つのスキルがすべて入っています。各スキルは、ルールと参考資料をそろえた単体でも配布しています。チャットにファイルを添付しただけでは導入されません。

02 / ダウンロードと照合

GitHub Release v0.1.0からZIPを取得し、導入前にSHA256SUMS.txtとSHA-256を照合してください。

  • プラグイン: kumihan-compasso-chatgpt-codex-plugin-v0.1.0.zip
  • 個別スキル: kumihan-compasso-chatgpt-skill-v0.1.0.zip
  • 個別スキル: kumihan-compasso-web-chatgpt-skill-v0.1.0.zip
  • 個別スキル: kumihan-compasso-documents-chatgpt-skill-v0.1.0.zip
  • 個別スキル: kumihan-compasso-review-chatgpt-skill-v0.1.0.zip

SHA256SUMS.txt · MANIFEST.json · GitHub Release v0.1.0

03 / 導入する

ChatGPT / Codex用プラグインは、クライアントが提供するプラグインの取り込み機能からのみ使います。Codexでは、各スキルをプロジェクトの.agents/skills/に展開します。ChatGPTのSkillsアップロードはアカウントの機能によります。

INSTALL.md

04 / 原稿を変えずに試す

言語・地域（pt-BR・pt-PT）・編集スタイル・作業モードを明示します。依頼の例：

kumihan-compasso-reviewで、このポルトガル語のページを編集スタイルpt-pt-editorialで、原文を変えずにレビューしてください。確認できた点と、まだ確認が必要な点を分けてください。

任意の静的チェック（読み取り専用）：

python runtime/checks.py input.txt --locale pt-PT

05 / 更新

カスタマイズを保存し、新しいバージョンとチェックサムを確認してから、ツールが対応する方法で更新します。新しいコミットだけでは既存の導入は更新されません。他言語のプラグインは上書きしないでください。

06 / 対応範囲と限界

GitHubでの公開は、ChatGPT・Claude・Geminiの公式ディレクトリへの掲載を意味しません。各ツールでの動作と実際の表示は、実行して確かめる必要があります。静的チェックは、ポルトガル語の母語話者による確認の代わりにはなりません。
