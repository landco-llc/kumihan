DOCUMENTATION / ChatGPT / Codex手順と注意事項

KUMIHAN｜CompassoをChatGPTやCodexで使うための手順です。

v0.1.0について ご自身の環境で導入を試していただくための版です。各ツールでの動作はまだ十分に確認できていないため、うまく動かない場合があります。

1. 導入方法を選ぶ

使いたい場所おすすめの方法
ChatGPT（スキルのアップロードができる場合）A. スキルを1つずつ追加する
ChatGPT（自分専用のプラグインとして登録したい場合）B. プラグインとしてまとめて登録する
Codex（パソコン上で使う場合）C. フォルダーをコピーする

スキルは機能1つ分、プラグインは4つのスキルをまとめたパッケージです。

2. ファイルをダウンロードする

ファイルは リリースページ にあります。リンクを押すと、ZIPファイルがダウンロードされます。

プラグイン（4つのスキルをまとめたもの）

  • kumihan-compasso-chatgpt-codex-plugin-v0.1.0.zip

スキル（1つずつ）

  • kumihan-compasso — 最初の入口
  • kumihan-compasso-web — Webページ
  • kumihan-compasso-documents — 報告書・スライド
  • kumihan-compasso-review — レビュー

A. ChatGPTにスキルを追加する

ChatGPTの画面に「Skills」とアップロードの項目がある場合に使える方法です。

  1. スキルのZIPファイルを1つ選んでアップロードします。
  2. 表示された内容を確認して、追加します。
  3. 必要なスキルの数だけ、同じ手順をくり返します。

ご注意

  • プラグインのZIPは、この方法では使えません。スキルのZIPを使ってください。
  • チャットにファイルを添付するだけでは、スキルとして追加されません。
  • 画面に項目が見当たらない場合は、お使いのプランやアプリでまだ提供されていない可能性があります。OpenAIの公式案内 をご確認ください。

B. ChatGPTにプラグインとして登録する

4つのスキルをまとめて、自分専用のプラグインとして登録する方法です。

  1. ChatGPTで新しい会話を開き、@plugin-creator を選びます。
  2. プラグインのZIPファイルを添付します。
  3. 次のように依頼します。

    このパッケージを自分用のプライベートプラグインとして登録してください。公開ディレクトリには提出しないでください。

  4. 登録できたら、Pluginsの「Personal」や「Created by me」に KUMIHAN｜Compasso が表示されます。
  5. 必要に応じてインストールし、新しい会話で有効にします。

ご注意

  • 登録先がチームのワークスペースになる場合があります。自分専用にしたい場合は、登録前に保存先を確認してください。
  • この機能は、プランやワークスペースの設定によって使えない場合があります。詳しくは Build plugins と Plugins をご覧ください。
  • この方法で登録したプラグインは、あなたのアカウントだけで使えます。公開ディレクトリには掲載されません。

C. Codexにフォルダーをコピーする

スキルのZIPを展開すると、kumihan-compasso などのフォルダーができます。このフォルダーを、Codexが読み込む場所にコピーします。

使う範囲コピー先
特定のプロジェクトだけで使うプロジェクト内の .agents/skills/
すべてのプロジェクトで使うホームフォルダーの ~/.agents/skills/

たとえば、プロジェクトに kumihan-compasso を追加する場合は次のとおりです。

mkdir -p /path/to/your-project/.agents/skills
cp -R kumihan-compasso /path/to/your-project/.agents/skills/

ご注意

  • フォルダーは中身ごと、まるごとコピーしてください。一部のファイルだけでは正しく動きません。
  • 同じ名前のフォルダーがすでにある場合は、上書きする前に中身を確認してください。

3. 使ってみる

導入できたら、新しい会話を開いてスキルを呼び出します。

ツール呼び出し方
ChatGPT@ から選ぶ
Codex$ または /skills から選ぶ

最初は、ファイルを変更しない依頼で試すのがおすすめです。

ポルトガル語の報告書をつくる予定です。気をつけるポイントを教えてください。ファイルは変更しないでください。

ファイルが正しいか確認する（任意）

ダウンロードしたファイルが壊れていないかを確認したい場合は、SHA256SUMS.txt を使います。

ダウンロードしたZIPファイルと同じフォルダーに SHA256SUMS.txt を置き、ターミナルで次のコマンドを実行します。shasum がない環境では、Windows PowerShellの Get-FileHash などでSHA-256を照合してください。

shasum -a 256 -c --ignore-missing SHA256SUMS.txt

ダウンロードしたファイルの行に OK と表示されれば問題ありません。
