# Future publication checklist

This is a checklist for future work, not completed release evidence. The current candidate is development source folders; no published bundle is claimed.

- Record full source commit and tree, all four folder inventories, file byte lengths and SHA-256 values. Preserve exact LICENSE bytes and reviewed canonical source identities.
- Run existing standalone, public-boundary and offline tests against the exact candidate; record original failures, scoped corrections, environment, commands, exit codes and hosted CI URLs. Hash read-only product paths before and after checks.
- Review bilingual claims, local links and installation command paths. Keep static checks separate from host and rendering evidence.
- In a fresh Codex Cloud task, verify actual discovery and invocation of a complete folder in an unrelated workspace, local resource resolution and synthetic read-only use. Record all missing capabilities without converting them into passes.
- Obtain relevant synthetic web, report and presentation evidence under actual available renderers. Native Office, zoom, spacing and browser-engine checks require their own observations; unavailable checks remain explicit.
- Obtain independent review in a fresh context that did not produce the candidate. Bind the review to exact source identity and retain unresolved findings.
- Obtain separate current owner publication approval binding the exact source and intended publication. Documentation, CI success or a review reference is not publication authority. Do not infer permission to merge, tag or release.
- Recheck disclosure, asset rights, fonts and limitations at publication. Publish only sanitized product evidence; keep approval records and operational logs private.

The historical custom ZIP builder is excluded and unresolved; source-folder delivery does not repair it. Do not require or advertise historical archive generation or a deterministic outer ZIP hash. See [architecture](architecture.md), [coverage](coverage.md) and [compatibility](compatibility.md).
