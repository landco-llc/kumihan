នេះជាការណែនាំអំពីរបៀបប្រើ KUMIHAN｜លំនឹង ជាមួយ Claude Code និងការជជែក Claude។

អំពី v0.1.0 កំណែនេះសម្រាប់ឱ្យអ្នកសាកល្បងដំឡើងក្នុងបរិស្ថានរបស់អ្នកផ្ទាល់។ ដោយសារយើងមិនទាន់បានពិនិត្យដំណើរការនៅក្នុងឧបករណ៍នីមួយៗបានគ្រប់គ្រាន់នៅឡើយ ជំហានខ្លះអាចនឹងមិនដំណើរការដូចការរំពឹងទុក។

1. ជ្រើសរើសវិធីដំឡើង

កន្លែងដែលចង់ប្រើវិធីដែលណែនាំ
Claude Code (ប្រសិនបើចង់ដំឡើងពី ZIP)A. ដំឡើងពី ZIP
ការជជែក Claude (claude.ai និងកម្មវិធី)B. ផ្ទុក Skill ឡើង

Claude Code និងការជជែក Claude មានវិធីដំឡើងខុសគ្នា។

A. Claude Code៖ ដំឡើងពី ZIP

  1. ទាញយក ឯកសារ ZIP នៃប្លាកអ៊ីនសម្រាប់ Claude Code។
  2. នៅពេលពន្លាឯកសារ ZIP អ្នកនឹងទទួលបានថត kumihan-lumnung។
  3. បើកដំណើរការ Claude Code ដោយបញ្ជាក់ថតនោះ។
    claude --plugin-dir "/absolute/path/kumihan-lumnung"

ចំណាំ

  • សូមប្រើខ្លឹមសារក្នុងថតដូចដើម។ សូមកុំលុបឯកសារចេញ ឬលាយឯកសារផ្សេងចូល។
  • វិធីនេះមិនធ្វើបច្ចុប្បន្នភាពដោយស្វ័យប្រវត្តិទេ។ នៅពេលមានកំណែថ្មី សូមប្ដូរទៅឯកសារ ZIP ថ្មី។

B. ការជជែក Claude៖ ផ្ទុក Skill ឡើង

វិធីនេះសម្រាប់ប្រើនៅលើ claude.ai និងកម្មវិធី Claude។

  1. ទាញយកឯកសារ ZIP របស់ Skill ដែលចង់ប្រើ។
    • kumihan-lumnung — ចំណុចចាប់ផ្ដើម
    • kumihan-lumnung-web — គេហទំព័រ
    • kumihan-lumnung-documents — របាយការណ៍ និងស្លាយ
    • kumihan-lumnung-review — ការត្រួតពិនិត្យ
  2. នៅក្នុង Claude សូមបើក Customize → Skills រួចជ្រើសរើស Upload a skill ពីប៊ូតុងបន្ថែម។
  3. ផ្ទុកឯកសារ ZIP ឡើងម្ដងមួយ ហើយបើកដំណើរការ Skill។

ចំណាំ

  • ឯកសារ ZIP នៃប្លាកអ៊ីនសម្រាប់ Claude Code មិនអាចប្រើនៅទីនេះបានទេ។ សូមប្រើឯកសារ ZIP របស់ Skill។
  • សូមផ្ទុកឡើងដោយមិនប្ដូរឈ្មោះឯកសារ ZIP។
  • ដើម្បីប្រើ Skill ត្រូវបើក «ការដំណើរការកូដ» នៅក្នុងការកំណត់។ សម្រាប់ព័ត៌មានលម្អិត សូមមើល ការណែនាំផ្លូវការរបស់ Claude។
  • សម្រាប់គណនីរបស់ស្ថាប័ន អាចប្រើមិនបាន អាស្រ័យលើការកំណត់របស់អ្នកគ្រប់គ្រង។
  • Skill ដែលបានផ្ទុកឡើងមិនធ្វើបច្ចុប្បន្នភាពដោយស្វ័យប្រវត្តិទេ។ នៅពេលមានកំណែថ្មី សូមផ្ទុកឡើងម្ដងទៀត។

2. សាកល្បងប្រើ

ជាដំបូង យើងណែនាំឱ្យសាកល្បងជាមួយសំណើដែលមិនកែប្រែឯកសារ។

ខ្ញុំគ្រោងនឹងបង្កើតគេហទំព័រជាភាសាខ្មែរ។ សូមប្រាប់ខ្ញុំអំពីចំណុចដែលគួរប្រុងប្រយ័ត្ន។ សូមកុំកែប្រែឯកសារណាមួយ។

ពិនិត្យថាឯកសារត្រឹមត្រូវ (ស្រេចចិត្ត)

ប្រសិនបើចង់ពិនិត្យថាឯកសារដែលបានទាញយកមិនខូច សូមប្រើ SHA256SUMS.txt។

ដាក់ SHA256SUMS.txt ក្នុងថតតែមួយជាមួយឯកសារ ZIP ដែលបានទាញយក រួចដំណើរការពាក្យបញ្ជាខាងក្រោមក្នុង terminal។ ប្រសិនបើគ្មាន shasum សូមផ្ទៀងផ្ទាត់ SHA-256 ដោយប្រើពាក្យបញ្ជាផ្សេង ដូចជា Get-FileHash របស់ Windows PowerShell។

shasum -a 256 -c --ignore-missing SHA256SUMS.txt

ប្រសិនបើបន្ទាត់នៃឯកសារដែលបានទាញយកបង្ហាញ OK មានន័យថាគ្មានបញ្ហាទេ។
