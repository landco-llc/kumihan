01 / Choose a format

The plugin contains all four skills. Each skill is also distributed on its own, with its rules and references. Attaching a ZIP to a chat does not install anything.

02 / Download and verify

Download the ZIP files from GitHub Release v0.1.0 and compare their SHA-256 with SHA256SUMS.txt before installing.

  • Plugin: kumihan-laras-claude-code-plugin-v0.1.0.zip
  • Individual skill: kumihan-laras-claude-skill-v0.1.0.zip
  • Individual skill: kumihan-laras-web-claude-skill-v0.1.0.zip
  • Individual skill: kumihan-laras-documents-claude-skill-v0.1.0.zip
  • Individual skill: kumihan-laras-review-claude-skill-v0.1.0.zip

SHA256SUMS.txt · MANIFEST.json · GitHub Release v0.1.0

03 / Install

Extract the Claude Code plugin, keeping the kumihan-laras folder, then launch Claude Code with that folder. You can also install it from the repository marketplace. In Claude, import an individual skill only through a Skills interface, if your account offers one.

claude --plugin-dir /absolute/path/kumihan-laras
claude plugin validate /absolute/path/kumihan-laras
/plugin marketplace add landco-llc/kumihan
/plugin install kumihan-laras@kumihan-marketplace

05 / Update

Save your customizations, verify the new version and its checksums, then update the way your tool supports. A new commit alone does not update an existing installation. Do not overwrite plugins for other languages.

06 / Scope and limits

Publishing on GitHub is not a listing in the official ChatGPT, Claude, or Gemini directories. Actual behavior and rendering must be checked in each tool. Static checks do not replace review by a native Indonesian editor.
