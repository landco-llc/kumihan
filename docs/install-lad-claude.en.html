02 / Download and verify

Download v0.1.0 ZIPs and verify SHA256SUMS.txt.

  • Plugin package: kumihan-lad-claude-code-plugin-v0.1.0.zip
  • Standalone Skill: kumihan-lad-claude-skill-v0.1.0.zip
  • Standalone Skill: kumihan-lad-web-claude-skill-v0.1.0.zip
  • Standalone Skill: kumihan-lad-documents-claude-skill-v0.1.0.zip
  • Standalone Skill: kumihan-lad-review-claude-skill-v0.1.0.zip

03 / Install

Use claude --plugin-dir /absolute/path/kumihan-lad in Claude Code and verify native discovery.

claude --plugin-dir /absolute/path/kumihan-lad
claude plugin validate /absolute/path/kumihan-lad
/plugin marketplace add landco-llc/kumihan
/plugin install kumihan-lad@kumihan-marketplace

04 / Test

State the language, region (ru-RU or ru-RU), house style, and working mode. Example request:

Review Russian typography without changing the source.

python runtime/checks.py original.txt --locale ru-RU

python runtime/checks.py input.txt --locale ru-RU

05 / Update

Verify checksums, preserve house styles and reinstall via the host.

06 / Limits

Static checks cannot prove native host, browser, Office/PDF or human editorial quality.
