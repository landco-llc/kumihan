01 / Choose a format

The plugin contains all four skills. Each skill is also distributed on its own, with its rules and references. Attaching a ZIP to a chat does not install anything.

02 / Download and verify

Download the ZIP files from GitHub Release v0.1.0 and compare their SHA-256 with SHA256SUMS.txt before installing.

  • Plugin: kumihan-lumnung-claude-code-plugin-v0.1.0.zip
  • Individual skill: kumihan-lumnung-claude-skill-v0.1.0.zip
  • Individual skill: kumihan-lumnung-web-claude-skill-v0.1.0.zip
  • Individual skill: kumihan-lumnung-documents-claude-skill-v0.1.0.zip
  • Individual skill: kumihan-lumnung-review-claude-skill-v0.1.0.zip

SHA256SUMS.txt · MANIFEST.json · GitHub Release v0.1.0

03 / Install

Extract the plugin keeping the kumihan-lumnung folder, validate with claude plugin validate and use claude --plugin-dir where supported. Individual skills may be placed in .claude/skills/. Native host support must be verified.

claude --plugin-dir /absolute/path/kumihan-lumnung
claude plugin validate /absolute/path/kumihan-lumnung
/plugin marketplace add landco-llc/kumihan
/plugin install kumihan-lumnung@kumihan-marketplace

04 / Try it without changing the source

Specify Khmer locale km-KH, medium, house style and source-editing permission. Example:

Use kumihan-lumnung-review to review Khmer typography without changing the original text.

Optional read-only static check:

python runtime/checks.py input.txt --locale km-KH

05 / Update

Save your customizations, verify the new version and its checksums, then update the way your tool supports. A new commit alone does not update an existing installation. Do not overwrite plugins for other languages.

06 / Scope and limits

30 Khmer rules, 24 proposed scenarios and a read-only source-byte comparator are provided. Native browser shaping, provider registration and Khmer proofreading are not automatically verified.
