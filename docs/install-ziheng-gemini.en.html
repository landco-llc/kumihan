01 / SETUP

Installation steps

01

Download and extract the Gemini CLI extension

Download the dedicated Gemini CLI extension ZIP and extract it into a new empty folder.

unzip kumihan-ziheng-Gemini-CLI-extension-0.1.0-preview.zip -d /absolute/path/kumihan-ziheng
02

Install the local extension

Install that local directory using Gemini CLI, restart, then verify the skills appear.

gemini extensions install "/absolute/path/kumihan-ziheng"
03

Verify the ZiHeng extension

The GitHub monorepo root contains the Japanese KUMIHAN extension; installing the root URL is not a ZiHeng install.

gemini extensions list
04

Import Gemini app skills

Gemini app: if your account supports Skills upload, import individual skill ZIPs and run host-specific acceptance tests.
