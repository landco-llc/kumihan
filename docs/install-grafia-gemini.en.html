DOCUMENTATION / GeminiSteps and notes

01 / Choose a format

The plugin contains all four skills. Each skill is also distributed on its own, with its rules and references. Attaching a ZIP to a chat does not install anything.

02 / Download and verify

Download the ZIP files for this version and compare SHA-256 and byte length with MANIFEST.json before installing. With all 17 files in one folder, run (on macOS, shasum -a 256 -c SHA256SUMS.txt):

sha256sum -c SHA256SUMS.txt
  • Plugin: kumihan-grafia-Gemini-CLI-extension-v0.1.0.zip
  • Individual skill: kumihan-grafia-Gemini-Apps-skill-v0.1.0.zip
  • Individual skill: kumihan-grafia-web-Gemini-Apps-skill-v0.1.0.zip
  • Individual skill: kumihan-grafia-documents-Gemini-Apps-skill-v0.1.0.zip
  • Individual skill: kumihan-grafia-review-Gemini-Apps-skill-v0.1.0.zip

SHA256SUMS.txt · MANIFEST.json · GitHub Release v0.1.0

03 / Install

Extract the extension ZIP into an empty folder; gemini-extension.json must sit at its root. Install it from that path and read the consent prompt. Do not install this repository’s root as Grafía. Import into the Gemini app has not been verified.

gemini extensions install /absolute/path/to/folder
gemini extensions list

05 / Update

Save your customizations, verify the new version and its checksum, then update the way your tool supports. A new commit alone does not update an existing installation. Do not overwrite plugins for other languages.

06 / Scope and limits

48 guidance records and 5 bounded static patterns: not a complete proofreader or a visual certification. Publishing on GitHub is not a listing in the official ChatGPT, Claude, or Gemini directories. Actual behavior and rendering must be checked in each tool.
