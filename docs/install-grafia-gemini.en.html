Install in your tool

  1. Requires Gemini CLI with Extensions. Gemini Apps Skills import is not verified.
  2. Extract the extension ZIP into an empty directory; gemini-extension.json must be directly at its root. Run gemini extensions install /absolute/path/folder and read installer consent.
  3. Do not install this monorepo root as Grafía. Independent Skills follow the installed CLI version’s Skills flow; Apps availability needs account-specific verification.

Download and verify

Compare SHA256 and byte length with MANIFEST.json before installation. With all 17 Release files in one directory: sha256sum -c SHA256SUMS.txt (macOS: shasum -a 256 -c SHA256SUMS.txt). For a single ZIP verify its individual entry.
