01 / Choose a format

The plugin bundles all four skills. Each skill is also available on its own with its full rules and references. Attaching a file to a chat does not install it.

02 / Download and verify

Download the ZIP files from GitHub Release v0.1.1 and compare their SHA-256 with SHA256SUMS.txt before installing.

  • Plugin: kumihan-accord-claude-code-plugin-v0.1.1.zip
  • Individual skill: kumihan-accord-claude-skill-v0.1.1.zip
  • Individual skill: kumihan-accord-web-claude-skill-v0.1.1.zip
  • Individual skill: kumihan-accord-documents-claude-skill-v0.1.1.zip
  • Individual skill: kumihan-accord-review-claude-skill-v0.1.1.zip

SHA256SUMS.txt · MANIFEST.json · GitHub Release v0.1.1

03 / Install

Unzip the Claude Code plugin, keeping the kumihan-accord directory, then start Claude Code with that directory. You can also use the repository marketplace. For Claude, import an individual skill through the Skills interface if your account offers it.

claude --plugin-dir /absolute/path/kumihan-accord
claude plugin validate /absolute/path/kumihan-accord
/plugin marketplace add landco-llc/kumihan
/plugin install kumihan-accord@kumihan-marketplace

04 / Test without editing

Set the locale, house style and work mode explicitly. Example request:

Use kumihan-accord-review to review this French page with the fr-fr-editorial house style, without changing the original text. Separate verified findings from items that still need checking.

Optional read-only static check:

python runtime/checks.py input.txt --locale fr-FR --house-style fr-fr-editorial

05 / Updates

Back up customizations, verify the version and checksums, and update through your tool’s supported process. New git commits do not update existing installations. Do not overwrite sibling language plugins.

06 / Known limits

A GitHub release does not imply official directory approval for ChatGPT, Claude or Gemini. Native host behavior and actual rendering need real execution. Static checks do not replace review by a French editor.
