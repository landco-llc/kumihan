01 / ホストに合わせて導入する

  1. Claude CodeではPlugin一式を独立したフォルダに展開します。
  2. 次のコマンドでローカルセッションを開始します。Claude chatでは、利用可能なSkills画面から独立スキルZIPを取り込みます。
  3. ローカルでの読み込みと公式マーケットへの掲載は別です。実アカウントでの検出・呼び出しは未確認です。
claude --plugin-dir /absolute/path/kumihan-ar

Release配布物

公開されたチェックサムとSHA-256を照合します。選んだ5 ZIPを同じフォルダに置き、次のGNUコマンドで5件すべてのOKを確認します。単体ZIPやmacOSではshasum -a 256の結果をMANIFEST.jsonの該当項目と照合します。

sha256sum --ignore-missing -c SHA256SUMS.txt

03 / 使い方と更新

kumihan-ar-reviewを使い、原文・名前・数値を変更せずにこのページをレビューしてください。静的な指摘と、実際に確認した表示を分けてください。

カスタマイズを保存し、新版を照合してから再インストールします。チャットへの添付だけでは、スキルのインストールを確認したことにはなりません。

制作を支援する指針であり、文字組の品質認証ではありません。各ホストでのインストール・呼び出しは未確認です。アラビア語のコピーは母語話者による校閲が必要です。
