English-language installation guide This installation guide is provided in English while a reviewed local-language translation is unavailable. The EL edition and its four skills are language-specific; native-host import and actual rendering have not been fully verified.

This guide explains how to use KUMIHAN｜Μέτρο with Gemini CLI and the Gemini app.

About v0.1.0 This version is for trying KUMIHAN｜Μέτρο in your own environment. Behavior in each tool has not yet been fully verified, so some steps may not work as expected.

1. Choose an installation method

Where you want to use itRecommended method
Gemini CLI (all four skills)A. Install as an extension
Gemini CLI (only the skills you need)B. Install individual skills
Gemini app (web, Mac, mobile)C. Upload skills

A. Gemini CLI: install as an extension

This installs all four skills at once.

  1. Download the extension ZIP (Source ZIP).
  2. Extract it to get a kumihan-metro folder.
  3. Install from that folder:
    gemini extensions install "/absolute/path/kumihan-metro"

Review the confirmation prompt before continuing. Once installed, the extension is active in all projects.

An extension installed from a ZIP does not update automatically. When a new version is released, replace it with the new ZIP.

B. Gemini CLI: install individual skills

This installs only the skills you need, for a single project. You don't need this if you used method A.

For example, to install kumihan-metro, run this in your project:

gemini skills install https://github.com/landco-llc/kumihan --path plugins/kumihan-metro/skills/kumihan-metro --scope workspace

For other skills, change --path to:

  • plugins/kumihan-metro/skills/kumihan-metro-web — web pages
  • plugins/kumihan-metro/skills/kumihan-metro-documents — reports and slides
  • plugins/kumihan-metro/skills/kumihan-metro-review — review

--scope workspace limits the skill to this project. Without it, the skill is available in all your projects.

To update

Run the same command again. The installed skill will be replaced, so save any changes you made to it first.

C. Gemini app: upload skills

  1. Download the skill ZIPs you want to use.
    • kumihan-metro (Source ZIP) — starting point
    • kumihan-metro-web (Source ZIP) — web pages
    • kumihan-metro-documents (Source ZIP) — reports and slides
    • kumihan-metro-review (Source ZIP) — review
  2. In Gemini, open Customize (or More if you don't see it) → Skills → Upload.
  3. Choose one ZIP at a time, review the details, and select Create.

Notes

  • Available for personal Google accounts of users 18 and older. Work and school accounts are not supported at this time.
  • Keep Activity must be turned on.
  • The feature is rolling out gradually and may not be available to you yet. See Gemini Help.
  • The extension ZIP (for Gemini CLI) does not work here.
  • Uploaded skills do not update automatically. When a new version is released, upload it again.

2. Try it out

We recommend starting with a request that doesn't change any files:

I'm planning a presentation in Ελληνικά. What should I keep in mind? Please don't change any files.

Verify your downloads (optional)

To check that your downloads are intact, use SHA256SUMS.txt.

Put SHA256SUMS.txt in the same folder as the ZIP files you downloaded, then run this in a terminal. If shasum is unavailable, use an equivalent SHA-256 command such as PowerShell Get-FileHash on Windows:

shasum -a 256 -c --ignore-missing SHA256SUMS.txt

If the lines for your downloaded files show OK, the files are intact.
