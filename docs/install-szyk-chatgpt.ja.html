01 / 導入形式を選ぶ

プラグインには4つのスキルがすべて入っています。各スキルは、ルールと参考資料をそろえた単体でも配布しています。チャットにファイルを添付しただけでは導入されません。

02 / ダウンロードと照合

このバージョンのZIPを取得し、導入前にMANIFEST.jsonのSHA-256とバイト数を照合してください。17ファイルを同じフォルダに置いて、次を実行します（macOSはshasum -a 256 -c SHA256SUMS.txt）。

sha256sum -c SHA256SUMS.txt
  • プラグイン: kumihan-szyk-GPT-Codex-plugin-v0.1.0.zip
  • 個別スキル: kumihan-szyk-GPT-Codex-skill-v0.1.0.zip
  • 個別スキル: kumihan-szyk-web-GPT-Codex-skill-v0.1.0.zip
  • 個別スキル: kumihan-szyk-documents-GPT-Codex-skill-v0.1.0.zip
  • 個別スキル: kumihan-szyk-review-GPT-Codex-skill-v0.1.0.zip

SHA256SUMS.txt · MANIFEST.json · GitHub Release v0.1.0

03 / 導入する

ChatGPT / Codex用プラグインは、クライアントが提供するプラグインの取り込み機能からのみ使います。展開するとkumihan-szyk/にplugin.jsonと.codex-plugin/plugin.jsonが入っています。CodexのSkillsは、各フォルダをプロジェクトの.agents/skills/に展開します。ChatGPTのSkillsアップロードはアカウントの機能によります。

mkdir -p .agents/skills

04 / 原稿を変えずに試す

ポーランド語・媒体・文体・作業モードを明示します。依頼の例：

kumihan-szyk-reviewでポーランド語の文字組みを確認し、原稿・数字・名前を変えず、観察事項と提案を区別してください。

任意の静的チェック（読み取り専用）：

python runtime/checks.py original.txt --locale pl --candidate candidate.txt

05 / 更新

カスタマイズを保存し、新しいバージョンとチェックサムを確認してから、ツールが対応する方法で更新します。新しいコミットだけでは既存の導入は更新されません。他言語のプラグインは上書きしないでください。

06 / 対応範囲と限界

研究由来の40規則・64ケースと限定的な静的検査を提供します。完全校正や描画品質の保証ではありません。GitHubでの公開はAIツールの公式ディレクトリ掲載やネイティブ動作確認を意味しません。
