Guía de instalación

KUMIHAN｜Grafía · ChatGPT / Codex · v0.1.0

ChatGPT / CodexClaude CodeGemini CLI

Instalar en tu herramienta

  1. Necesitas una interfaz real de plugins o Skills compatible. En Codex, también puedes usar carpetas Skills del proyecto.
  2. El plugin se extrae como kumihan-grafia/, con plugin.json y .codex-plugin/plugin.json. Impórtalo solo mediante la función que tu cliente ofrezca. Para Skills de Codex, extrae la carpeta individual en .agents/skills/ del proyecto.
  3. En ChatGPT, la carga de Skills depende de tu cuenta. Adjuntar un ZIP a una conversación no registra un plugin. Sin interfaz de instalación, consulta el código como guía manual.

Descargar y verificar

Compara SHA256 y tamaño con MANIFEST.json antes de instalar. Con los 17 archivos del Release en una carpeta: sha256sum -c SHA256SUMS.txt (macOS: shasum -a 256 -c SHA256SUMS.txt). Para un ZIP, verifica su entrada individual.

Usar y actualizar

Usa kumihan-grafia-review. Conserva el original, las cifras y los nombres; separa observaciones y propuestas.

Guarda tus ajustes, verifica la nueva versión y usa el flujo de actualización o reinstalación del proveedor. Comprueba descubrimiento e invocación en tu cuenta.
