01 / Elegir el formato

El plugin incluye las cuatro skills. Cada skill también se distribuye por separado, con sus reglas y referencias. Adjuntar un ZIP a una conversación no instala nada.

02 / Descargar y verificar

Descarga los ZIP de esta versión y compara SHA-256 y tamaño con MANIFEST.json antes de instalar. Con los 17 archivos en una misma carpeta, ejecuta (en macOS, shasum -a 256 -c SHA256SUMS.txt):

sha256sum -c SHA256SUMS.txt
  • Plugin: kumihan-grafia-GPT-Codex-plugin-v0.1.0.zip
  • Skill individual: kumihan-grafia-GPT-Codex-skill-v0.1.0.zip
  • Skill individual: kumihan-grafia-web-GPT-Codex-skill-v0.1.0.zip
  • Skill individual: kumihan-grafia-documents-GPT-Codex-skill-v0.1.0.zip
  • Skill individual: kumihan-grafia-review-GPT-Codex-skill-v0.1.0.zip

SHA256SUMS.txt · MANIFEST.json · GitHub Release v0.1.0

03 / Instalar

Usa el plugin de ChatGPT / Codex solo mediante la función de importación de plugins que ofrezca tu cliente; se extrae como kumihan-grafia/ con plugin.json y .codex-plugin/plugin.json. Para Skills de Codex, extrae cada carpeta en .agents/skills/ del proyecto. La subida de Skills en ChatGPT depende de tu cuenta.

mkdir -p .agents/skills

04 / Probar sin cambiar el original

Indica el idioma, la región, el tratamiento y el modo de trabajo. Ejemplo de petición:

Usa kumihan-grafia-review. Conserva el original, las cifras y los nombres; separa las observaciones de las propuestas.

Comprobación estática opcional (solo lectura):

python runtime/checks.py original.txt --locale es --candidate candidate.txt

05 / Actualizar

Guarda tus ajustes, verifica la nueva versión y su suma de control, y actualiza con el método que admita tu herramienta. Un nuevo commit no actualiza una instalación existente. No sobrescribas los plugins de otros idiomas.

06 / Alcance y límites

48 pautas y 5 patrones estáticos acotados: no es un corrector completo ni una certificación visual. Publicar en GitHub no equivale a figurar en los directorios oficiales de ChatGPT, Claude o Gemini. El funcionamiento y la visualización reales deben comprobarse en cada herramienta.
