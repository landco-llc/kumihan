Antes de instalar

Use uma interface real de Skills ou plugins no seu host. Um ZIP numa conversa não instala o plugin.

Código e fontes ↗
DOCUMENTATION / ChatGPT / Codex3 passos

01 / Escolher pacote

O plugin reúne quatro Skills; cada Skill também funciona de forma independente. A instalação só funciona nas interfaces suportadas pelo fornecedor.

02 / Transferir e verificar

Descarregue os ZIP v0.1.0 do GitHub Release e verifique SHA256SUMS.txt.

  • Pacote de plugin: kumihan-compasso-chatgpt-codex-plugin-v0.1.0.zip
  • Skill independente: kumihan-compasso-chatgpt-skill-v0.1.0.zip
  • Skill independente: kumihan-compasso-web-chatgpt-skill-v0.1.0.zip
  • Skill independente: kumihan-compasso-documents-chatgpt-skill-v0.1.0.zip
  • Skill independente: kumihan-compasso-review-chatgpt-skill-v0.1.0.zip

SHA256SUMS.txt · MANIFEST.json · GitHub Release v0.1.0

03 / Instalar

Em Codex, extraia cada Skill para .agents/skills/ no projeto. Para plugins, utilize a interface suportada. No ChatGPT, os recursos de instalação dependem da conta; anexar o ZIP não regista o plugin.

04 / Testar e atualizar

Confirme descoberta real e execução nativa; não deduza sucesso apenas de uma validação JSON.

Revê a tipografia deste texto em português sem alterar o original.

python runtime/checks.py original.txt --locale pt-PT

python runtime/checks.py input.txt --locale pt-PT
