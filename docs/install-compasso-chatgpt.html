01 / Escolher o formato

O plugin reúne as quatro skills. Cada skill também é distribuída em separado, com as suas regras e referências. Anexar um ZIP a uma conversa não instala nada.

02 / Transferir e verificar

Transfira os ZIP do GitHub Release v0.1.0 e compare o SHA-256 com SHA256SUMS.txt antes de instalar.

  • Plugin: kumihan-compasso-chatgpt-codex-plugin-v0.1.0.zip
  • Skill individual: kumihan-compasso-chatgpt-skill-v0.1.0.zip
  • Skill individual: kumihan-compasso-web-chatgpt-skill-v0.1.0.zip
  • Skill individual: kumihan-compasso-documents-chatgpt-skill-v0.1.0.zip
  • Skill individual: kumihan-compasso-review-chatgpt-skill-v0.1.0.zip

SHA256SUMS.txt · MANIFEST.json · GitHub Release v0.1.0

03 / Instalar

Use o plugin de ChatGPT / Codex apenas através da função de importação de plugins que o seu cliente oferecer. No Codex, extraia cada skill para a pasta .agents/skills/ do projeto. No ChatGPT, o carregamento de skills depende da sua conta.

INSTALL.md

04 / Testar sem alterar o original

Indique a língua, a região (pt-BR ou pt-PT), o estilo editorial e o modo de trabalho. Exemplo de pedido:

Usa kumihan-compasso-review para rever esta página em português com o estilo pt-pt-editorial, sem alterar o texto original. Separa o que foi verificado do que ainda precisa de confirmação.

Verificação estática opcional (só de leitura):

python runtime/checks.py input.txt --locale pt-PT

05 / Atualizar

Guarde as suas personalizações, verifique a nova versão e as somas de controlo e atualize pelo método que a sua ferramenta suporta. Um novo commit não atualiza uma instalação existente. Não substitua os plugins de outras línguas.

06 / Alcance e limites

Publicar no GitHub não significa figurar nos diretórios oficiais do ChatGPT, do Claude ou do Gemini. O funcionamento e a apresentação reais têm de ser verificados em cada ferramenta. As verificações estáticas não substituem a revisão por um editor nativo de português.
