DOCUMENTATION / Gemini3 steps

01 / Choose package

The plugin contains four standalone Skills. Each Skill can also be installed separately when supported by the host.

02 / Download and verify

Download v0.1.0 ZIPs from GitHub Release, then check SHA256SUMS.txt.

  • Plugin package: kumihan-compasso-gemini-cli-extension-v0.1.0.zip
  • Standalone Skill: kumihan-compasso-gemini-skill-v0.1.0.zip
  • Standalone Skill: kumihan-compasso-web-gemini-skill-v0.1.0.zip
  • Standalone Skill: kumihan-compasso-documents-gemini-skill-v0.1.0.zip
  • Standalone Skill: kumihan-compasso-review-gemini-skill-v0.1.0.zip

SHA256SUMS.txt · MANIFEST.json · GitHub Release v0.1.0

03 / Install

Use gemini extensions install /absolute/path/kumihan-compasso for the CLI extension. Skill support depends on your Gemini environment.

gemini extensions install /absolute/path/kumihan-compasso
gemini extensions list

04 / Test and update

Verify discovery and native invocation. JSON validation alone does not demonstrate functioning installation.

Review Portuguese typography without changing any supplied source text.

python runtime/checks.py original.txt --locale pt-BR

python runtime/checks.py input.txt --locale pt-PT
