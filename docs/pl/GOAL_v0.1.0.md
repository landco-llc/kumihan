# KUMIHAN｜Szyk v0.1.0 /goal

## Goal
Ship one Polish KUMIHAN product edition as open-source software: four standalone skills, 3 host bundles (Claude, Gemini and GPT/Codex), 15 versioned ZIPs, 3 localized product pages and 9 localized install guides. Preserve Japanese KUMIHAN brand philosophy and existing CSS/layout without rebranding common JA/EN copy.

## Work groups — autonomous end-to-end
- W00 · Fresh Read: use current main source, RJP/CLDR/GUM-based research; protect other language editions.
- W01 · Product: Polish guidance, byte-preserving bounded checker, locale/profile rules, citations and 64 proposed fixtures.
- W02 · Distribution: Claude and Gemini plugins and skills, bilingual PL/EN descriptions, name KUMIHAN｜Szyk, original official icon, 15 versioned ZIPs, deterministic manifest and checksums.
- W03 · Site: only after W01-W02, build kumihan-pl.html plus en/ja versions and 9 install guides from Japanese-derived shared CSS and common copy; add edition to all existing language gateways.
- W04 · Test & Release: run static, archive, consistency, locality, gateway and existing-site checks; merge branch after review, tag v0.1.0, publish 17 release attachments and verify GitHub Pages.

## Explicit limits
Rules are original research proposals rather than full Polish proofreading. Fixtures are unexecuted by default; checker has bounded static candidates and source-byte comparison, not actual rendering. No automatic source rewrite. Host-native use and external marketplace listing not claimed. Browser screenshots and Polish native speaker review are separate checks.

## Acceptance
- 40 rules + 64 proposed fixtures (unmodified provenance) and public source links
- Skill descriptions, host/plugin descriptions Polish | English, display name only KUMIHAN｜Szyk
- All release ZIPs include v0.1.0 and SHA256 manifest checks pass
- Existing site structure and CSS parity; no Spanish strings leak into PL/EN/JA Szyk pages
- 12 generated pages, valid internal links, lang/hreflang, reachable release & public site
- Simple tests only: no heavyweight security audit for the open-source typographic data product
