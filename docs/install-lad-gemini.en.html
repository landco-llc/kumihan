01 / Choose package

Four independent Skills and a plugin package.

02 / Download and verify

Download v0.1.0 ZIPs and verify SHA256SUMS.txt.

  • Plugin package: kumihan-lad-gemini-cli-extension-v0.1.0.zip
  • Standalone Skill: kumihan-lad-gemini-skill-v0.1.0.zip
  • Standalone Skill: kumihan-lad-web-gemini-skill-v0.1.0.zip
  • Standalone Skill: kumihan-lad-documents-gemini-skill-v0.1.0.zip
  • Standalone Skill: kumihan-lad-review-gemini-skill-v0.1.0.zip

SHA256SUMS.txt · MANIFEST.json · GitHub Release v0.1.0

03 / Install

Use gemini extensions install /absolute/path/kumihan-lad in Gemini CLI and list extensions.

gemini extensions install /absolute/path/kumihan-lad
gemini extensions list

INSTALL.md

04 / Test

State the language, region (ru-RU or ru-RU), house style, and working mode. Example request:

Review Russian typography without changing the source.

python runtime/checks.py original.txt --locale ru-RU

python runtime/checks.py input.txt --locale ru-RU

05 / Update

Verify checksums, preserve house styles and reinstall via the host.

06 / Limits

Static checks cannot prove native host, browser, Office/PDF or human editorial quality.
