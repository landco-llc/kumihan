INSTALLATION / इस्तेमाल से पहले

आपके परिवेश में यहाँ बताए गए कुछ चरण उपलब्ध न भी हों। अपने AI होस्ट में वास्तविक व्यवहार की जाँच करें।

मूल स्थापना निर्देश खोलें ↗
DOCUMENTATION / Claudeचरण और टिप्पणियाँ

यह मार्गदर्शिका बताती है कि KUMIHAN｜अक्षर-संगति को Claude Code और Claude चैट में कैसे इस्तेमाल करें।

v0.1.0 के बारे में यह संस्करण अपने परिवेश में स्थापना आज़माने के लिए है। हर टूल में इसके काम करने की अभी पूरी जाँच नहीं हुई है, इसलिए हो सकता है कि यह ठीक से काम न करे।

1. स्थापना का तरीका चुनें

आप इसे कहाँ इस्तेमाल करना चाहते हैंसुझाया गया तरीका
Claude Code (यदि ZIP से स्थापित करना चाहते हैं)A. ZIP से स्थापित करें
Claude चैट (claude.ai और ऐप)B. स्किल अपलोड करें

Claude Code और Claude चैट में स्थापना के तरीके अलग-अलग हैं।

A. Claude Code: ZIP से स्थापित करें

  1. Claude Code प्लगइन की ZIP फ़ाइल डाउनलोड करें।
  2. ZIP खोलने पर kumihan-hi फ़ोल्डर बनता है।
  3. उस फ़ोल्डर को निर्दिष्ट करके Claude Code शुरू करें।
    claude --plugin-dir "/absolute/path/kumihan-hi"

ध्यान दें

  • फ़ोल्डर की सामग्री को जैसी है वैसी ही इस्तेमाल करें। उसमें से फ़ाइलें न हटाएँ और दूसरी फ़ाइलें न मिलाएँ।
  • इस तरीके में अपने-आप अपडेट नहीं होता। नया संस्करण आने पर ZIP बदल दें।

B. Claude चैट: स्किल अपलोड करें

यह तरीका claude.ai या Claude ऐप में इस्तेमाल के लिए है।

  1. जिन स्किल का इस्तेमाल करना है, उनकी ZIP फ़ाइलें डाउनलोड करें।
    • kumihan-hi — शुरुआती बिंदु
    • kumihan-hi-web — वेब पेज
    • kumihan-hi-documents — रिपोर्ट और स्लाइड
    • kumihan-hi-review — समीक्षा
  2. Claude में Customize → Skills खोलें और जोड़ने वाले बटन से Upload a skill चुनें।
  3. ZIP फ़ाइलें एक-एक करके अपलोड करें और स्किल सक्रिय करें।

ध्यान दें

  • Claude Code प्लगइन की ZIP फ़ाइल यहाँ काम नहीं करती। स्किल की ZIP फ़ाइलें इस्तेमाल करें।
  • ZIP फ़ाइलों का नाम बदले बिना अपलोड करें।
  • स्किल इस्तेमाल करने के लिए सेटिंग में “कोड निष्पादन” चालू होना चाहिए। विस्तार से जानने के लिए Claude की आधिकारिक मार्गदर्शिका देखें।
  • संगठन के खातों में, व्यवस्थापक की सेटिंग के अनुसार यह सुविधा उपलब्ध न भी हो।
  • अपलोड की गई स्किल अपने-आप अपडेट नहीं होतीं। नया संस्करण आने पर उन्हें फिर से अपलोड करें।

2. आज़माकर देखें

शुरुआत ऐसे अनुरोध से करना बेहतर है, जिससे कोई फ़ाइल न बदले।

मेरी योजना हिंदी में एक वेब पेज बनाने की है। मुझे किन बातों का ध्यान रखना चाहिए? कृपया कोई फ़ाइल न बदलें।

फ़ाइलों की शुद्धता जाँचें (वैकल्पिक)

यदि आप जाँचना चाहते हैं कि डाउनलोड की गई फ़ाइलें ख़राब तो नहीं हैं, तो SHA256SUMS.txt का इस्तेमाल करें।

डाउनलोड की गई ZIP फ़ाइलों वाले फ़ोल्डर में ही SHA256SUMS.txt रखें और टर्मिनल में नीचे दिया गया कमांड चलाएँ। जहाँ shasum उपलब्ध न हो, वहाँ Windows PowerShell के Get-FileHash जैसे किसी तरीके से SHA-256 मिलाएँ।

shasum -a 256 -c --ignore-missing SHA256SUMS.txt

यदि डाउनलोड की गई फ़ाइल की पंक्ति में OK दिखाई दे, तो फ़ाइल ठीक है।

अन्य टूल: ChatGPT / Codex · Gemini

स्क्रीन और उपलब्धता की शर्तें बदल सकती हैं। नवीनतम जानकारी के लिए हर सेवा की आधिकारिक मार्गदर्शिका देखें (इस पृष्ठ की जाँच की तारीख: 14 अक्टूबर 2026)।
