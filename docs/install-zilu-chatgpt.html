01 / 安装步骤

  1. 前提：账户与客户端需提供插件或Skills导入入口。完整插件与单个Skill不可混用。
  2. 下载完整插件，解压后用客户端支持的插件导入入口选择 kumihan-zilu 文件夹。只支持Skills时，从下方下载四个独立Skill ZIP并通过Skills入口安装。
  3. 仅把文件附到聊天不代表已安装。原生发现、图标显示与调用未验证；无入口时请使用源码手动指导。

Codex Skills · Codex Plugins

02 / 下载与核验

在 downloads 目录使用 sha256sum -c SHA256SUMS.txt（macOS 可用 shasum -a 256 -c）。只下载单个ZIP时对照 MANIFEST.json 对应项校验。

  • kumihan-zilu-plugin-v0.1.0.zip
  • kumihan-zilu-entry-skill-v0.1.0.zip
  • kumihan-zilu-web-skill-v0.1.0.zip
  • kumihan-zilu-documents-skill-v0.1.0.zip
  • kumihan-zilu-review-skill-v0.1.0.zip
