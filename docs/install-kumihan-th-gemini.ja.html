03

導入手順

必要なSkillをダウンロードして展開し、SKILL.mdと同梱資料を読みます。対応する導入機能がない場合は作業の文脈として資料を渡し、ネイティブ導入ではなく指示文に沿った利用であると明示します。

Gemini：本製品にはGeminiネイティブ拡張は含まれません。SKILL.mdと同梱資料を作業の文脈として利用します。ChatGPT/Codex用プラグインをGemini拡張として登録しないでください。

04

原稿を変更しないテスト

「น้ำชา เก่ง ภาษาไทย」の改行と声調記号の表示を、元の原稿を変更せずにレビューしてください。実際に検査した項目と未検証事項を分けてください。

05

更新

更新前に旧版を保存してください。新しいタグとSHA256SUMSを確認し、本製品のフォルダーのみ置き換えます。旧版への差し戻しでロールバックできます。削除はホストの管理機能で行うか、作業の文脈から資料を取り除きます。

06

対応範囲と限界

各ホストでのネイティブ導入・呼び出し：not-checked。語分割と表示はエンジン・フォント・環境に依存します。実描画と意味は人による確認が必要です。すべての組版を自動修正する保証はありません。
