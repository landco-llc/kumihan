01 / Pilih format

Plugin memuat empat skill. Setiap skill juga tersedia sebagai arsip tersendiri bersama aturan dan sumbernya. Mengunggah ZIP ke percakapan tidak otomatis memasangnya.

02 / Unduh dan verifikasi

Unduh berkas ZIP dari GitHub Release v0.1.0 lalu cocokkan nilai SHA-256 dengan SHA256SUMS.txt.

  • Plugin: kumihan-laras-claude-code-plugin-v0.1.0.zip
  • Skill mandiri: kumihan-laras-claude-skill-v0.1.0.zip
  • Skill mandiri: kumihan-laras-web-claude-skill-v0.1.0.zip
  • Skill mandiri: kumihan-laras-documents-claude-skill-v0.1.0.zip
  • Skill mandiri: kumihan-laras-review-claude-skill-v0.1.0.zip

SHA256SUMS.txt · MANIFEST.json · GitHub Release v0.1.0

03 / Pasang

Ekstrak plugin Claude Code dengan folder kumihan-laras yang utuh, lalu jalankan Claude Code dengan --plugin-dir. Jika didukung, Anda dapat memakai marketplace repositori.

claude --plugin-dir /absolute/path/kumihan-laras
claude plugin validate /absolute/path/kumihan-laras
/plugin marketplace add landco-llc/kumihan
/plugin install kumihan-laras@kumihan-marketplace

05 / Perbarui

Simpan penyesuaian lokal, verifikasi versi serta checksum baru, lalu perbarui lewat alat yang sesuai. Pemasangan tidak otomatis diperbarui oleh commit GitHub.

06 / Cakupan dan batasan

Publikasi di GitHub tidak berarti terdaftar dalam direktori resmi ChatGPT, Claude atau Gemini. Hasil pengecekan statis tidak menggantikan pemeriksaan tampilan nyata atau penyunting manusia.
