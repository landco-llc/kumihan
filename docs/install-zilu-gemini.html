KUMIHAN｜字律 · v0.1.0

ChatGPT / CodexClaudeGemini

安装步骤

  1. 前提：支持Extensions的Gemini CLI。Gemini App 的Skills上传未验证。
  2. 把完整Extension ZIP解压到空目录，确认根部存在 gemini-extension.json，再运行 gemini extensions install /absolute/path/to/folder，并阅读安装器的权限提示。
  3. 单个Skill ZIP可解压为独立目录，通过CLI当前支持的Skills安装流程使用。不要把本仓库根URL当作字律Extension；根部属于其他产品。App导入只在实际账户提供入口时尝试。

Gemini CLI extensions · Gemini CLI Skills

下载与核验

在 downloads 目录使用 sha256sum -c SHA256SUMS.txt（macOS 可用 shasum -a 256 -c）。只下载单个ZIP时对照 MANIFEST.json 对应项校验。
