ホストに合わせて導入する

  1. Extensionsに対応するGemini CLIを使います。展開先のルートにgemini-extension.jsonがあることを確認します。
  2. 次のコマンドでローカルフォルダを導入し、権限の確認画面を読みます。
  3. 独立スキルZIPは別の配布形式です。Gemini Appsへの取り込みは手動・未検証です。CLI Extensionをチャット用パッケージとして扱いません。
gemini extensions install /absolute/path/kumihan-ar

公開されたチェックサムとSHA-256を照合します。選んだ5 ZIPを同じフォルダに置き、次のGNUコマンドで5件すべてのOKを確認します。単体ZIPやmacOSではshasum -a 256の結果をMANIFEST.jsonの該当項目と照合します。

sha256sum --ignore-missing -c SHA256SUMS.txt
