នេះជាការណែនាំអំពីរបៀបប្រើ KUMIHAN｜លំនឹង ជាមួយ Gemini CLI និងកម្មវិធី Gemini។

អំពី v0.1.0 កំណែនេះសម្រាប់ឱ្យអ្នកសាកល្បងដំឡើងក្នុងបរិស្ថានរបស់អ្នកផ្ទាល់។ ដោយសារយើងមិនទាន់បានពិនិត្យដំណើរការនៅក្នុងឧបករណ៍នីមួយៗបានគ្រប់គ្រាន់នៅឡើយ ជំហានខ្លះអាចនឹងមិនដំណើរការដូចការរំពឹងទុក។

1. ជ្រើសរើសវិធីដំឡើង

កន្លែងដែលចង់ប្រើវិធីដែលណែនាំ
Gemini CLI (ទាំង 4 ព្រមគ្នា)A. ដំឡើងជាផ្នែកបន្ថែម
Gemini CLI (តែអ្វីដែលត្រូវការ)B. ជ្រើសរើស Skill ដើម្បីដំឡើង
កម្មវិធី Gemini (វេប Mac និងស្មាតហ្វូន)C. ផ្ទុក Skill ឡើង

A. Gemini CLI៖ ដំឡើងជាផ្នែកបន្ថែម

វិធីនេះដំឡើង Skill ទាំង 4 ព្រមគ្នា។

  1. ទាញយក ឯកសារ ZIP នៃផ្នែកបន្ថែម។
  2. នៅពេលពន្លាឯកសារ ZIP អ្នកនឹងទទួលបានថត kumihan-lumnung។
  3. ដំឡើងដោយបញ្ជាក់ថតនោះ។
    gemini extensions install "/absolute/path/kumihan-lumnung"

នៅពេលអេក្រង់បញ្ជាក់លេចឡើង សូមពិនិត្យខ្លឹមសារមុននឹងបន្ត។ បន្ទាប់ពីដំឡើងរួច ផ្នែកបន្ថែមនឹងដំណើរការនៅក្នុងគម្រោងទាំងអស់។

ប្រសិនបើដំឡើងពី ZIP វានឹងមិនធ្វើបច្ចុប្បន្នភាពដោយស្វ័យប្រវត្តិទេ។ នៅពេលមានកំណែថ្មី សូមប្ដូរទៅឯកសារ ZIP ថ្មី។

B. Gemini CLI៖ ជ្រើសរើស Skill ដើម្បីដំឡើង

វិធីនេះដំឡើងតែ Skill ដែលត្រូវការ សម្រាប់គម្រោងនីមួយៗ។ ប្រសិនបើបានដំឡើងតាមវិធី A រួចហើយ មិនចាំបាច់ធ្វើជំហាននេះទេ។

ឧទាហរណ៍ ដើម្បីដំឡើង kumihan-lumnung សូមដំណើរការពាក្យបញ្ជាខាងក្រោមនៅក្នុងគម្រោងគោលដៅ៖

gemini skills install https://github.com/landco-llc/kumihan --path plugins/kumihan-lumnung/skills/kumihan-lumnung --scope workspace

ដើម្បីដំឡើង Skill ផ្សេងទៀត សូមប្ដូរ --path ដូចខាងក្រោម៖

  • plugins/kumihan-lumnung/skills/kumihan-lumnung-web — គេហទំព័រ
  • plugins/kumihan-lumnung/skills/kumihan-lumnung-documents — របាយការណ៍ និងស្លាយ
  • plugins/kumihan-lumnung/skills/kumihan-lumnung-review — ការត្រួតពិនិត្យ

--scope workspace គឺជាការកំណត់សម្រាប់ប្រើ «តែក្នុងគម្រោងនេះ»។ ប្រសិនបើលុបវាចោល Skill នឹងអាចប្រើបាននៅក្នុងគម្រោងទាំងអស់។

នៅពេលធ្វើបច្ចុប្បន្នភាព

ដំណើរការពាក្យបញ្ជាដដែលម្ដងទៀត។ Skill ដែលបានដំឡើងរួចនឹងត្រូវបានជំនួស ដូច្នេះប្រសិនបើអ្នកបានកែប្រែខ្លឹមសារដោយខ្លួនឯង សូមរក្សាទុកវាជាមុនសិន។

C. កម្មវិធី Gemini៖ ផ្ទុក Skill ឡើង

  1. ទាញយកឯកសារ ZIP របស់ Skill ដែលចង់ប្រើ។
    • kumihan-lumnung — ចំណុចចាប់ផ្ដើម
    • kumihan-lumnung-web — គេហទំព័រ
    • kumihan-lumnung-documents — របាយការណ៍ និងស្លាយ
    • kumihan-lumnung-review — ការត្រួតពិនិត្យ
  2. នៅក្នុង Gemini សូមបើក Customize (ប្រសិនបើរកមិនឃើញ សូមបើក More) → Skills → Upload។
  3. ជ្រើសរើសឯកសារ ZIP ម្ដងមួយ ពិនិត្យខ្លឹមសារ រួចចុច Create។

ចំណាំ

  • អាចប្រើបានជាមួយគណនី Google ផ្ទាល់ខ្លួនរបស់អ្នកដែលមានអាយុចាប់ពី 18 ឆ្នាំឡើងទៅ។ បច្ចុប្បន្ន គណនីសម្រាប់ការងារ ឬសាលារៀនមិនអាចប្រើបានទេ។
  • ត្រូវបើក «Keep Activity (ការរក្សាទុកសកម្មភាព)»។
  • មុខងារនេះកំពុងដាក់ឱ្យប្រើជាបណ្ដើរៗ ដូច្នេះប្រហែលជាមិនទាន់បង្ហាញនៅឡើយ។ សម្រាប់ព័ត៌មានលម្អិត សូមមើល ជំនួយផ្លូវការរបស់ Gemini។
  • ឯកសារ ZIP នៃផ្នែកបន្ថែម (សម្រាប់ Gemini CLI) មិនអាចប្រើនៅទីនេះបានទេ។
  • Skill ដែលបានផ្ទុកឡើងមិនធ្វើបច្ចុប្បន្នភាពដោយស្វ័យប្រវត្តិទេ។ នៅពេលមានកំណែថ្មី សូមផ្ទុកឡើងម្ដងទៀត។

2. សាកល្បងប្រើ

ជាដំបូង យើងណែនាំឱ្យសាកល្បងជាមួយសំណើដែលមិនកែប្រែឯកសារ។

ខ្ញុំគ្រោងនឹងរៀបចំស្លាយបទបង្ហាញជាភាសាខ្មែរ។ សូមប្រាប់ខ្ញុំអំពីចំណុចដែលគួរប្រុងប្រយ័ត្ន។ សូមកុំកែប្រែឯកសារណាមួយ។

ពិនិត្យថាឯកសារត្រឹមត្រូវ (ស្រេចចិត្ត)

ប្រសិនបើចង់ពិនិត្យថាឯកសារដែលបានទាញយកមិនខូច សូមប្រើ SHA256SUMS.txt។

ដាក់ SHA256SUMS.txt ក្នុងថតតែមួយជាមួយឯកសារ ZIP ដែលបានទាញយក រួចដំណើរការពាក្យបញ្ជាខាងក្រោមក្នុង terminal។ ប្រសិនបើគ្មាន shasum សូមផ្ទៀងផ្ទាត់ SHA-256 ដោយប្រើពាក្យបញ្ជាផ្សេង ដូចជា Get-FileHash របស់ Windows PowerShell។

shasum -a 256 -c --ignore-missing SHA256SUMS.txt

ប្រសិនបើបន្ទាត់នៃឯកសារដែលបានទាញយកបង្ហាញ OK មានន័យថាគ្មានបញ្ហាទេ។
