01 / ជ្រើសប្រភេទឯកសារ

Plugin មានជំនាញ ៤។ ជំនាញនីមួយៗអាចទាញយកដាច់ដោយឡែក។ ការភ្ជាប់ ZIP ទៅក្នុងការជជែកមិនមែនជាការដំឡើងទេ។

02 / ទាញយក និងផ្ទៀងផ្ទាត់

ទាញយក ZIP កំណែ v0.1.0 ពី GitHub Release ហើយផ្ទៀងផ្ទាត់ SHA-256 មុនដំឡើង។

  • Plugin: kumihan-lumnung-gemini-cli-extension-v0.1.0.zip
  • ជំនាញ: kumihan-lumnung-gemini-skill-v0.1.0.zip
  • ជំនាញ: kumihan-lumnung-web-gemini-skill-v0.1.0.zip
  • ជំនាញ: kumihan-lumnung-documents-gemini-skill-v0.1.0.zip
  • ជំនាញ: kumihan-lumnung-review-gemini-skill-v0.1.0.zip

SHA256SUMS.txt · MANIFEST.json · GitHub Release v0.1.0

03 / ដំឡើង

ស្រាយ ZIP ដែលមាន gemini-extension.json រួចដំឡើងតាម Gemini CLI។

gemini extensions install /absolute/path/kumihan-lumnung
gemini extensions list

INSTALL.md

04 / សាកល្បងដោយរក្សាអត្ថបទដើម

សូមបញ្ជាក់ភាសា km-KH ប្រភេទការងារ និងសិទ្ធិកែប្រែ។ ឧទាហរណ៍៖

ប្រើ kumihan-lumnung-review ពិនិត្យអក្សរខ្មែរ ដោយមិនកែអត្ថបទដើម។

ពិនិត្យអត្ថបទដើមដោយមិនសរសេរជាន់លើ៖

python runtime/checks.py input.txt --locale km-KH

05 / ធ្វើបច្ចុប្បន្នភាព

ទាញយកកំណែថ្មី និងផ្ទៀងផ្ទាត់ checksum មុនធ្វើបច្ចុប្បន្នភាព។

06 / វិសាលភាព និងកម្រិត

ច្បាប់ ៣០ និងសេណារីយ៉ូ ២៤ ជាសេចក្តីណែនាំ។ ការបង្ហាញនៅលើកម្មវិធីពិត និងការត្រួតពិនិត្យដោយអ្នកប្រើភាសាខ្មែរនៅតែត្រូវការផ្ទៀងផ្ទាត់។
