DOCUMENTATION / ClaudeInstallation steps

01 / Installation steps

  1. Prerequisite: Claude Code CLI; Claude chat Skills upload depends on account availability.
  2. Extract the full plugin and start claude --plugin-dir /absolute/path/kumihan-zilu. Validate with claude plugin validate /absolute/path/kumihan-zilu where supported.
  3. For Claude chat, upload an individual skill ZIP through the actual Skills interface. Session-local plugin loading does not imply official marketplace listing.

02 / Downloads & checksums

From downloads/, run sha256sum -c SHA256SUMS.txt (or shasum -a 256 -c on macOS). For one ZIP, compare its hash with the matching MANIFEST.json entry.

  • kumihan-zilu-claude-plugin-v0.1.0.zip (Source ZIP)
  • kumihan-zilu-entry-claude-skill-v0.1.0.zip (Source ZIP)
  • kumihan-zilu-web-claude-skill-v0.1.0.zip (Source ZIP)

03 / Invoke & update

Use kumihan-zilu-review to review this Simplified Chinese page without changing source text, numbers or brands.

请保留原文与数字，使用 kumihan-zilu-web 检查页面。

Use kumihan-zilu-documents to review a report while preserving its source text.

Back up customizations, verify the new package, then use the host update or reinstall workflow. If no installation interface is available, read SKILL.md from GitHub as manual guidance; that is not plugin installation.

The source and website are public. Native plugin invocation in each AI tool, marketplace listing and Office/PDF rendering quality are verified separately.

Four independent skills: start and scope, web and interfaces, documents and slides, read-only review.
