DOCUMENTATION / ClaudeШаги и примечания

Здесь описано, как использовать KUMIHAN｜Лад в Claude Code и чате Claude.

О версии v0.1.0 Эта версия предназначена для того, чтобы вы могли попробовать установку в своей среде. Работа в каждом инструменте ещё не проверена в достаточной мере, поэтому что-то может работать не так, как ожидается.

1. Выберите способ установки

Где вы хотите использоватьРекомендуемый способ
Claude CodeA. Установить с GitHub (легко обновлять)
Claude Code (установка из ZIP)B. Установить из ZIP
Чат Claude (claude.ai и приложения)C. Загрузить Skills

Claude Code и чат Claude устанавливаются разными способами.

A. Claude Code: установка с GitHub

  1. В терминале добавьте источник KUMIHAN.
    claude plugin marketplace add "https://github.com/landco-llc/kumihan.git#main"
  2. В разговоре в Claude Code введите:
    /plugin install kumihan-lad@kumihan-marketplace
  3. Проверьте сведения, выберите область действия (только для вас, только для этого проекта и т. д.) и установите.

После установки станут доступны следующие команды:

  • /kumihan-lad:kumihan-lad
  • /kumihan-lad:kumihan-lad-web
  • /kumihan-lad:kumihan-lad-documents
  • /kumihan-lad:kumihan-lad-review

B. Claude Code: установка из ZIP

  1. Скачайте ZIP-файл плагина для Claude Code.
  2. После распаковки ZIP-файла появится папка kumihan-lad.
  3. Запустите Claude Code, указав эту папку:
    claude --plugin-dir "/absolute/path/kumihan-lad"

Обратите внимание

  • Используйте содержимое папки как есть. Не удаляйте файлы и не добавляйте в неё другие.
  • При этом способе обновления не устанавливаются автоматически. Когда выйдет новая версия, замените папку содержимым нового ZIP-файла.

C. Чат Claude: загрузка Skills

Этот способ подходит для claude.ai и приложений Claude.

  1. Скачайте ZIP-файлы нужных вам Skills.
    • kumihan-lad — отправная точка
    • kumihan-lad-web — веб-страницы
    • kumihan-lad-documents — отчёты и слайды
    • kumihan-lad-review — проверка
  2. В Claude откройте Customize → Skills и с помощью кнопки добавления выберите Upload a skill.
  3. Загрузите ZIP-файлы по одному и включите каждый Skill.

Обратите внимание

  • ZIP-файл плагина для Claude Code здесь не подойдёт. Используйте ZIP-файлы отдельных Skills.
  • Загружайте ZIP-файлы, не переименовывая их.
  • Для работы Skills в настройках должно быть включено выполнение кода. Подробнее — в официальном руководстве Claude.
  • В учётных записях организаций доступность может зависеть от настроек администратора.
  • Загруженные Skills не обновляются автоматически. Когда выйдет новая версия, загрузите их ещё раз.

2. Попробуйте

Для начала лучше попробовать запрос, который не изменяет файлы:

Я планирую веб-страницу на русском языке. На что мне стоит обратить внимание? Пожалуйста, не изменяй файлы.

Проверьте файлы (необязательно)

Если вы хотите убедиться, что скачанные файлы не повреждены, используйте SHA256SUMS.txt.

Положите SHA256SUMS.txt в ту же папку, что и скачанные ZIP-файлы, и выполните в терминале следующую команду. Если shasum недоступна, сверьте SHA-256 другим способом, например с помощью Get-FileHash в Windows PowerShell.

shasum -a 256 -c --ignore-missing SHA256SUMS.txt

Если в строках скачанных файлов указано OK, всё в порядке.
