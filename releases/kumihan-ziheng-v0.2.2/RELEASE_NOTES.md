# KUMIHAN｜字衡 v0.2.2

Traditional Chinese vertical typography guidance for Taiwan and Hong Kong.

- Separate reading, display and hybrid purposes for vertical and horizontal compositions.
- Add contextual punctuation, quotations, mixed-script runs, font evidence and reading-order guidance.
- Preserve fixed source text and Unicode sequences; retain earlier distribution files.
- Add 30 vertical case definitions with explicit verification states. Case definitions and static checks do not establish browser, native Office, assistive-technology or native-language acceptance.

Four independent Skills are available in three host families: 15 ZIPs. Verify the exact downloads with MANIFEST.json and SHA256SUMS.txt. Native host installation and invocation require acceptance in the target environment.
