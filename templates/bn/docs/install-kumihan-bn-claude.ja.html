03 / 導入する

For Claude Code, extract the plugin and register the directory with .claude-plugin/plugin.json using your supported plugin installation mechanism. You may instead install a standalone Skill where supported.

配布物を展開し、各ホストの現行ドキュメントに従ってフォルダを登録してください。

04 / 原稿を変えずに試す

最初は読み取り専用で「কি কো কৌ ক্ষ স্ত্র র‍্য অ্যা」を確認し、Unicode格納順とZWJ/ZWNJを保持してください。

Claude.ai browser chat and Claude Code have different installation capabilities. Do not describe a plugin archive as a marketplace listing.

05 / 更新する

更新時はマニフェストと変更履歴を確認してからパッケージを入れ替えます。
