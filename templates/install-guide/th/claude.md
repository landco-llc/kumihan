## A. Claude Code: ติดตั้งจาก GitHub

1. ในเทอร์มินัล ให้ลงทะเบียนแหล่งเผยแพร่ของ KUMIHAN

   ```sh
   claude plugin marketplace add "https://github.com/landco-llc/kumihan.git#main"
   ```

2. ในการสนทนาของ Claude Code ให้ป้อนคำสั่งต่อไปนี้

   ```text
   /plugin install {{plugin}}@kumihan-marketplace
   ```

3. ตรวจสอบรายละเอียด เลือกขอบเขตการใช้งาน (เฉพาะตัวคุณ เฉพาะโปรเจกต์นี้ เป็นต้น) แล้วติดตั้ง

## {{L_zip}}. Claude Code: ติดตั้งจาก ZIP

1. ดาวน์โหลด[ไฟล์ ZIP ของปลั๊กอินสำหรับ Claude Code]({{plugin_url}})
{{#if plugin_folder}}
2. เมื่อแตกไฟล์ ZIP จะได้โฟลเดอร์ `{{plugin_folder}}`
{{else}}
2. สร้างโฟลเดอร์ `{{plugin}}` เปล่า แล้วแตกไฟล์ ZIP ลงในโฟลเดอร์นั้น
{{/if}}
3. เริ่ม Claude Code โดยระบุโฟลเดอร์นั้น

   ```sh
   claude --plugin-dir "/absolute/path/{{plugin_dir}}"
   ```

**ข้อควรทราบ**

- โปรดใช้เนื้อหาในโฟลเดอร์ตามเดิม อย่าลบไฟล์ออกหรือใส่ไฟล์อื่นปนเข้าไป
- วิธีนี้จะไม่อัปเดตอัตโนมัติ เมื่อมีรุ่นใหม่ โปรดเปลี่ยนเป็นไฟล์ ZIP รุ่นใหม่

## {{L_chat}}. แชต Claude: อัปโหลด Skill

วิธีนี้ใช้กับ claude.ai และแอป Claude

1. ดาวน์โหลดไฟล์ ZIP ของ Skill ที่ต้องการใช้
{{skills_list_indented}}
2. ใน Claude ให้เปิด **Customize → Skills** แล้วเลือก **Upload a skill** จากปุ่มเพิ่ม
3. อัปโหลดไฟล์ ZIP ทีละไฟล์ แล้วเปิดใช้งาน Skill

**ข้อควรทราบ**

- ใช้ไฟล์ ZIP ของปลั๊กอินสำหรับ Claude Code ที่นี่ไม่ได้ โปรดใช้ไฟล์ ZIP ของ Skill
- โปรดอัปโหลดโดยไม่เปลี่ยนชื่อไฟล์ ZIP
- การใช้ Skill ต้องเปิด “การรันโค้ด” ไว้ในการตั้งค่า ดูรายละเอียดได้ที่[คู่มืออย่างเป็นทางการของ Claude](https://support.claude.com/en/articles/12512180-use-skills-in-claude)
- สำหรับบัญชีขององค์กร อาจใช้ไม่ได้ ขึ้นอยู่กับการตั้งค่าของผู้ดูแลระบบ
- Skill ที่อัปโหลดจะไม่อัปเดตอัตโนมัติ เมื่อมีรุ่นใหม่ โปรดอัปโหลดอีกครั้ง

## 2. ลองใช้งาน

ในครั้งแรก เราแนะนำให้ลองด้วยคำขอที่ไม่แก้ไขไฟล์

> ฉันกำลังวางแผนจะทำหน้าเว็บภาษาไทย มีจุดไหนที่ควรระวังบ้าง โปรดอย่าแก้ไขไฟล์ใด ๆ

## ตรวจสอบความถูกต้องของไฟล์ (ไม่บังคับ)

หากต้องการตรวจสอบว่าไฟล์ที่ดาวน์โหลดมาไม่เสียหาย ให้ใช้ [SHA256SUMS.txt]({{sums}})

วาง SHA256SUMS.txt ไว้ในโฟลเดอร์เดียวกับไฟล์ ZIP ที่ดาวน์โหลดมา แล้วรันคำสั่งต่อไปนี้ในเทอร์มินัล หากไม่มี `shasum` ให้ตรวจสอบค่า SHA-256 ด้วยคำสั่งอื่น เช่น `Get-FileHash` ของ Windows PowerShell

```sh
shasum -a 256 -c --ignore-missing SHA256SUMS.txt
```

หากบรรทัดของไฟล์ที่ดาวน์โหลดมาแสดง `OK` แสดงว่าไฟล์ไม่มีปัญหา
