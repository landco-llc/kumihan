## A. เพิ่ม Skill ใน ChatGPT

ใช้วิธีนี้ได้เมื่อหน้าจอ ChatGPT มีเมนู “Skills” และตัวเลือกสำหรับอัปโหลด

1. เลือกไฟล์ ZIP ของ Skill หนึ่งไฟล์แล้วอัปโหลด
2. ตรวจสอบรายละเอียดที่แสดง แล้วเพิ่ม Skill
3. ทำซ้ำขั้นตอนเดียวกันตามจำนวน Skill ที่ต้องการ

**ข้อควรทราบ**

- ใช้ไฟล์ ZIP ของปลั๊กอินกับวิธีนี้ไม่ได้ โปรดใช้ไฟล์ ZIP ของ Skill
- การแนบไฟล์ในแชตเพียงอย่างเดียวไม่ได้เป็นการเพิ่ม Skill
- หากไม่พบเมนูดังกล่าว อาจเป็นเพราะแผนการใช้งานหรือแอปที่คุณใช้ยังไม่รองรับ โปรดดู[คู่มืออย่างเป็นทางการของ OpenAI](https://learn.chatgpt.com/docs/build-skills)

## B. ลงทะเบียนเป็นปลั๊กอินใน ChatGPT

วิธีนี้จะรวม Skill ทั้ง 4 รายการแล้วลงทะเบียนเป็นปลั๊กอินที่คุณใช้ได้เพียงคนเดียว

1. เปิดการสนทนาใหม่ใน ChatGPT แล้วเลือก `@plugin-creator`
2. แนบไฟล์ ZIP ของปลั๊กอิน
3. ส่งคำขอดังนี้

   > ช่วยลงทะเบียนแพ็กเกจนี้เป็นปลั๊กอินส่วนตัวสำหรับฉันใช้เอง และอย่าส่งเข้าไดเรกทอรีสาธารณะ

4. เมื่อลงทะเบียนเสร็จ **{{display}}** จะปรากฏใน Plugins ที่ “Personal” หรือ “Created by me”
5. ติดตั้งหากจำเป็น แล้วเปิดใช้งานในการสนทนาใหม่

**ข้อควรทราบ**

- ปลั๊กอินอาจถูกบันทึกไว้ในเวิร์กสเปซของทีม หากต้องการใช้เพียงคนเดียว โปรดตรวจสอบปลายทางก่อนลงทะเบียน
- ฟีเจอร์นี้อาจใช้ไม่ได้ ขึ้นอยู่กับแผนการใช้งานหรือการตั้งค่าเวิร์กสเปซ ดูรายละเอียดได้ที่ [Build plugins](https://learn.chatgpt.com/docs/build-plugins) และ [Plugins](https://learn.chatgpt.com/docs/plugins)
- ปลั๊กอินที่ลงทะเบียนด้วยวิธีนี้ใช้ได้เฉพาะในบัญชีของคุณ และจะไม่แสดงในไดเรกทอรีสาธารณะ

## C. คัดลอกโฟลเดอร์ไปยัง Codex

เมื่อแตกไฟล์ ZIP ของ Skill จะได้โฟลเดอร์ เช่น `{{first}}` ให้คัดลอกโฟลเดอร์นี้ไปยังตำแหน่งที่ Codex อ่าน Skill

| ขอบเขตการใช้งาน | ปลายทาง |
| --- | --- |
| ใช้เฉพาะบางโปรเจกต์ | `.agents/skills/` ภายในโปรเจกต์ |
| ใช้กับทุกโปรเจกต์ | `~/.agents/skills/` ในโฟลเดอร์โฮม |

ตัวอย่างเช่น หากต้องการเพิ่ม `{{first}}` ลงในโปรเจกต์ ให้ทำดังนี้

```sh
mkdir -p /path/to/your-project/.agents/skills
cp -R {{first}} /path/to/your-project/.agents/skills/
```

**ข้อควรทราบ**

- โปรดคัดลอกทั้งโฟลเดอร์พร้อมเนื้อหาทั้งหมด หากมีเพียงบางไฟล์ Skill จะทำงานไม่ถูกต้อง
- หากมีโฟลเดอร์ชื่อเดียวกันอยู่แล้ว โปรดตรวจสอบเนื้อหาก่อนเขียนทับ

> ฉันกำลังวางแผนจะทำรายงานภาษาไทย มีจุดไหนที่ควรระวังบ้าง โปรดอย่าแก้ไขไฟล์ใด ๆ

## ตรวจสอบความถูกต้องของไฟล์ (ไม่บังคับ)

หากต้องการตรวจสอบว่าไฟล์ที่ดาวน์โหลดมาไม่เสียหาย ให้ใช้ [SHA256SUMS.txt]({{sums}})

วาง SHA256SUMS.txt ไว้ในโฟลเดอร์เดียวกับไฟล์ ZIP ที่ดาวน์โหลดมา แล้วรันคำสั่งต่อไปนี้ในเทอร์มินัล หากไม่มี `shasum` ให้ตรวจสอบค่า SHA-256 ด้วยคำสั่งอื่น เช่น `Get-FileHash` ของ Windows PowerShell

```sh
shasum -a 256 -c --ignore-missing SHA256SUMS.txt
```

หากบรรทัดของไฟล์ที่ดาวน์โหลดมาแสดง `OK` แสดงว่าไฟล์ไม่มีปัญหา
