## A. Gemini CLI— extension အဖြစ် တပ်ဆင်ပါ

ဤနည်းဖြင့် ကျွမ်းကျင်မှု လေးခုလုံးကို တစ်ပြိုင်နက် တပ်ဆင်နိုင်သည်။

1. [extension ZIP]({{plugin_url}}) ကို ဒေါင်းလုဒ်လုပ်ပါ။
{{#if plugin_folder}}
2. ZIP ကို ဖြည်လိုက်လျှင် `{{plugin_folder}}` folder ရမည်။
{{else}}
2. `{{plugin}}` folder အလွတ်တစ်ခု ပြုလုပ်ပြီး ZIP ကို ၎င်းအတွင်းသို့ ဖြည်ပါ။
{{/if}}
3. ထို folder မှ တပ်ဆင်ပါ—

   ```sh
   gemini extensions install "/absolute/path/{{plugin_dir}}"
   ```

ဆက်မလုပ်မီ အတည်ပြုချက် မေးခွန်းကို စစ်ဆေးပါ။ တပ်ဆင်ပြီးသည်နှင့် extension သည် project အားလုံးတွင် အလုပ်လုပ်မည်။

ZIP မှ တပ်ဆင်ထားသော extension သည် အလိုအလျောက် update မဖြစ်ပါ။ ဗားရှင်းအသစ် ထွက်လာလျှင် ZIP အသစ်ဖြင့် အစားထိုးပါ။

## B. Gemini CLI— ကျွမ်းကျင်မှု တစ်ခုချင်း တပ်ဆင်ပါ

ဤနည်းဖြင့် လိုအပ်သော ကျွမ်းကျင်မှုများကိုသာ project တစ်ခုအတွက် တပ်ဆင်နိုင်သည်။ A နည်းကို အသုံးပြုပြီးပါက ဤအဆင့် မလိုအပ်ပါ။

ဥပမာ `{{first}}` ကို တပ်ဆင်ရန် သင့် project တွင် အောက်ပါအတိုင်း run ပါ—

```sh
gemini skills install https://github.com/landco-llc/kumihan --path {{skills_path}}/{{first}} --scope workspace
```

အခြား ကျွမ်းကျင်မှုများအတွက် `--path` ကို အောက်ပါအတိုင်း ပြောင်းပါ—

{{gemini_paths}}

`--scope workspace` သည် ကျွမ်းကျင်မှုကို ဤ project တွင်သာ ကန့်သတ်သည်။ မထည့်လျှင် project အားလုံးတွင် အသုံးပြုနိုင်မည်။

**update လုပ်ရန်**

တူညီသော command ကို ထပ်မံ run ပါ။ တပ်ဆင်ထားသော ကျွမ်းကျင်မှုကို အစားထိုးမည်ဖြစ်၍ ကိုယ်တိုင် ပြင်ဆင်ထားသည်များ ရှိလျှင် ဦးစွာ သိမ်းဆည်းထားပါ။

## C. Gemini app— ကျွမ်းကျင်မှုများကို upload လုပ်ပါ

1. အသုံးပြုလိုသော ကျွမ်းကျင်မှု ZIP များကို ဒေါင်းလုဒ်လုပ်ပါ။
{{skills_list_indented}}
2. Gemini တွင် **Customize** (မမြင်ရလျှင် **More**) → **Skills** → **Upload** ကို ဖွင့်ပါ။
3. ZIP တစ်ခုချင်းကို ရွေးပြီး အချက်အလက်များကို စစ်ဆေးကာ **Create** ကို နှိပ်ပါ။

**သတိပြုရန်**

- အသက် ၁၈ နှစ်နှင့်အထက် အသုံးပြုသူများ၏ ကိုယ်ပိုင် Google အကောင့်များတွင်သာ ရနိုင်သည်။ အလုပ်နှင့် ကျောင်း အကောင့်များကို လက်ရှိတွင် မပံ့ပိုးပါ။
- **Keep Activity** ကို ဖွင့်ထားရမည်။
- ဤလုပ်ဆောင်ချက်ကို အဆင့်လိုက် ဖြန့်ချိနေသဖြင့် သင့်အတွက် မရနိုင်သေးခြင်း ဖြစ်နိုင်သည်။ [Gemini Help](https://support.google.com/gemini/answer/17094296) ကို ကြည့်ပါ။
- extension ZIP (Gemini CLI အတွက်) သည် ဤနေရာတွင် အလုပ်မလုပ်ပါ။
- upload လုပ်ထားသော ကျွမ်းကျင်မှုများသည် အလိုအလျောက် update မဖြစ်ပါ။ ဗားရှင်းအသစ် ထွက်လာလျှင် ထပ်မံ upload လုပ်ပါ။

## 2. စမ်းသုံးကြည့်ပါ

ဖိုင်များကို မပြောင်းလဲသော တောင်းဆိုချက်ဖြင့် စတင်ရန် အကြံပြုပါသည်—

> {{lang}}ဘာသာဖြင့် တင်ပြချက်တစ်ခု ပြုလုပ်ရန် စီစဉ်နေပါသည်။ ဘာတွေကို သတိထားသင့်ပါသလဲ။ ဖိုင်များကို မပြောင်းပါနှင့်။

## ဒေါင်းလုဒ်လုပ်ထားသော ဖိုင်များကို စစ်ဆေးပါ (ရွေးချယ်နိုင်)

ဒေါင်းလုဒ်လုပ်ထားသော ဖိုင်များ ပျက်စီးမှုမရှိကြောင်း စစ်ဆေးလိုလျှင် [SHA256SUMS.txt]({{sums}}) ကို အသုံးပြုပါ။

ဒေါင်းလုဒ်လုပ်ထားသော ZIP ဖိုင်များနှင့် folder တစ်ခုတည်းတွင် SHA256SUMS.txt ကို ထားပြီး terminal တွင် အောက်ပါ command ကို run ပါ။ `shasum` မရှိလျှင် Windows ၏ PowerShell `Get-FileHash` ကဲ့သို့ တူညီသော SHA-256 command ဖြင့် တိုက်စစ်ပါ။

```sh
shasum -a 256 -c --ignore-missing SHA256SUMS.txt
```

ဒေါင်းလုဒ်လုပ်ထားသော ဖိုင်များ၏ စာကြောင်းတွင် `OK` ပြလျှင် ဖိုင်များ ပြည့်စုံမှန်ကန်ပါသည်။
