## A. Claude Code: نصب از GitHub

1. در ترمینال، منبع توزیع KUMIHAN را ثبت کنید.

   ```sh
   claude plugin marketplace add "https://github.com/landco-llc/kumihan.git#main"
   ```

2. در گفت‌وگوی Claude Code، دستور زیر را وارد کنید.

   ```text
   /plugin install {{plugin}}@kumihan-marketplace
   ```

3. محتوا را بررسی کنید، دامنهٔ استفاده (فقط برای خودتان، فقط برای این پروژه و غیره) را برگزینید و نصب کنید.

## {{L_zip}}. Claude Code: نصب از فایل ZIP

1. [فایل ZIP پلاگین Claude Code]({{plugin_url}}) را دریافت کنید.
{{#if plugin_folder}}
2. با باز کردن فایل ZIP، پوشهٔ `{{plugin_folder}}` ایجاد می‌شود.
{{else}}
2. یک پوشهٔ خالی به نام `{{plugin}}` بسازید و فایل ZIP را درون آن باز کنید.
{{/if}}
3. Claude Code را با مشخص کردن همان پوشه اجرا کنید.

   ```sh
   claude --plugin-dir "/absolute/path/{{plugin_dir}}"
   ```

**توجه**

- محتوای پوشه را همان‌طور که هست استفاده کنید. فایلی از آن حذف نکنید و فایل دیگری به آن نیفزایید.
- با این روش، به‌روزرسانی خودکار انجام نمی‌شود. با انتشار نسخهٔ جدید، فایل ZIP را جایگزین کنید.

## {{L_chat}}. گفت‌وگوی Claude: بارگذاری مهارت‌ها

این روش برای استفاده در claude.ai یا برنامه‌های Claude است.

1. فایل‌های ZIP مهارت‌هایی را که می‌خواهید استفاده کنید دریافت کنید.
{{skills_list_indented}}
2. در Claude بخش **Customize → Skills** را باز کنید و از دکمهٔ افزودن، **Upload a skill** را انتخاب کنید.
3. فایل‌های ZIP را یکی‌یکی بارگذاری کنید و مهارت را فعال کنید.

**توجه**

- فایل ZIP پلاگین Claude Code در اینجا کار نمی‌کند. از فایل‌های ZIP مهارت‌ها استفاده کنید.
- فایل‌های ZIP را بدون تغییر نام بارگذاری کنید.
- برای استفاده از مهارت‌ها، باید «اجرای کد» در تنظیمات فعال باشد. برای جزئیات، [راهنمای رسمی Claude](https://support.claude.com/en/articles/12512180-use-skills-in-claude) را ببینید.
- در حساب‌های سازمانی، ممکن است بسته به تنظیمات مدیر، این قابلیت در دسترس نباشد.
- مهارت‌های بارگذاری‌شده به‌طور خودکار به‌روز نمی‌شوند. با انتشار نسخهٔ جدید، دوباره آن‌ها را بارگذاری کنید.

## 2. امتحان کردن

پیشنهاد می‌کنیم ابتدا با درخواستی شروع کنید که هیچ فایلی را تغییر نمی‌دهد.

> قصد دارم یک صفحهٔ وب به زبان فارسی بسازم. به چه نکته‌هایی باید توجه کنم؟ لطفاً هیچ فایلی را تغییر نده.

## بررسی درستی فایل‌ها (اختیاری)

اگر می‌خواهید مطمئن شوید فایل‌های دریافت‌شده سالم هستند، از [SHA256SUMS.txt]({{sums}}) استفاده کنید.

فایل SHA256SUMS.txt را در همان پوشه‌ای بگذارید که فایل‌های ZIP دریافت‌شده در آن قرار دارند و دستور زیر را در ترمینال اجرا کنید. اگر `shasum` در دسترس نیست، مقدار SHA-256 را با `Get-FileHash` در Windows PowerShell یا ابزاری مشابه تطبیق دهید.

```sh
shasum -a 256 -c --ignore-missing SHA256SUMS.txt
```

اگر در سطر فایل دریافت‌شده `OK` نمایش داده شود، فایل سالم است.
