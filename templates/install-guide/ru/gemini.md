## A. Gemini CLI: установка как расширения

Этот способ устанавливает все четыре Skills сразу.

1. Скачайте [ZIP-файл расширения]({{plugin_url}}).
{{#if plugin_folder}}
2. После распаковки ZIP-файла появится папка `{{plugin_folder}}`.
{{else}}
2. Создайте пустую папку `{{plugin}}` и распакуйте ZIP-файл в неё.
{{/if}}
3. Установите расширение, указав эту папку:

   ```sh
   gemini extensions install "/absolute/path/{{plugin_dir}}"
   ```

Когда появится запрос подтверждения, проверьте сведения и продолжите. После установки расширение действует во всех проектах.

Расширение, установленное из ZIP, не обновляется автоматически. Когда выйдет новая версия, замените его содержимым нового ZIP-файла.

## B. Gemini CLI: выбор и установка Skills

Этот способ устанавливает только нужные Skills и только для одного проекта. Если вы воспользовались способом A, этот шаг не нужен.

Например, чтобы установить `{{first}}`, выполните в нужном проекте:

```sh
gemini skills install https://github.com/landco-llc/kumihan --path {{skills_path}}/{{first}} --scope workspace
```

Для других Skills измените `--path` следующим образом:

{{gemini_paths}}

`--scope workspace` ограничивает Skill этим проектом. Без этого параметра он будет доступен во всех ваших проектах.

**Как обновить**

Выполните ту же команду ещё раз. Установленный Skill будет заменён, поэтому заранее сохраните свои изменения в нём.

## C. Приложение Gemini: загрузка Skills

1. Скачайте ZIP-файлы нужных вам Skills.
{{skills_list_indented}}
2. В Gemini откройте **Customize** (если этого пункта нет — **More**) → **Skills** → **Upload**.
3. Выбирайте ZIP-файлы по одному, проверяйте сведения и нажимайте **Create**.

**Обратите внимание**

- Функция доступна для личных аккаунтов Google пользователей от 18 лет. Рабочие и учебные аккаунты пока не поддерживаются.
- Должна быть включена настройка «Keep Activity» («Сохранять историю действий»).
- Функция внедряется постепенно, поэтому у вас она может ещё не отображаться. Подробнее — в [официальной справке Gemini](https://support.google.com/gemini/answer/17094296?hl=ru).
- ZIP-файл расширения (для Gemini CLI) здесь не подойдёт.
- Загруженные Skills не обновляются автоматически. Когда выйдет новая версия, загрузите их ещё раз.

## Проверьте файлы (необязательно)

Если вы хотите убедиться, что скачанные файлы не повреждены, используйте [SHA256SUMS.txt]({{sums}}).

Положите SHA256SUMS.txt в ту же папку, что и скачанные ZIP-файлы, и выполните в терминале следующую команду. Если `shasum` недоступна, сверьте SHA-256 другим способом, например с помощью `Get-FileHash` в Windows PowerShell.

```sh
shasum -a 256 -c --ignore-missing SHA256SUMS.txt
```

Если в строках скачанных файлов указано `OK`, всё в порядке.
