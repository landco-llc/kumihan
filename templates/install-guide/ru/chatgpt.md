## A. Добавьте Skills в ChatGPT

Этот способ подходит, если в ChatGPT есть раздел «Skills» с возможностью загрузки.

1. Выберите один ZIP-файл Skill и загрузите его.
2. Проверьте показанные сведения и добавьте Skill.
3. Повторите эти шаги для каждого нужного Skill.

**Обратите внимание**

- ZIP-файл плагина в этом способе не подойдёт. Используйте ZIP-файлы отдельных Skills.
- Если просто прикрепить файл к чату, он не будет добавлен как Skill.
- Если вы не видите такого пункта, возможно, он ещё недоступен в вашем тарифе или приложении. Подробнее — в [официальном руководстве OpenAI](https://learn.chatgpt.com/docs/build-skills).

## B. Зарегистрируйте плагин в ChatGPT

Этот способ объединяет все четыре Skills в ваш собственный приватный плагин.

1. Откройте в ChatGPT новый разговор и выберите `@plugin-creator`.
2. Прикрепите ZIP-файл плагина.
3. Попросите, например, так:

   > Зарегистрируй, пожалуйста, этот пакет как мой приватный плагин. Не отправляй его в публичный каталог.

4. После регистрации **{{display}}** появится в разделе Plugins — в «Personal» или «Created by me».
5. При необходимости установите плагин и включите его в новом разговоре.

**Обратите внимание**

- Плагин может быть сохранён в рабочее пространство вашей команды. Если он нужен только вам, перед регистрацией проверьте, куда он будет сохранён.
- В зависимости от тарифа или настроек рабочего пространства эта функция может быть недоступна. Подробнее — в разделах [Build plugins](https://learn.chatgpt.com/docs/build-plugins) и [Plugins](https://learn.chatgpt.com/docs/plugins).
- Плагин, зарегистрированный таким способом, доступен только в вашей учётной записи. В публичном каталоге он не появится.

## C. Скопируйте папки для Codex

После распаковки ZIP-файла Skill появится папка, например `{{first}}`. Скопируйте эту папку туда, где Codex ищет Skills.

| Область действия | Куда копировать |
| --- | --- |
| Только в определённом проекте | `.agents/skills/` внутри проекта |
| Во всех проектах | `~/.agents/skills/` в домашней папке |

Например, чтобы добавить `{{first}}` в проект:

```sh
mkdir -p /path/to/your-project/.agents/skills
cp -R {{first}} /path/to/your-project/.agents/skills/
```

**Обратите внимание**

- Копируйте папку целиком, со всем содержимым. Если скопировать только часть файлов, Skill не будет работать правильно.
- Если папка с таким же именем уже существует, проверьте её содержимое, прежде чем перезаписывать.

После установки откройте новый разговор и вызовите Skill.

| Инструмент | Как вызвать |
| --- | --- |
| ChatGPT | выбрать через `@` |
| Codex | выбрать через `$` или `/skills` |

Для начала лучше попробовать запрос, который не изменяет файлы:

> Я планирую отчёт на русском языке. На что мне стоит обратить внимание? Пожалуйста, не изменяй файлы.

## Проверьте файлы (необязательно)

Если вы хотите убедиться, что скачанные файлы не повреждены, используйте [SHA256SUMS.txt]({{sums}}).

Положите SHA256SUMS.txt в ту же папку, что и скачанные ZIP-файлы, и выполните в терминале следующую команду. Если `shasum` недоступна, сверьте SHA-256 другим способом, например с помощью `Get-FileHash` в Windows PowerShell.

```sh
shasum -a 256 -c --ignore-missing SHA256SUMS.txt
```

Если в строках скачанных файлов указано `OK`, всё в порядке.
