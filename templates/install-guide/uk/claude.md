## A. Claude Code: встановлення з GitHub

1. У терміналі додайте маркетплейс KUMIHAN.

   ```sh
   claude plugin marketplace add "https://github.com/landco-llc/kumihan.git#main"
   ```

2. У розмові в Claude Code введіть:

   ```text
   /plugin install {{plugin}}@kumihan-marketplace
   ```

3. Перегляньте відомості, виберіть область дії (лише для вас, для цього проєкту тощо) і встановіть.


## {{L_chat}}. Чат Claude: завантаження навичок

Цей спосіб підходить для claude.ai і застосунків Claude.

1. Завантажте ZIP-файли потрібних навичок.
{{skills_list_indented}}
2. У Claude відкрийте **Customize → Skills** і за допомогою кнопки додавання виберіть **Upload a skill**.
3. Завантажте ZIP-файли по одному й увімкніть кожну навичку.

**Зверніть увагу**

- ZIP-файл плагіна для Claude Code тут не підійде. Використовуйте ZIP-файли окремих навичок.
- Завантажуйте ZIP-файли, не перейменовуючи їх.
- Для роботи навичок у налаштуваннях має бути ввімкнено виконання коду. Докладніше — в [офіційному посібнику Claude](https://support.claude.com/en/articles/12512180-use-skills-in-claude).
- В облікових записах організацій доступність може залежати від налаштувань адміністратора.
- Завантажені навички не оновлюються автоматично. Коли вийде нова версія, завантажте їх ще раз.

## Перевірте файли (необов’язково)

Якщо хочете переконатися, що завантажені файли не пошкоджено, скористайтеся [SHA256SUMS.txt]({{sums}}).

Покладіть SHA256SUMS.txt у ту саму теку, що й завантажені ZIP-файли, і виконайте в терміналі таку команду. Якщо `shasum` недоступна, звірте SHA-256 іншим способом, наприклад за допомогою `Get-FileHash` у Windows PowerShell.

```sh
shasum -a 256 -c --ignore-missing SHA256SUMS.txt
```

Якщо в рядках завантажених файлів указано `OK`, усе гаразд.
