## 2. សាកល្បងប្រើ

ជាដំបូង យើងណែនាំឱ្យសាកល្បងជាមួយសំណើដែលមិនកែប្រែឯកសារ។

> ខ្ញុំគ្រោងនឹងបង្កើតគេហទំព័រជាភាសាខ្មែរ។ សូមប្រាប់ខ្ញុំអំពីចំណុចដែលគួរប្រុងប្រយ័ត្ន។ សូមកុំកែប្រែឯកសារណាមួយ។

## ពិនិត្យថាឯកសារត្រឹមត្រូវ (ស្រេចចិត្ត)

ប្រសិនបើចង់ពិនិត្យថាឯកសារដែលបានទាញយកមិនខូច សូមប្រើ [SHA256SUMS.txt]({{sums}})។

ដាក់ SHA256SUMS.txt ក្នុងថតតែមួយជាមួយឯកសារ ZIP ដែលបានទាញយក រួចដំណើរការពាក្យបញ្ជាខាងក្រោមក្នុង terminal។ ប្រសិនបើគ្មាន `shasum` សូមផ្ទៀងផ្ទាត់ SHA-256 ដោយប្រើពាក្យបញ្ជាផ្សេង ដូចជា `Get-FileHash` របស់ Windows PowerShell។

```sh
shasum -a 256 -c --ignore-missing SHA256SUMS.txt
```

ប្រសិនបើបន្ទាត់នៃឯកសារដែលបានទាញយកបង្ហាញ `OK` មានន័យថាគ្មានបញ្ហាទេ។
