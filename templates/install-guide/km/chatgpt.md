## A. បន្ថែម Skill ទៅក្នុង ChatGPT

វិធីនេះប្រើបាន នៅពេលអេក្រង់ ChatGPT មាន «Skills» និងជម្រើសសម្រាប់ផ្ទុកឡើង។

1. ជ្រើសរើសឯកសារ ZIP របស់ Skill មួយ ហើយផ្ទុកឡើង។
2. ពិនិត្យខ្លឹមសារដែលបង្ហាញ រួចបន្ថែម។
3. ធ្វើជំហានដដែលនេះម្ដងទៀតតាមចំនួន Skill ដែលត្រូវការ។

**ចំណាំ**

- ឯកសារ ZIP របស់ប្លាកអ៊ីនមិនអាចប្រើជាមួយវិធីនេះបានទេ។ សូមប្រើឯកសារ ZIP របស់ Skill។
- ការភ្ជាប់ឯកសារទៅក្នុងការជជែកតែប៉ុណ្ណោះ មិនមែនជាការបន្ថែម Skill ទេ។
- ប្រសិនបើរកមិនឃើញជម្រើសនេះនៅលើអេក្រង់ទេ ប្រហែលជាការជាវ ឬកម្មវិធីដែលអ្នកកំពុងប្រើ មិនទាន់ផ្ដល់មុខងារនេះនៅឡើយ។ សូមពិនិត្យ [ការណែនាំផ្លូវការរបស់ OpenAI](https://learn.chatgpt.com/docs/build-skills)។

## B. ចុះឈ្មោះជាប្លាកអ៊ីននៅក្នុង ChatGPT

វិធីនេះប្រមូល Skill ទាំង 4 ហើយចុះឈ្មោះជាប្លាកអ៊ីនសម្រាប់តែអ្នកប្រើផ្ទាល់។

1. បើកការសន្ទនាថ្មីនៅក្នុង ChatGPT ហើយជ្រើសរើស `@plugin-creator`។
2. ភ្ជាប់ឯកសារ ZIP របស់ប្លាកអ៊ីន។
3. ស្នើដូចខាងក្រោម៖

   > សូមចុះឈ្មោះកញ្ចប់នេះជាប្លាកអ៊ីនឯកជនសម្រាប់ខ្ញុំប្រើផ្ទាល់។ សូមកុំដាក់ស្នើវាទៅកាន់បញ្ជីសាធារណៈ។

4. បន្ទាប់ពីចុះឈ្មោះរួច **{{display}}** នឹងបង្ហាញនៅក្នុង «Personal» ឬ «Created by me» នៃ Plugins។
5. ដំឡើងប្រសិនបើចាំបាច់ រួចបើកដំណើរការវានៅក្នុងការសន្ទនាថ្មី។

**ចំណាំ**

- ប្លាកអ៊ីនអាចត្រូវបានរក្សាទុកក្នុង workspace របស់ក្រុម។ ប្រសិនបើចង់ប្រើតែម្នាក់ឯង សូមពិនិត្យទីតាំងរក្សាទុកមុនពេលចុះឈ្មោះ។
- មុខងារនេះអាចប្រើមិនបាន អាស្រ័យលើការជាវ ឬការកំណត់ workspace។ សម្រាប់ព័ត៌មានលម្អិត សូមមើល [Build plugins](https://learn.chatgpt.com/docs/build-plugins) និង [Plugins](https://learn.chatgpt.com/docs/plugins)។
- ប្លាកអ៊ីនដែលចុះឈ្មោះតាមវិធីនេះ អាចប្រើបានតែក្នុងគណនីរបស់អ្នកប៉ុណ្ណោះ ហើយមិនត្រូវបានដាក់បង្ហាញក្នុងបញ្ជីសាធារណៈទេ។

## ពិនិត្យថាឯកសារត្រឹមត្រូវ (ស្រេចចិត្ត)

ប្រសិនបើចង់ពិនិត្យថាឯកសារដែលបានទាញយកមិនខូច សូមប្រើ [SHA256SUMS.txt]({{sums}})។

ដាក់ SHA256SUMS.txt ក្នុងថតតែមួយជាមួយឯកសារ ZIP ដែលបានទាញយក រួចដំណើរការពាក្យបញ្ជាខាងក្រោមក្នុង terminal។ ប្រសិនបើគ្មាន `shasum` សូមផ្ទៀងផ្ទាត់ SHA-256 ដោយប្រើពាក្យបញ្ជាផ្សេង ដូចជា `Get-FileHash` របស់ Windows PowerShell។

```sh
shasum -a 256 -c --ignore-missing SHA256SUMS.txt
```

ប្រសិនបើបន្ទាត់នៃឯកសារដែលបានទាញយកបង្ហាញ `OK` មានន័យថាគ្មានបញ្ហាទេ។
