## A. Gemini CLI: এক্সটেনশন হিসেবে ইনস্টল করুন

এই পদ্ধতিতে চারটি স্কিল একসঙ্গে ইনস্টল হয়।

1. [এক্সটেনশনের ZIP]({{plugin_url}}) ডাউনলোড করুন।
{{#if plugin_folder}}
2. ZIP খুললে `{{plugin_folder}}` ফোল্ডার তৈরি হবে।
{{else}}
2. একটি খালি `{{plugin}}` ফোল্ডার তৈরি করে তার ভেতরে ZIP খুলুন।
{{/if}}
3. ফোল্ডারটি নির্দিষ্ট করে ইনস্টল করুন।

   ```sh
   gemini extensions install "/absolute/path/{{plugin_dir}}"
   ```

নিশ্চিতকরণের স্ক্রিন দেখা গেলে তথ্য যাচাই করে এগিয়ে যান। ইনস্টল করার পর এক্সটেনশনটি সব প্রজেক্টে চালু থাকে।

ZIP থেকে ইনস্টল করলে স্বয়ংক্রিয়ভাবে আপডেট হয় না। নতুন সংস্করণ এলে ZIP বদলে দিন।

## B. Gemini CLI: স্কিল বেছে নিয়ে ইনস্টল করুন

এই পদ্ধতিতে শুধু দরকারি স্কিলগুলো প্রজেক্ট ধরে ধরে ইনস্টল করা হয়। পদ্ধতি A দিয়ে ইনস্টল করে থাকলে এই ধাপগুলোর দরকার নেই।

উদাহরণস্বরূপ, `{{first}}` ইনস্টল করতে সংশ্লিষ্ট প্রজেক্টে নিচেরটি চালান:

```sh
gemini skills install https://github.com/landco-llc/kumihan --path {{skills_path}}/{{first}} --scope workspace
```

অন্য স্কিল ইনস্টল করতে `--path` এভাবে বদলে দিন:

{{gemini_paths}}

`--scope workspace` মানে “শুধু এই প্রজেক্টে” ব্যবহারের সেটিং। এটি বাদ দিলে স্কিলটি সব প্রজেক্টে ব্যবহার করা যাবে।

**আপডেট করতে**

একই কমান্ড আবার চালান। ইনস্টল করা স্কিলটি প্রতিস্থাপিত হবে, তাই নিজে কোনো পরিবর্তন করে থাকলে আগে সেটি সংরক্ষণ করুন।

## C. Gemini অ্যাপ: স্কিল আপলোড করুন

1. যে স্কিলগুলো ব্যবহার করতে চান, সেগুলোর ZIP ডাউনলোড করুন।
{{skills_list_indented}}
2. Gemini-তে **Customize** (দেখা না গেলে **More**) → **Skills** → **Upload** খুলুন।
3. ZIP ফাইলগুলো একটি একটি করে বেছে নিন, তথ্য যাচাই করুন এবং **Create** চাপুন।

**লক্ষ করুন**

- এটি ১৮ বছর বা তার বেশি বয়সী ব্যবহারকারীদের ব্যক্তিগত Google অ্যাকাউন্টে ব্যবহার করা যায়। কর্মক্ষেত্র বা শিক্ষাপ্রতিষ্ঠানের অ্যাকাউন্টে বর্তমানে এটি ব্যবহার করা যায় না।
- “Keep Activity” (অ্যাক্টিভিটি সংরক্ষণ) চালু রাখতে হবে।
- ফিচারটি ধাপে ধাপে চালু করা হচ্ছে, তাই এখনও আপনার কাছে দেখা নাও যেতে পারে। বিস্তারিত জানতে [Gemini-এর অফিশিয়াল সহায়তা](https://support.google.com/gemini/answer/17094296?hl=bn) দেখুন।
- এক্সটেনশনের ZIP (Gemini CLI-এর জন্য) এখানে কাজ করে না।
- আপলোড করা স্কিল স্বয়ংক্রিয়ভাবে আপডেট হয় না। নতুন সংস্করণ এলে আবার আপলোড করুন।

## 2. ব্যবহার করে দেখুন

শুরুতে এমন অনুরোধ দিয়ে চেষ্টা করা ভালো, যাতে কোনো ফাইল বদলায় না।

> আমি বাংলায় একটি প্রেজেন্টেশন তৈরি করার পরিকল্পনা করছি। কোন কোন বিষয়ে খেয়াল রাখা উচিত, বলুন। কোনো ফাইল পরিবর্তন করবেন না।

## ফাইল ঠিক আছে কি না যাচাই করুন (ঐচ্ছিক)

ডাউনলোড করা ফাইল নষ্ট হয়নি কি না যাচাই করতে চাইলে [SHA256SUMS.txt]({{sums}}) ব্যবহার করুন।

ডাউনলোড করা ZIP ফাইলগুলো যে ফোল্ডারে আছে, সেখানেই SHA256SUMS.txt রাখুন এবং টার্মিনালে নিচের কমান্ডটি চালান। `shasum` না থাকলে Windows PowerShell-এর `Get-FileHash` বা অনুরূপ কোনো উপায়ে SHA-256 মিলিয়ে দেখুন।

```sh
shasum -a 256 -c --ignore-missing SHA256SUMS.txt
```

ডাউনলোড করা ফাইলের সারিতে `OK` দেখা গেলে ফাইলটি ঠিক আছে।
