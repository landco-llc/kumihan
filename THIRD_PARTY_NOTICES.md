# Third-party references

KUMIHAN's independently authored product guidance is provided under the existing [Apache-2.0 LICENSE](LICENSE). Each standalone folder carries the same license bytes. This license does not relicense linked external standards, documentation, fonts or other third-party material.

The [public source registry](skills/kumihan/sources/public-sources.json) distinguishes adopted references, comparison-only metadata and deferred candidates. A listed URL is not evidence that its content was adopted, copied or verified. Public guidance cites standards and implementation documentation without distributing protected standard text or font binaries.

Adopted references include [JLReq (2020 note)](https://www.w3.org/TR/2020/NOTE-jlreq-20200811/), [Unicode UAX #14 revision 57](https://www.unicode.org/reports/tr14/tr14-57.html), [CSS Text Level 4 (2026-08-14 working draft)](https://www.w3.org/TR/2026/WD-css-text-4-20260814/), [WCAG 2.2 (2024 recommendation)](https://www.w3.org/TR/2024/REC-WCAG22-20241212/), the registry's selected WCAG Understanding pages, [Digital Agency typography](https://design.digital.go.jp/dads/foundations/typography/) and [OpenType feature documentation](https://learn.microsoft.com/en-us/typography/opentype/spec/features_pt). A working draft is not a final recommendation; selected references do not establish whole-site accessibility conformance or legal compliance.

The build script in `tools/` is development tooling that uses the Python standard library only; it is not a consumer requirement or a bundled skill asset. See [development](docs/development.md). No ownership, rights or runtime assurance follows solely from a citation or static check.
