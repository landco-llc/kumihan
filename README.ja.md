# KUMIHAN — 日本語の使い方

[English](README.md)

KUMIHAN は、日本語の Web・文書制作を支援する、計画中の v0.1 スキル製品です。原文の保持、目的に合う組版と構成、実際の確認内容に基づく報告を支援します。v0.1 は未リリースです。このブランチは契約と公開文書の草案で、統合・単独配布フォルダー・ホストでの動作確認は未完了です。

## スキルと対象

| スキル | 役割 |
| --- | --- |
| `kumihan` | 目的、媒体、モード、権限、保護対象を確認し、必要な資料を選ぶ。 |
| `kumihan-web` | 記事、マーケティング、UI の制作と、日本語組版・条件付きリフロー確認を支援する。 |
| `kumihan-documents` | 報告書とスライドの階層、改ページ、注記、元データ、描画確認を支援する。 |
| `kumihan-review` | 既存の対象を変更せずにレビューし、所見を報告する。 |

38 件は **guidance rules（指針）** であり、38 個の自動検出器ではありません。プロファイルは `web-editorial`、`web-marketing`、`web-ui`、`report-document`、`presentation`、`display-copy` の六つです。[確認範囲](docs/coverage.md)を参照してください。

## 依頼の書き方

| モード | 実行の範囲 |
| --- | --- |
| `study` | 指針や選択肢を説明する。対象を編集しない。 |
| `build` | 明示された出力先・ツール権限の範囲で制作する。 |
| `audit` | 調査して報告する。対象を編集しない。 |
| `refine` | 明示的に許可された対象・範囲だけを修正する。audit 後の修正には、新たな明示的 refine 許可が必要。 |

読者、目的、媒体、出力先、使用可能なツール、編集範囲、保護対象を伝えます。人名・価格・数値・単位・句読点・異体字セレクター・分解された Unicode を、個別の変更許可なしに変えないでください。スキルやスキーマの妥当性は編集権限を与えません。制作前に構成理由、文字の役割、実際の素材の出所、ブランド制約、採用しない既定パターン、例外を記録します。カード、グラデーション、対称配置は一律禁止ではなく、目的に照らして判断します。

依頼例：「kumihan-review を audit モードで使い、この日本語記事をレビューしてください。原文は保護対象です。利用可能なレンダラーで狭い画面の配置を確認し、実行できない確認も報告してください。編集しないでください。」呼び出し記法はホストによって異なり、ここでは未検証です。

## 導入と報告

検証済みバンドルが用意されたら、選んだ **一つの完全なスキルフォルダー** をホスト対応の場所にコピーします。`SKILL.md` と同梱の参照資料を保持してください。利用者に Python・`jsonschema`、兄弟リポジトリ、別の計画サービスは不要です。[導入手順](docs/installation.md)のローカル Codex の場所と、Cloud の検証待ちの区別を確認してください。公開済みダウンロードや KUMIHAN 専用マーケットプレイスコマンドはありません。

制作には、ホストに実在し、使用が許可されたツールを使います。ブラウザー描画、PDF・スライド変換、フォント利用はホストの任意機能で、KUMIHAN は提供しません。レンダラーがない場合、視覚的な確認は `not-checked` または `unsupported` とし、テキストだけで組版を passed にしません。

結果は `passed`、`failed`、`needs-review`、`not-checked`、`unsupported`、`waived`、`not-applicable` を区別します。passed には関連する証拠と確認方法が必要です。範囲を限定して承認された waived は passed とは異なります。モデルの判断は assisted/manual と表示し、決定的な自動検証と混同しません。構造検査は内容の真実性、美しさ、法的な独創性、実ホストの動作を証明しません。

Codex Cloud の互換性は観測記録待ちで pending/unverified です。Office ネイティブ、全ブラウザー、他のプロバイダーの認証はありません。[互換性](docs/compatibility.md)を参照してください。
