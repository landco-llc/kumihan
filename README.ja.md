# KUMIHAN

[English](README.md)

**日本語の文字組みから、AIのデザインをもっと自然に。**

KUMIHANは、AIを使った日本語のWebサイト・記事・文書・プレゼンテーション資料の制作とレビューを支援するオープンソースプロジェクトです。

改行や禁則、約物、和欧混植、文字と余白のバランスなど、日本語ならではの読みやすさを大切にしています。決まりきったテンプレートではなく、**伝えたい内容と目的に合ったデザイン**を目指します。

## KUMIHANが目指すこと

- **読みやすい日本語の文字組み** — 改行、字間、約物、和文と欧文の組合せへの配慮。
- **伝わるレイアウト** — 情報の優先順位が分かる、目的に合った構成。
- **原稿を大切にする制作** — 言葉、名前、数値などの内容を保持。
- **制作物のレビュー** — 文字の読みやすさや配置の問題を見直すための支援。

## 公開状況

**現在v0.1を開発中です。この文書はリリースや公開済み配布バンドルを示すものではありません。** `skills/` 配下に4つの完全なフォルダーが収録されています。各フォルダーには38のガイダンスルール、6つのプロファイル、引用した標準、ローカル参照資料、スキーマ、インベントリー、ライセンスが含まれます。どれか1つを独立してコピーでき、利用時にPython、開発用依存関係、他のSkillフォルダー、ネットワークでの参照取得を必要としません。

これは制作・レビューの指針であり、38の自動検出器ではありません。利用可能なホストのツールで、`study`、`build`、読み取り専用の `audit`、明示的に許可された範囲の `refine` を選ぶための支援を行います。ホストによる検出・呼び出しは未検証です。静的チェックは実際の描画やOfficeネイティブ互換性を検証せず、承認の自動解決機能も提供しません。独立したレビューは未実施です。

[導入方法](docs/installation.md)はソースフォルダーからの導入案です。[カバレッジ](docs/coverage.md)と[互換性](docs/compatibility.md)では現在のチェック、非対応の機能、今後の作業を区別しています。[開発](docs/development.md)、[来歴](docs/provenance.md)、[貢献](CONTRIBUTING.md)、[セキュリティ](SECURITY.md)、[第三者に関する通知](THIRD_PARTY_NOTICES.md)に根拠と範囲を記載しています。リンク先の詳細文書は英語です。
