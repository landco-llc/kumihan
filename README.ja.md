# KUMIHAN

[English](README.md)

**日本語の文字組みから、AIのデザインをもっと自然に。**

KUMIHANは、AIを使った日本語のWebサイト・記事・文書・プレゼンテーション資料の制作とレビューを支援するオープンソースプロジェクトです。

改行や禁則、約物、和欧混植、文字と余白のバランスなど、日本語ならではの読みやすさを大切にしています。決まりきったテンプレートではなく、**伝えたい内容と目的に合ったデザイン**を目指します。

## KUMIHANが目指すこと

- **読みやすい日本語の文字組み** — 改行、字間、約物、和文と欧文の組合せへの配慮。
- **伝わるレイアウト** — 情報の優先順位が分かる、目的に合った構成。
- **原稿を大切にする制作** — 言葉、名前、数値などの内容を保持。
- **制作物のレビュー** — 文字の読みやすさや配置の問題を見直すための支援。

## 開発中のSkills

| Skill | 主な用途 |
| --- | --- |
| `kumihan` | 内容や媒体に合う制作指針の選択 |
| `kumihan-web` | Webサイト・記事・UIの文字組みとデザイン |
| `kumihan-documents` | 文書・報告書・プレゼン資料の制作 |
| `kumihan-review` | 元の制作物を変更しないレビュー |
