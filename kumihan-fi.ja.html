01 / THE IDEA

「見た目をそろえる」より
「伝わる形を考える」

目的も読み手も違うのに、同じ構成を繰り返さない。文章の意味や情報の優先順位を踏まえて、文字組み・余白・レイアウトを考える。KUMIHAN｜Rytmiは、デザインを画一化するためではなく、一つひとつの制作物をよりよくするための指針を提供します。フィンランド語では、まずその文字が順に読むものか、UIで操作するものか、見出しやロゴ、ポスターとして見せるものかを見極め、それに合うリズム（rytmi）を探ります。

02 / WHAT MATTERS

伝えるための4つの視点

制作と見直しに共通する、KUMIHAN｜Rytmiが大切にする考え方。

01 / TYPE
Ä Ö Å

フィンランド語の文字組み

ä・ö・åは、記号を添えたa・oではなく、アルファベットの一字です。全大文字の見出しやロゴでも点や輪を落とさず、別の文字に置き換えません。同じ文字を重ねて書くかどうかで意味が変わり、tuli・tulli・tuuliは火・税関・風を表します。重なった文字をまとめたり、見分けにくくなるほど字間を詰めたりしません。verkkokauppaのような長い複合語や、EU:ssaのような格語尾も語の一部です。ボタンや入力欄のラベルは、語を切らずに収まる幅を確保します。

02 / STRUCTURE
▮▮▯

内容に合う構成

伝える順番と情報の重要度を整理し、目的に合ったレイアウトを考えます。本文、UIの文言、数値、見せる文字（見出し、ロゴ、ポスター）を別々に扱います（調査では、公共のSuomi.fiデザインシステムが小さな画面でも本文を18pxに保ち、H1を40pxから32pxに縮めています）。行末の分綴はverkko-kauppaのように複合語の境界を優先し、検証済みの辞書なしに一律で有効にしません。

03 / FIDELITY
” €

原稿を大切に

名前・引用・数値・日時・コード・意味を守ります。フィンランド語の引用符は通常、開きも閉じも同じ”…”で、英語式の“…”へ一括変換しません。1 234,50の空白と小数点のコンマ、18,90 €・20 %の空白、21.10.2026やklo 10.30のピリオドを保ち、EU:ssaや20 %:nはコロンの後で分断しません。標準的な書き言葉、話し言葉、selkokieli（やさしいフィンランド語）の間の書き換えは編集にあたるため、提案として記録し、黙って書き換えません。

04 / REVIEW
◌̈

制作後の見直し

完成物の気になる点を、対象を変更せずに確認・整理するための指針です。hyphensを宣言しただけでは、フィンランド語が正しく分綴された証拠になりません。表示結果をブラウザごとに確かめます。長い語は活用形で、320 CSS px幅と200%拡大の条件で試し、日時・料金・会場などの必要な情報を装飾文字や画像化した文字だけに頼らせません。

DESIGNED FOR THE MESSAGE

文字を並べるだけでなく
読む体験を組み立てる

KUMIHAN｜Rytmiは完成デザインを一律に指定しません。使う媒体や条件に合わせて考えるための知識を提供します。「フィンランドらしい」唯一の書体や、北欧ミニマルの定型はありません。FrakturからAntiquaへの移行は段階的に進み、いまも公共のUI、新聞、手描きのフェスティバル表現、古い看板に由来するブランド文字が共存しています。書体はText／Headlineの別、ウェイト、幅、版、利用条件まで比べます。

kumihan-rytmi-web

COMING SOON / v0.1.0

v0.1.0（予定）は、完了した調査をもとに開発中です。4つのスキル（kumihan-rytmi・-web・-documents・-review、名称は仮）を計画していますが、ルールはまだ確定していません。調査では、現代の標準的なフィンランド語（fi）を初期の重点として提案しています。辞書に基づく分綴、selkokieli（やさしいフィンランド語）、歴史資料、独自の装飾文字にはさらに根拠が必要です。配布、ブラウザごとの表示と分綴、書体の選定は未検証で、このサイトのフィンランド語の文面は母語話者による確認をまだ受けていません。
